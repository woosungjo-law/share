처분 권고·징계 검토와 연계

3줄 요약

  • 조사 결과에 따른 선택지는 징계·경고·교육·부서 이동·피해 회복·형사 고소·민사 청구·합의·무혐의 종결이다.
  • 징계는 취업규칙과 인사 규정에 근거해야 하며, 징계 사유·양정·절차·소명 기회·징계위원회 구성·통지 방식이 모두 적법해야 한다.
  • 형사 고소는 증거 충분성과 회사 자료의 수사 절차 노출 리스크를 함께 고려한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 결정)

사실인정(017) -> [처분 권고·징계] -> 사후 조치(019)

1. 이번 단계에서 반드시 할 일

  • [ ] 사실인정 결과에 기반한 선택지 목록화(징계·경고·고소·합의·종결)
  • [ ] 각 선택지별 필요 증거 수준과 리스크 비교
  • [ ] 징계 사유와 양정을 분리하여 검토 — 고의성·반복성·손해 규모·사후 태도·형평성
  • [ ] 취업규칙·인사 규정상 징계 근거 조항 확인
  • [ ] 형사 고소 검토 시 회사 자료의 수사 절차 노출 리스크 평가

2. 준비물

| 준비물 | 왜 필요한가 | 준비 상태 | |---|---|---| | 취업규칙·인사 규정 | 징계 사유·절차·양정 근거 | 미확인 | | 징계 검토 체크리스트 | 사유·양정·절차·소명 기회·형평성 | 미확인 | | 형사 고소 검토표 | 증거 충분성·노출 리스크·시효 확인 | 미확인 |

3. 작성·제출물

| 문서 | 제출처 | 주의점 | |---|---|---| | 처분 권고서 | 감사위원회·경영진 | 사실·증거·규정·비례성 기준 명시 | | 징계 검토 메모 | 인사팀(법무팀 검토) | 징계 사유·양정 근거 별도 기재 | | 형사 고소 검토서(필요 시) | 경영진(의사결정) | 고소 리스크·증거 현황 포함 |

4. 흔한 실수

  • 사실 확인과 징계 양정을 혼동 — "무죄면 징계 안 됨"이라는 오해(징계는 법적 유죄와 별개)
  • 형사 고소의 증명 수준을 내부 조사에 적용 — 과도한 증거 요구로 조사 지연
  • 징계 절차(소명 기회·징계위원회)를 생략 — 징계 효력 다툼
  • 합의 시 비밀 유지·법령상 신고 의무와의 관계 미정리

5. 전문가 상담 신호

위험도: 상담 권장

  • 형사 고소를 검토하는 경우 — 고소장 작성·증거 구성에 전문가 필요
  • 임원 징계 또는 해고가 예상되는 경우 — 부당 해고 리스크 검토 필요
  • 합의 조건·비밀 유지 범위 설정이 복잡한 경우

6. 인접 절차 연결

  • 선행: PROC-INVS-017 · 후속: PROC-INVS-019(경영진 보고) / PROC-HARS(징계)
