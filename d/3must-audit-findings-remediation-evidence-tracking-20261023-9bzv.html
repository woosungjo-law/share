컴플라이언스 감사 지적사항의 시정 담당과 완료 근거를 정할 때

적용 상황: 감사에서 여러 내부통제·준법 항목의 개선 지적을 받아, 항목별 실행 부서와 확인 자료를 정리해 후속 진행을 관리해야 할 때 사용합니다. 범위: 이 카드는 법적 의무 위반 여부나 감독기관 제출·통지 의무를 판단하지 않습니다. 감사 지적사항의 사실 확인, 시정 작업 배정, 완료 근거 관리만 다룹니다.

Must Know · 알아야 할 것

  • 감사 등급은 해당 감사 기준에 따른 표시로 관리하고, 그 자체를 법 위반·책임·제재 결론으로 바꾸지 않습니다.
  • “정책을 만들었다”는 설명과 실제 절차가 운영되고 있는 근거를 구분해 확인합니다.
  • 우선순위 평가와 각 지적사항의 시정 완료는 다른 기록입니다. 담당자·조치·증빙·검토자·종결일을 항목별로 연결합니다.

Must Check · 확인할 것

  • 감사 보고서의 원문 지적, 범위, 기준일, 평가방법과 관련 자료를 보존했는가?
  • 지적된 업무 과정과 실제 자료를 담당 부서와 대조해 사실관계를 확인했는가?
  • 즉시 차단·보존이 필요한 운영 문제가 있는지 관련 담당자가 확인했는가?
  • 원인, 영향받는 프로세스·시스템, 기존 통제와 빠진 통제를 구분했는가?
  • 시정 책임자, 협업 부서, 목표일, 필요한 자원과 진행상태를 정했는가?
  • 완료로 판단할 증빙과 이를 확인할 독립 검토자를 미리 정했는가?
  • 반복 지적 여부와 이전 시정 조치의 실제 운영 기록을 확인했는가?

Must Do · 실행할 것

  1. 감사 지적사항별 관리번호를 부여하고 원문 문구, 기준일, 제출 자료와 담당 감사인을 연결해 보존합니다.
  2. 업무 부서와 함께 지적이 발생한 실제 흐름을 따라가며 확인된 사실, 원인 가설, 아직 확인되지 않은 사항을 나눕니다.
  3. 즉시 위험을 줄일 임시 조치와 근본 원인을 바꿀 후속 조치를 구분하고, 실행 책임자와 협업 부서를 지정합니다.
  4. 각 조치에 완료 목표일, 필요한 자원, 진행 상태, 지연 시 보고 경로를 붙입니다. 모든 항목에 동일한 기한이나 등급을 일괄 적용하지 않습니다.
  5. 조치 완료를 입증할 문서·시스템 기록·표본 점검 결과와 검토자를 정하고, 자료 위치와 확인일을 기록합니다.
  6. 검토자는 계획서 작성 사실만으로 종결하지 말고 실제 운영 여부와 표본 결과를 확인해 보완 필요성을 기록합니다.
  7. 반복 지적이나 일정 지연은 원인·영향·추가 자원·결정 필요 사항을 함께 올리고, 의사결정자의 판단과 남은 위험을 기록합니다.
  8. 종결된 항목도 재점검 시점과 담당을 정하고, 감사 보고용 요약은 지적 원문·시정 조치·증빙·미완료 사항이 서로 추적되게 작성합니다.
