3MUST · 형사법

임직원이 자료를 삭제한 정황이 확인됐을 때

적용 상황: 내부 감사나 규제기관 조사 준비 과정에서 임직원이 문서·데이터를 삭제한 정황이 확인되어, 추가 삭제를 막고 사실을 기록·보고해야 할 때 법무·컴플라이언스 담당자가 사용합니다.

Must Know · 알아야 할 것

  • 먼저 할 일은 결론 판단이 아니라 추가 삭제 차단과 증거 확보입니다.
  • 삭제 경위는 시점·범위·경로가 기록으로 남아야 나중 어떤 검토든 가능해집니다.
  • 임직원에게 삭제 경위를 강제로 진술시키면 문제가 커집니다. 진술은 권리 안내 후 자율적으로 받고, 객관 자료를 우선 확보합니다.
  • 임직원 개인의 책임 여부와 회사의 대응 의무는 별개입니다.
  • 조사·수사 중인 사건에서는 자료의 임의 삭제·반출 자체가 별도 문제로 이어질 수 있습니다.

Must Check · 확인할 것

  • 삭제가 의심되는 기기·계정·저장소 범위 목록(PC·공용 폴더·서버·클라우드·모바일)
  • 발견 시점·발견자·최초 발견 경위
  • 사전 보존 안내·명령 발령 내역과 수신 확인 기록
  • 삭제 관련 지시·대화 정황의 보존 여부 (수정·삭제 금지)
  • 백업·로그·기기 교체 이력 등 객관 자료의 보관 상태
  • 여전히 추가 삭제·수정 위험에 노출된 영역

Must Do · 실행할 것

  1. 관련 임직원 전원에게 문서로 보존 안내(명령) 발송 — 삭제·이동·복제·외부 반출 금지, 기기 교체 금지, 위반 시 보고 창구 명시
  2. 의심 기기·계정 접근 제한, IT와 협업해 포렌식 보존 또는 이미지 백업 요청
  3. 발견 경위를 시간 순으로 기록 — 언제, 누가, 어디서, 무엇을 발견하고 무엇을 했는지
  4. 확보한 객관 자료(로그·백업·지시 기록)를 원본 상태로 보존하고 사본을 검토용으로 분리
  5. 경영진 보고 — 확인된 사실, 미확인 사항, 즉시 조치, 다음 검토 일정을 구분
  6. 외부 변호사 검토 인계 — 확인된 사실 목록과 보존 조치 이력 함께 제출
잠깐 멈추고 검토할 때외부 기관의 조사·수사와 사건이 연결된 정황이 있을 때, 삭제 지시가 임원급에서 나왔다는 정황이 있을 때, 임직원이 진술 거부나 변호인 참여를 요구할 때, 삭제 범위가 회계·인사·규제 대응 자료처럼 핵심 영역에 걸쳐 있을 때에는 내부 조사만으로 처리하지 말고 외부 검토로 넘기고 보존 범위를 전사로 확대합니다.
