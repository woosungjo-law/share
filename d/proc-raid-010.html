PROC-RAID-010 | 문서 및 실물 자료 압수 대응 (영장 기재 범위를 벗어난 압수 방어)

3줄 요약

  • 수사관은 영장에 기재된 '압수할 물건'과 '수색할 장소' 범위 내에서만 압수할 수 있으며, 범위 이탈 압수는 즉시 이의제기 대상이다
  • 수사관이 압수하려는 문서·물건이 영장 범위에 해당하는지 확인하려면 반드시 영장 원본을 직접 읽고 대조해야 한다
  • 영장 범위를 벗어난 물건을 임의제출·압수목록 서명으로 승인하면 추후 이의제기가 곤란해지므로 서명 전 반드시 변호인 검토를 받아야 한다

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후

[009] 참관권 보장 요구 -> [010] 문서·실물 압수 대응 -> [011] 디지털 포렌식 대응

1. 이번 단계에서 반드시 할 일

  • 영장 원본을 직접 열람하고 '압수할 물건'(제2항 제3호)과 '수색할 장소'(제2항 제2호) 기재를 확인한다
  • 수사관이 압수하려는 개별 문서·물건 하나하나에 대해 "이 물건이 영장 기재 '압수할 물건' 중 어느 항목에 해당하는지 설명해 달라"고 요청한다
  • 영장 범위를 벗어난 것으로 판단되는 물건에 대해서는 "이 물건은 영장 범위를 벗어나므로 압수에 동의할 수 없으며, 별도 영장을 받아 오시기 바란다"고 명시적으로 이의를 제기한다
  • 압수물 목록 작성 시 수사관이 기재하는 압수물명·수량·특징을 반드시 눈으로 확인하고 대조한다
  • 압수물 목록에 서명하기 전 변호인의 검토를 받는다 (변호인 부재 시 "변호인 검토 후 서명하겠다"고 하고 서명을 보류한다)
  • 수사관이 영장과 관련 없는 서류더미·파일을 뒤적이거나 열람하는 행위를 발견하면 즉시 "그 행위는 영장 범위 밖의 수색에 해당한다"고 구두 항의한다

2. 준비물

준비물 왜 필요한가 준비 상태
영장 사진(스마트폰 촬영) 수사관이 영장을 거둔 후에도 압수범위 대조 가능 미확인
압수물 대조 체크리스트 (영장 '압수할 물건' 항목별) 현장 혼란 속에서도 범위 이탈 압수를 실시간 감지 미확인
이의제기 작성 서식 ('압수 범위 이의제기서' 초안) 현장에서 즉시 기재하여 수사관에게 교부 미확인
별도의 봉투·박스 "영장 범위 이탈 물건은 여기에 따로 보관 요청" (분쟁 최소화) 미확인

3. 작성·제출물

문서 제출처 주의점
압수물 목록 (사본·사진 필수) 수사관 작성본과 동시에 회사 측 사본 확보 수사관 작성 목록과 차이가 없도록 즉시 대조
영장 범위 이탈 압수 항의서 현장 수사관 + 당일 팩스/이메일로 검찰청·경찰청 감사부서 이의제기 시각·수사관 성명·대상 물건 특정
압수물 반환 청구서 (준항고) 법원 (영장 발부 법원) 영장 범위 이탈이 명백할 때만 제기, 전문가 검토 필수

4. 흔한 실수

  • "영장에 '관련 문서'라고 광범위하게 기재되어 있다"며 포기: 영장 기재가 광범위하더라도 '관련성'이라는 해석의 테두리는 존재함. 예를 들어 특정 계약서를 압수하는 영장인데 회사 전체 급여명부까지 압수하려 하면 범위 일탈. 구체적 관련성 요구 가능
  • 수사관이 "일단 다 가져가서 검토 후 관련 없는 건 돌려준다"고 하여 동의: 법원 영장 범위를 수사관 재량으로 사후 판단하게 방치하는 것. 반환이 현실적으로 어렵고, 수사팀이 모든 자료를 열람·분석할 기회를 주는 결과 초래
  • 압수물 목록에 "기명날인 또는 서명"을 아무 확인 없이 함: 압수목록 서명은 '압수사실 확인'의 의미를 넘어 '압수 절차 적법 확인'으로 해석될 소지 있음. 압수물명·수량이 실제와 일치하는지 반드시 1:1 대조

5. 전문가 상담 신호

위험도: 상담 권장

  • 영장 기재가 '특정 전자문서'가 아닌 '저장매체 전체'로 기재된 경우 → 대법원 2011모1839 전원합의체 판결에 따라 저장매체 반출·이미징 요건이 별도로 적용되므로 사전 대응책 수립 필요
  • 수사관이 '긴급 압수'를 주장하며 사후 영장을 받겠다고 하는 경우 → 긴급 압수 요건(형소법 제217조) 충족 여부를 즉시 검토해야 하며, 요건 미비 시 위법
  • 업무상 비밀(변호인·회계사·의료 기록 등)에 해당하는 문서가 압수 대상에 포함된 경우

6. 인접 절차 연결

  • 선행: PROC-RAID-009 (참관권 보장 요구) · 후속: PROC-RAID-011 (디지털 포렌식 대응)
  • 영장 범위 이탈 압수에 대한 사후 구제: PROC-RAID-016 (압수물 반환·준항고) / PROC-RAID-017 (위법수집증거 배제 신청)
