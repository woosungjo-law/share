공정위 조사관이 회사에 나왔을 때

적용 상황: 게시 URL 확인 후 입력 적용 상황: 공정거래위원회 조사관이 예고 없이 방문해 현장조사·자료제출을 요구하거나, 조사 관련 연락이 프론트데스크에 먼저 도착한 경우. 범위: 조사권의 범위, 거부·지연의 법적 효과, 과태료·과징금 여부를 판단하지 않습니다. 첫 몇 시간의 응대·연락·기록을 정리하는 카드입니다.

Must Know · 알아야 할 것

  • 첫 응대자가 회사의 태도를 사실상 결정합니다. 현장에서 즉흥적으로 대응하지 말고 연락 체계를 먼저 작동시킵니다.
  • 요구에 응하는지 여부와 별개로, 무엇을 요구받았고 무엇을 제공했는지는 기록으로 남아야 합니다.
  • 조사 단계와 심의 단계는 준비할 자료가 다릅니다. 아직 조사 단계라면 자료 제출 범위를 정하는 일이 먼저입니다.

Must Check · 확인할 것

  • 조사관의 소속·성명·직위와 제시한 문서(조사 공문·영장·자료요구서)의 종류와 범위를 확인했는가.
  • 요구 범위가 문서에 적힌 대상·기간·장소와 일치하는지, 범위를 넘는 요구가 있는지 확인합니다.
  • 사내 연락 체계(총괄 담당, 법무, IT, 홍보)가 즉시 가동되는지, 부재 시 대리 순서가 있는지 확인합니다.
  • 조사 대상 안건과 관련된 기존 회의록·메일·보고자료가 어디에 있는지 파악합니다.
  • 외부 변호인과의 상담·자문 자료가 어떤 경로로 관리되는지 확인합니다.

Must Do · 실행할 것

  1. 프론트데스크는 안내 후 총괄 담당자에게 즉시 연락하고, 응대자·시각·요구 사항을 한 줄씩 기록합니다.
  2. 총괄 담당자는 조사관에게 회사 절차를 설명하고, 요구 문서 사본과 방문 기록을 확보합니다.
  3. 조사 중 제공한 자료·복사·출력·계정 접근 내역을 목록으로 만들고 담당자를 지정합니다.
  4. 임직원 면담이 요구되면 면담 대상·시간을 기록하고, 사실 확인 없이 추측으로 답하지 않도록 안내합니다.
  5. 종료 후 첫 24시간 안에 요구 사항 / 제공한 것 / 보류한 것 / 사유 표를 만들어 법무와 확인합니다.
  6. 자료제출·의견제출 등 다음 기한이 통지되면 기한·제출 범위·담당자를 한 문서로 묶어 관리합니다.
잠깐 멈추고 검토할 때

요구 범위가 문서에 적힌 범위를 넘거나, 문서 없이 자료 제공을 요구하는 경우 · 조사 대상이 개인 형사책임과 연결되거나 임직원 개인 기기가 포함된 경우 · 이미 심사보고서가 송부되어 의견제출 기한이 걸린 경우 · 언론·거래처·투자자에게 알려질 가능성이 있어 공개 문구를 정해야 하는 경우

제한: 절차별 법정 기한, 조문·심결례 인용, 행정소송·집행정지 판단은 제외했습니다.
