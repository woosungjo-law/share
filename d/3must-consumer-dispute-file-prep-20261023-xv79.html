개별 소비자 분쟁조정 자료를 법무팀에 넘길 때

적용 상황: 조정기관 문서를 받고 관련 사실·자료를 정리해 법무팀에 전달할 때 씁니다. 범위: 자료 정리와 법무 인계만 다루며 법적 효력·기한·책임 판단은 하지 않습니다.

Must Know · 알아야 할 것

  • 한눈에: 문서 원본·요청사항 기록 → 사실·증빙 분리 → 법무 검토·승인 → 회신 증빙 보관.
  • 이 단계의 목적은 사건 문서와 확인된 사실을 빠짐없이 모아 검토자가 판단할 수 있게 넘기는 것입니다.
  • 고객의 주장, 회사 자료로 확인된 사실, 아직 확인되지 않은 내용은 서로 다른 항목으로 기록합니다.
  • 문서에 적힌 요청사항·회신일·회신 방법을 그대로 옮기고, 그 의미나 법적 효과를 임의로 해석하지 않습니다.
  • 담당자와 승인자를 분리해 사실 확인과 대외 회신이 한 사람의 추정만으로 진행되지 않게 합니다.

Must Check · 확인할 것

  • 받은 문서 원본, 첨부물, 발신 기관·담당 연락처와 접수 일시
  • 문서에 표시된 사건 식별정보와 회신 요청일·제출 방식
  • 소비자 주장, 회사가 이미 안내한 내용, 현재까지의 연락 기록
  • 계약·주문·결제·배송·수리 등 쟁점과 직접 관련된 업무 자료
  • 사실별 확인 상태와 확인 근거의 위치·담당자
  • 고객 응대 담당, 사실 확인 담당, 법무 검토자, 최종 승인자
  • 외부 제출본에 불필요한 개인정보나 다른 고객·거래의 정보가 섞였는지

Must Do · 실행할 것

  1. 받은 문서와 첨부물을 원형대로 보관하고 접수 일시·경로·보관 위치를 기록합니다.
  2. 문서에 적힌 요청사항, 회신 요청일, 제출 방식을 그대로 사건 기록에 옮기고 담당자와 일정 알림을 지정합니다.
  3. 소비자 주장과 주문·결제·배송·고객응대 자료를 시간순으로 대조합니다. 각 항목에 자료 출처와 확인 여부를 붙입니다.
  4. 확인된 사실, 소비자 측 주장, 미확인 사실을 구분한 한 장 요약과 관련 자료 목록을 만듭니다.
  5. 요청 범위에 필요한 자료만 묶고, 불필요한 개인정보나 무관한 거래정보는 내부 정책에 따라 가린 뒤 법무 검토자에게 전달합니다.
  6. 법무팀에는 문서상 요청사항, 회신 일정, 사실관계 요약, 미확인 항목, 사업부가 필요한 판단을 함께 전달합니다. 책임 유무나 조정 수용 여부를 사실처럼 미리 적지 않습니다.
  7. 검토와 승인 후 외부에 회신한 문안·첨부물·제출 시각·제출 경로·접수 증빙을 사건 기록에 보관하고 후속 일정의 담당자를 지정합니다.
잠깐 멈추고 검토할 때

문서에 적힌 회신일이나 제출 방법을 확인할 수 없거나 일정이 임박한 경우 · 조정 수락, 합의, 책임 인정 또는 금액 제시 등 회사의 입장 결정을 요구하는 경우 · 소비자 주장과 내부 기록이 충돌하거나 핵심 자료가 누락된 경우 · 제출 자료에 다른 사람의 개인정보나 비공개 거래정보가 포함된 경우

검토일: 2026-10-23
