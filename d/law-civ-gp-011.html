소장의 전체 구조 이해하기

3줄 요약

  • 소장은 법원에 소송을 제기하는 첫 번째 문서로, 법원은 소장을 보고 사건의 내용을 파악한다. 소장이 잘못되면 보정명령을 받거나 각하될 수 있다.
  • 소장은 크게 당사자 표시 → 청구취지 → 청구원인 → 입증방법 → 첨부서류 순서로 구성된다. 각 부분이 빠짐없이 기재되어야 한다.
  • 전자소송 사이트에서 양식을 제공하므로, 처음부터 혼자 작성해도 어렵지 않다. 다만 청구취지와 청구원인은 법률 검토가 필요할 수 있다.

0. 지금 당신의 위치

소장을 직접 작성하기 전에, 소장의 전체 구조를 이해하는 단계다.

...전자소송 가입 -> [소장 구조 이해] -> 본격 소장 작성

한눈에: 이 단계의 핵심은 소장은 법원과 상대방에게 내 주장을 전달하는 '편지' 라는 점을 이해하는 것이다. 형식이 틀리면 내용을 봐주지 않는다.

1. 이번 단계에서 반드시 할 일

  • 소장의 5대 구성 요소(당사자·청구취지·청구원인·입증방법·첨부서류)를 이해한다.
  • 전자소송 사이트의 소장 양식을 미리 열어본다.
  • 소장 작성 시 필요한 기재사항 체크리스트를 만든다.
  • 인지대·송달료를 미리 계산한다(GP-009 참조).
  • 관할법원이 올바른지 최종 확인한다(GP-008 참조).

2. 준비물

| 준비물 | 왜 필요한가 | 준비 상태 | |---|---|---| | 전자소송 사이트 접속 | 소장 양식 확인 | 미확인 | | 청구금액 계산서 | 청구취지 작성 기준 | 미확인 | | 사실관계 정리 노트 | 청구원인 작성 기초 | 미확인 | | 증거 자료 목록 | 입증방법·첨부서류 준비 | 미확인 |

3. 작성·제출물

| 문서 | 제출처 | 주의점 | |---|---|---| | 소장(최종본) | 법원(전자소송 또는 방문) | 모든 기재사항 누락 없이 작성 | | 인지 | 소장에 첨부 | 금액 확인 필수 | | 송달료 납부서 | 법원 | 피고 수만큼 예납 | | 증거서류 사본 | 소장에 첨부 | 원본은 별도 보관 |

4. 흔한 실수

  • 소장을 너무 간략하게 쓴다 — 청구원인에 사실관계를 충분히 적지 않으면 법원이 이해하지 못한다. 있던 사실을 빼먹지 말고 시간순으로 적어라.
  • 청구취지와 청구원인을 혼동한다 — 청구취지는 '무엇을 요구하는가'(결론), 청구원인은 '왜 요구하는가'(이유)다. 이 둘은 반드시 구분해서 써야 한다.
  • 첨부서류를 원본으로 내려 한다 — 법원에는 사본을 제출하고, 원본은 본인이 보관한다. 법원이 원본 대조를 요구할 때만 제시한다.
  • 서명날인을 빼먹는다 — 전자소송은 전자서명으로 대체되지만, 방문 제출 시에는 인감 또는 서명이 필요하다.

5. 변호사 상담 신호

위험도: 혼자 가능

  • 소장의 구조를 이해하는 것 자체는 혼자서 충분히 할 수 있다. 다만 아래 경우는 상담을 권장한다:
    • 청구취지와 청구원인을 어떻게 써야 할지 전혀 감이 잡히지 않는 경우
    • 이미 소장을 써봤지만 보정명령을 받은 경험이 있는 경우

6. 전자소송 연결

  • 전자소송 관련 카드: 추후 전자소송_미니가이드/EL03_소장작성.md 예정
  • 이 단계에서 확인할 메뉴: 전자소송 → 민사 → 소장작성 → 양식 확인

7. 근거 조문·판례

[근거·조문] 민사소송법 제249조(소장의 기재사항) — 소장에는 당사자, 법정대리인, 청구의 취지와 원인을 적어야 한다. 소장의 필수 기재사항을 규정한 가장 중요한 조문이다. 검증: 한국법 MCP 확인(2026-07-30)

[근거·조문] 민사소송법 제254조(재판장등의 소장심사권) — 재판장은 소장이 법정 요건을 갖추지 못한 경우 보정을 명할 수 있고, 보정되지 않으면 각하할 수 있다. 검증: 한국법 MCP 확인(2026-07-30)

[근거·조문] 민사소송법 제255조(소장부본의 송달) — 법원은 소장을 접수하면 지체 없이 피고에게 소장 부본을 송달해야 한다. 검증: 한국법 MCP 확인(2026-07-30)

[근거·조문] 민사소송 등 인지법 제13조(인지를 붙이지 아니한 경우의 효력) — 소장에 정해진 인지를 붙이지 않으면 접수가 보류되거나 각하될 수 있다. 다만 법원은 보정 기회를 준다. 검증: 한국법 MCP 확인(2026-07-30)
