조사 범위 설정과 조사팀 구성

3줄 요약

  • 조사 범위는 법무팀이 혼자 결정하는 순간 '의도'가 되고, 감사위원회와 함께 결정하는 순간 '절차'가 된다.
  • 제보 내용을 범위의 '천장'이 아닌 '바닥(출발점)'으로 삼고, 동일 패턴 발견 시 확대하는 재설정 조건을 명시하라.
  • 조사팀은 법무·감사·인사·정보보안으로 구성하고, 이해충돌이 있는 인원은 배제한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사전)

익명 제보(002) -> [범위 설정·팀 구성] -> 증거보전(004)

1. 이번 단계에서 반드시 할 일

  • [ ] 조사 목적과 범위를 문서화(제보 내용·기간·관련 부서·검토 대상 자료)
  • [ ] 감사위원회(이사회) 서면 승인 — 단독 결정 금지
  • [ ] 조사팀 구성 — 법무·감사·인사·정보보안 역할 분담
  • [ ] 이해충돌 점검 — 피조사자와 관계가 있는 인원 배제
  • [ ] 조사 범위 결정 의사록 작성 — 결정 근거·제외 사유·재설정 조건 명시

4. 흔한 실수

  • 경영진의 비공식 압박으로 범위 축소 — '고의 축소' 의혹
  • 제보 내용만 범위로 삼고 연관 거래나 패턴을 누락 — 추가 비위 발견 시 조사 부실 책임
  • 조사팀 단독 결정, 감사위원회 사후 보고 — 결정 책임이 법무팀에 집중

5. 전문가 상담 신호

위험도: 상담 권장

  • 피조사자가 임원급으로, 조사 독립성에 대한 외부 검증이 필요한 경우
  • 다부서·계열사가 연루된 복잡한 사안
