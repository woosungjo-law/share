1. 문제상황 — "확률형 아이템 확률을 공개하지 않으면 법적 문제가 될까?"

네, 법적 문제가 됩니다. 게임산업법 제33조 제2항은 확률형 아이템의 종류별 공급 확률정보를 게임물·인터넷 홈페이지·광고선전물마다 표시하도록 의무화하고 있습니다.

미표시·허위 표시 시 리스크 요약
▸ 행정제재: 시정명령 → 미이행 시 2년 이하 징역 또는 2천만 원 벌금
▸ 민사책임: 입증책임 게임사 전환 — 고의·과실 없음을 게임사가 입증해야 면책
▸ 징벌적 손해배상: 고의 위반 시 손해액의 3배 이내 배상
▸ 표시광고법 위반: 공정위 시정명령·과징금
▸ 전자상거래법 위반: 기만적 방법 금지 위반

3. 체크리스트 — 확률형 아이템 표시의무 이행

3.1 표시 내용

  • 확률형 아이템 유형별(캡슐형/강화형/합성형) 구분 표시
  • 모든 게임아이템의 종류·등급·성능별 공급 확률정보 (별표3의2 가~다목)
  • 백분율 표시 (소수점 반올림 기준 준수)
  • 한정 제공 시: 제공 총수 또는 기간 (별표3의2 라목)
  • 확률 변동 구조: 구매·사용·합성 진행에 따른 변경 내용 (마목)
  • 천장제도(확정 획득 조건) 존재 시 해당 조건 (바목)

3.2 표시 위치·매체

  • 게임물 내: 구매·조회·사용 화면에 직접 표시 (불가피 시 홈페이지 연결)
  • 인터넷 홈페이지: 문자열/숫자열 검색 가능 형태로 표시
  • 광고·선전물: 확률형 아이템 포함 사실 표시 (배너·크기 예외 있음)

3.3 변경 시 재고지

  • 확률 정보 변경 시 변경 내용 + 변경 시점을 사전 게시
  • 긴급 오류 수정 시: 사유 해소 후 지체 없이 게시
  • 변경 전후 비교 가능하도록 이력 관리
  • 게임물 내 + 홈페이지 동시 게시

3.4 내부 통제

  • 확률 설계·운영 내역 문서화 (확률 테이블, 버전별 변경 이력)
  • 확률 공지 이력 문서화 (공지 시점·매체·문안·게시 기간)
  • 표시내용 진위 여부 검토·보고 체계 수립
  • 정기적 내부 감사 절차
  • 실무자 교육·체크리스트 배포
  • 확률 오류·이상 징후 시 즉시 서비스 중단 또는 공지 프로토콜

3.5 사후 대응

  • 고의·과실 없음 입증 자료 사전 준비
  • 표시의무 위반 관련 문서 보관 정책
  • 사후 보상조치의 적정성·시의성 확보
  • 약관상 보상 기준 사전 명시
  • 집단 분쟁 대비 인과관계·가분성별 손해 산정 시나리오

4. 위험 신호 (Red Flags)

🚩 확률 미공개

6. FAQ

Q1. 확률 정보를 게임물 내에만 표시하고 홈페이지에는 표시하지 않아도 되나요? 아닙니다. 게임산업법 제33조 제2항은 게임물, 인터넷 홈페이지, 광고·선전물 각각에 표시하도록 요구합니다.
Q2. 중소기업도 표시의무가 있나요? 최근 3년간 연평균 매출액 1억 원 이하 영세기업은 면제됩니다. 면제 요건을 충족하지 못하는 중소기업은 의무 적용 대상입니다.
Q3. 확률 정보 변경 시 어떻게 해야 하나요? 변경 내용과 변경 시점을 사전에 게임물과 홈페이지에 게시해야 합니다. 긴급 오류 수정 시 사유 해소 후 지체 없이 게시합니다.
Q4. "랜덤"이라고만 표시해도 되나요? 아닙니다. 추상적 표시만으로 면책되지 않습니다. 실제 확률 구조를 백분율로 구체적으로 표시해야 합니다.
Q5. 실수로 잘못 표시했는데 책임을 면할 수 있나요? 행정제재는 고의·과실 불요이므로 면책이 어렵습니다. 징벌적 손해배상(3배)은 고의 위반 시에만 적용됩니다.
Q6. 확률형 아이템의 청약철회를 제한할 수 있나요? 단순 변심 청약철회 제한이 일정 조건에서 유효할 수 있으나, 전면 차단이나 미명시는 전자상거래법 위반이 될 수 있습니다.
Q7. 해외 게임사도 게임산업법을 준수해야 하나요? 국내 유통·제공 시 적용되나, 국내 대리인 부재 게임사에 대한 집행에 현실적 어려움이 있습니다. 국내대리인 지정제도(제31조의2) 도입으로 규제 사각지대 축소 중입니다.
