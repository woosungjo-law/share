휴대폰 요금·위약금이 예상과 다를 때 청구 근거를 대조할 때

적용 상황: 휴대폰 월 청구서나 해지·번호이동 관련 청구 금액이 가입 당시 안내와 다르게 보여 근거 자료를 모을 때

Must Know · 알아야 할 것

  • 월 청구서 한 장에는 월정액, 약정 할인, 부가서비스, 단말기 할부금, 해지 관련 일회성 금액이 함께 표시됩니다. 항목마다 근거가 되는 계약·가입 이력이 다르므로 한 번에 묶어 판단하지 않고 항목별로 대조합니다.
  • 이 카드는 청구 내역을 확인 가능한 자료로 정리하는 안내입니다. 위약금·할인반환금의 정당성, 면제 여부, 감액·환불 범위를 판단하지 않습니다.

Must Check · 확인할 것

  • 가입·약정 문서: 약정 기간, 할인 종류, 월 납부 구조
  • 최근 월별 요금 명세서와 실제 납부 내역
  • 부가서비스 가입·해지 이력과 가입 시점의 동의 흔적
  • 단말기 할부 조건과 잔여 회차
  • 해지·번호이동 신청일과 처리 결과 통지
  • 상담 기록: 일시, 채널, 담당자, 안내받은 내용

Must Do · 실행할 것

  1. 청구서를 월별로 모으고 월정액, 할인, 부가서비스, 단말기 할부금, 일회성 금액 열로 표를 만듭니다.
  2. 각 항목 옆에 근거 계약·가입 이력의 위치(문서명, 확인한 화면과 날짜)를 적습니다.
  3. 설명이 필요한 항목은 목록으로 만들어 산정 근거 자료를 서면이나 앱 문의로 요청하고 접수 번호를 남깁니다.
  4. 안내받은 내용은 안내받은 사실과 추가 확인 필요로 나눠 기록하고, 원본 자료와 다른 부분은 날짜·담당자와 함께 남깁니다.
  5. 해지·번호이동을 진행하기 전에 미납 금액, 잔여 할부, 일회성 금액 목록을 최신 상태로 다시 확인합니다.
잠깐 멈추고 검토할 때

금액 산정 기준, 면제 사유, 감액을 다투려는 경우에는 기록만으로 결론 내리지 말고 약관 원문과 현행 기준을 별도로 확인합니다. · 청구서·상담 기록에 주민등록번호, 전체 전화번호, 결제수단 정보가 포함되어 있으면 공유·게시 전에 가립니다.

원자료: 이동통신·스마트폰 요금·위약금 분쟁 독트린. 쟁점 목록만 상황 설정에 참고하고 법률 주장은 사용하지 않았습니다.
