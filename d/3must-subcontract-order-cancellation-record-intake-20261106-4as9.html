납품 발주가 취소됐을 때 주문·준비 자료를 묶어 검토할 때

적용 상황: 납품 발주가 취소됐을 때 주문·준비 자료를 묶어 검토할 때

Must Know · 알아야 할 것

  • 통지 내용과 원발주 조건, 이후 협의안을 구분합니다. 제안·확정·실행 상태를 기록만으로 단정하지 말고 확인된 문서에 연결합니다.
  • 준비 비용이나 손실이라고 미리 분류하지 않습니다. 실제 주문·취소 가능 여부·청구서·지급 기록과 미확인 항목을 따로 적습니다.
  • 이 카드는 사실·자료를 정리하는 절차입니다. 취소의 적법성, 권리, 손해배상 범위나 액수는 판단하지 않습니다.

Must Check · 확인할 것

자료 묶음확인할 내용기록할 상태
발주·변경 자료발주서, 사양, 수량, 납기, 변경·취소 통지원본 위치, 작성·수신일, 버전
협의 기록이메일, 회의록, 메신저, 통화 후 확인 기록발언 주체, 제안·확정 여부, 미확인 사실
생산 준비자재·외주 주문, 전용 설비, 인력 배치, 작업 일정주문일, 수량, 취소·전환 가능 여부
거래 자료세금계산서, 송장, 지급 내역, 반품·취소 확인실제 발생·지급 여부, 증빙 위치
진행 상태제작·검수·출고·납품 현황, 남은 재고기준일, 담당자, 다음 확인 항목

Must Do · 실행할 것

  1. 통지를 받은 날짜·경로·수신자와 통지 원문을 기록하고, 발주서와 당시 적용된 사양·수량·일정을 함께 묶습니다.
  2. 이후 변경·취소 관련 대화를 날짜순으로 배열하고, 제안·승인·실행·미확인 상태를 각각 표시합니다.
  3. 자재·외주·설비·인력·일정에 관해 실제로 한 준비를 항목별로 적고, 주문서·계약서·송장·지급 자료의 원본 위치를 연결합니다.
  4. 진행 중 작업, 남은 재고, 취소·전환 가능 여부를 현업 담당자에게 확인해 기준일과 답변자를 기록합니다.
  5. 자료가 없는 항목은 추정해 채우지 말고 ‘미확인’으로 남겨 관련 부서에 확인 요청합니다.
  6. 원본 파일을 덮어쓰지 않고 비교표와 자료목록을 만들어 계약·법무 담당자에게 전달합니다.
잠깐 멈추고 검토할 때

취소 통지 전후 문서의 수량·사양·납기가 서로 다르거나, 승인 여부가 확인되지 않을 때 · 생산·자재 자료와 청구서·지급 내역이 맞지 않을 때 · 계약 해석, 책임, 비용 회수 가능성 또는 대외 회신을 정해야 할 때
