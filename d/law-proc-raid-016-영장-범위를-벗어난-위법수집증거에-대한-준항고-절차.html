PROC-RAID-016 | 영장 범위를 벗어난 위법수집증거에 대한 준항고 절차

3줄 요약

  • 검사·사법경찰관의 압수처분에 불복이 있으면 관할법원에 준항고(준항고)로 취소·변경을 청구할 수 있음(형소법 제417조)
  • 준항고는 서면으로 제출하며, 불복대상 처분을 안 날부터 7일 이내 제기해야 함(즉시항고 기간 준용)
  • 준항고 자체에 집행정지 효력이 없으므로, 긴급한 경우 별도로 집행정지 신청을 병행해야 함

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후

015(압수물목록 확인·서명) -> [016] -> 017(가환부·환부청구)

1. 이번 단계에서 반드시 할 일

  • 위법수집증거를 특정한다: 영장 기재 압수대상물과 실제 압수물을 비교하여 영장 범위 초과분을 목록화
  • 준항고 기간(처분을 안 날부터 7일)를 계산하고 변호인에게 즉시 준항고장 작성을 의뢰
  • 위법성 입증 자료를 수집한다: 현장 사진·영상, 목록 사본, 영장 사본, 이의제기 사실 기록, 참여자 진술
  • 필요시 관할법원에 집행정지 신청서를 별도 제출

2. 준비물

준비물 왜 필요한가 준비 상태
영장 사본 영장 기재 범위와 실제 압수의 대비 — 위법성 판단의 기준자료 미확인
압수목록 사본 실제 압수물 내역 확정 — 영장 범위 초과분 특정 근거 미확인
현장 상황 기록(영상·사진·녹음) 위법 압수 경위·수사관 인식·이의제기 사실을 입증 미확인
법인 인감증명서·등기부등본 준항고인(법인)의 대표권한 증명 미확인

3. 작성·제출물

문서 제출처 주의점
준항고장(청구취지·청구이유) 관할법원(수사기관 직무집행지) 청구취지에 "압수처분 취소" 또는 "압수물 반환" 명확히 기재, 증거번호 별지로 첨부
증거자료 편철 관할법원 영장·목록·현장기록 등을 대비표로 정리하여 위법성 쉽게 파악되도록 구성
집행정지 신청서(선택) 관할법원 압수물이 업무필수인 경우 집행정지 필요성 구체적 소명

4. 흔한 실수

  • 준항고 기간(7일)을 처분일로부터 계산하는 오류: 형소법 제419조가 준용하는 제415조의 즉시항고 기간은 "처분을 안 날부터" 기산. 목록 교부가 지연되면 기간 개시 자체를 다툴 수 있음. 다만 기간 안에 행동하지 않으면 권리 소멸.
  • 준항고장에 주장만 있고 증거가 없음: 법원은 기계적 기각보다는 "증거소명 부족"으로 각하하는 경우가 많음. 영장·목록·현장기록을 대비표로 만들어 위법성이 시각적으로 드러나도록 편철해야 함.
  • 준항고와 증거배제신청(형소법 제308조의2)을 혼동함: 준항고는 압수처분 자체의 취소를 구하는 절차이고, 증거배제신청은 공판단계에서 증거능력을 다툼. 두 절차는 병행 가능하나 목적·시기·법원이 다름.

5. 전문가 상담 신호

위험도: 전문가 필요

  • 위법수집증거가 형사재판의 핵심증거가 될 것으로 예상되는 경우(예: 영장 범위를 넘어 압수한 회계자료로 탈세 수사)
  • 저장매체 전체 이미징 압수 시 영장 기재 범죄사실과 무관한 파일이 대량 포함된 경우
  • 준항고 기간(7일)이 임박하여 즉시 대응이 필요한 경우

6. 인접 절차 연결

  • 선행: (내사·수사) · 후속: 형사고소상품 피의자 트랙

7. 근거 조문·판례

근거 후보 의미 검증상태
형사소송법 제417조 검사·사법경찰관의 압수처분에 대한 준항고 — 불복 시 법원에 취소·변경 청구 가능 검증완료(L2)
형사소송법 제418조 준항고의 방식 — 서면으로 관할법원에 제출 검증완료(L2)
형사소송법 제419조 준용규정 — 제415조 즉시항고 기간(7일)이 준항고에 준용 검증완료(L2)
형사소송법 제308조의2 위법수집증거 배제 — 공판단계 증거능력 부정(준항고와 별도 절차) 검증완료(L2)
