해외 법률자문을 맡기기 전 업무범위와 견적을 비교할 때

적용 상황: 해외 법률 업무가 생겨 외부 로펌이나 현지 자문 후보에게 제안과 예산을 요청하기 전에, 내부 요청을 비교 가능한 기준으로 정리할 때 사용한다.

Must Know · 알아야 할 것

  • 후보의 명성이나 시간당 단가 하나만으로 선택하지 않는다. 필요한 결과물, 담당 인력, 업무 범위, 예상 비용과 일정이 서로 같은 기준으로 비교되는지 먼저 확인한다.
  • 이 카드는 외국법상 자격·업무범위, 변호사 선임의 법적 요건, 특권·비밀보호, 이해충돌의 법적 효과 또는 특정 후보의 적합성을 판단하지 않는다.

Must Check · 확인할 것

  • 요청 목적, 관련 국가·분야, 의사결정 시점, 필요한 결과물이 한 장의 요청 개요에 정리돼 있는가?
  • 후보별 제안에 포함되는 일과 제외되는 일, 산출물, 담당 파트너·실무자, 예상 일정이 구분돼 있는가?
  • 비용 기준·통화·가정·추가업무 처리 방식이 같은 비교표에 기록돼 있는가? 불확실한 금액은 확정 견적처럼 취급하지 않았는가?
  • 후보에게 이해충돌 확인을 요청하고, 확인 완료 여부와 남은 질문을 기록했는가?
  • 예산 초과·업무범위 변경·추가 국가 투입 때 누구의 사전 승인을 받을지 정했는가?
  • 견적에 포함된 업무가 기존 사내 담당자 또는 다른 자문기관의 역할과 겹치지 않는가?

Must Do · 실행할 것

  1. 요청 부서와 짧은 착수 면담을 해 목적, 결정 시점, 대상 국가·사업, 필요한 결과물, 이미 확보한 자료를 정리한다.
  2. 모든 후보에게 같은 요청 개요와 답변 형식을 전달한다. 확인이 필요한 질문은 별도 목록으로 두고 후보마다 동일하게 묻는다.
  3. 제안서를 업무범위·제외사항 / 산출물 / 담당 인력 / 일정 / 비용 가정 / 추가업무 승인 항목으로 나눈 비교표에 옮긴다. 통화나 산정 방식이 다르면 그대로 표시해 단순 합산을 피한다.
  4. 이해충돌 확인, 보안·자료 전달 방식, 내부 예산 담당자 의견을 각각 기록한다. 확인되지 않은 항목은 완료로 표시하지 않는다.
  5. 선택 이유와 남은 불확실성, 승인자, 다음 조치를 짧게 결재 메모에 남기고, 착수 후 범위·예산 변경이 생기면 같은 기록에 갱신한다.
