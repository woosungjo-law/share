대관업무 자가진단 — 지금 내 기업에 필요한 대관 액션은?

각 질문에 예/아니오로 답하며 분기를 따라가세요. 이 진단은 일반 정보이며 자문이 아닙니다.

Q1. 현재 기업이 인허가·승인을 받아야 하는 상황인가요, 아니면 규제기관의 조사·처분에 대응 중인가요?

- 인허가·승인이 필요 (신규 사업·공장 증설·면허 갱신 등) → Q2

- 조사·처분에 대응 중 (행정조사 통보·과징금 예고·영업정지 등) → Q4

Q2. 사업 일정이 촉박한가요 (3개월 이내에 인허가 필요)?

- 예 → 사전협의·사전컨설팅부터 시작 → PROC-GOVR-005(사전컨설팅·사전협의 활용) → Q3

- 아니오 → 정식 신청 전 요건·결격사유 점검 먼저 → PROC-GOVR-003(인허가 요건·결격사유 사전점검)

Q3. 소관 기관·근거법령이 명확한가요?

- 예 → 신청 준비 → PROC-GOVR-008(인허가 신청서·첨부서류 접수)로

- 아니오/여러 부처 관련 → PROC-GOVR-001(규제·인허가 지형 파악)부터

Q4. 사전통지(처분 예고)를 받았나요?

- 예 → 처분 유형에 따라 대응 (Q5)

- 아니오, 아직 조사 단계 → PROC-GOVR-010(행정조사·현장조사 초동대응)으로

Q5. 어떤 유형의 처분이 예고되었나요?

- 과징금·과태료 → PROC-GOVR-016(과징금·과태료 소명서 작성)으로

- 영업정지·허가취소 → PROC-GOVR-017(행정처분 사전통지 대응)으로

- 시정명령 → PROC-GOVR-018(협상·시정조치 제안)으로

Q6. 처분이 이미 내려졌나요?

- 예 → PROC-GOVR-020(처분 결과 확인과 효과 분석) → 불복 여부 결정

- 아니오 → 현재 단계에 맞는 사전·대응 카드 계속 진행

결과 안내

- 인허가 경로: 사전 요건 점검 → 사전협의 → 신청 → 보완대응 → 결과 확인 → 사후관리

- 처분 대응 경로: 조사 대응 → 사전통지 대응 → 의견제출 → 처분 결과 → 불복·재신청
