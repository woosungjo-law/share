3MUST · 회사법

사업부문을 떼어내 별도 법인으로 만들려 할 때

적용 상황: 인적분할·물적분할로 사업부문을 별도 법인으로 옮기려 하거나, 이미 작성된 분할계획서를 최종 점검해야 할 때 사용합니다.

Must Know · 알아야 할 것

  • 회사분할은 분할계획서 → 주주 보호 → 채권자 보호 → 근로관계 승계 네 단계로 진행됩니다. 순서를 바꾸면 나중에 되돌리기 어렵습니다.
  • 분할계획서에는 이전할 재산과 가액, 자본과 주식 배정, 채무 분담이 구체적으로 들어가야 합니다. "각자 부담한다"는 한 줄로는 부족합니다.
  • 분할 후 회사들은 원칙적으로 분할 전 채무에 대해 연대하여 변제할 책임을 집니다. 이 책임을 배제하려면 채권자 보호 절차를 제대로 밟아야 합니다.
  • 채권자 보호는 공고와 개별 통지가 함께 필요합니다. 공고만 하고 알고 있는 채권자에게 통지하지 않으면 배제가 되지 않습니다.
  • 반대주주에게는 주식매수청구권이 있고, 행사 기간·가격 산정·대금 지급 절차를 안내해야 합니다.
  • 분할되는 사업부문 근로자의 고용관계는 원칙적으로 신설회사에 승계됩니다. 근로자 의사와 무관하게 진행되므로 목록과 승계 방안을 미리 만들어야 합니다.

Must Check · 확인할 것

  • 분할 방식(인적분할·물적분할)과 그 선택 이유
  • 분할계획서의 이전 재산·가액·채무 분담·주식 배정 기재
  • 이사회 결의와 주주총회 승인 일정
  • 반대주주 현황과 주식매수청구권 안내 계획
  • 채권자 목록(금액·만기·담보 유무)
  • 공고 방법과 매체, 개별 통지 대상과 발송 방법
  • 이의제출 기간 설정과 접수 창구
  • 분할 대상 부문 근로자 목록과 승계 방안
  • 존속·신설 회사의 상호·목적·자본금 정관 반영

Must Do · 실행할 것

  1. 분할계획서를 네 구역으로 나눠 점검표를 만듭니다. 각 구역에 '완료 / 미비 / 해당 없음'을 표시합니다.
  2. 채무 분담 조항을 항목별로 다시 씁니다. 어느 회사가 어떤 채무를 얼마나 부담하는지 숫자로 적습니다.
  3. 채권자 목록을 만들고, 연대책임 배제가 필요한 채권자를 표시합니다. 배제 대상이면 공고와 개별 통지를 모두 계획에 넣습니다.
  4. 공고문과 개별 통지문을 준비합니다. 이의제출 기간, 접수 방법, 기간 내 이의가 없을 때의 효과를 명시합니다.
  5. 개별 통지는 발송 증빙(등기·내용증명 접수증)을 남깁니다. 발송일과 도달일을 기록합니다.
  6. 반대주주 안내문을 준비하고, 행사 기간과 절차를 공지합니다.
  7. 분할 대상 근로자 목록을 만들고 승계 방안·설명 계획을 세웁니다.
  8. 정관 변경 사항을 반영하고 등기 일정을 확정합니다.
잠깐 멈추고 검토할 때

채권자 보호 절차를 이미 건너뛴 채 주총 승인이 끝났을 때 · 알고 있는 채권자에게 개별 통지를 하지 않은 사실을 발견했을 때 · 분할 대상에 담보 제공된 자산이 포함되어 있을 때 · 반대주주가 상당수여서 매수대금 부담이 커질 때 · 분할 대상 부문에 노동조합이 있거나 단체협약이 적용될 때
