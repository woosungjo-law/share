펀드·ELS 권유 분쟁이 생겼을 때 설명 기록을 점검할 때

적용 상황: 투자상품 가입자가 위험 설명 부족을 주장하거나 금융기관이 권유 과정의 기록을 찾아야 하는 준법·법무팀

Must Know · 알아야 할 것

  • 투자상품 분쟁은 서명 한 장보다 실제로 어떤 자료를 언제 제공하고 어떤 설명·확인을 했는지가 핵심 기록이 된다.
  • 설명 기록과 투자자 적합성 자료는 별도 장부로 모으고, 판매사·운용사·수탁사 등 역할을 나눠 책임 검토가 가능하게 한다.

Must Check · 확인할 것

  • 상품설명서·위험고지·수수료·환매·손실 관련 자료의 버전을 확보한다.
  • 설명 녹취·해피콜·자필·전자 확인과 자료 교부 시각을 대조한다.
  • 투자 목적·재산 상태·경험 등 투자자 정보와 적합성 평가 기록을 확인한다.
  • 펀드 구조의 각 참여자와 권유·설명·운용·수탁 역할을 표시한다.
  • 민원·분쟁조정·소송 기한과 대응 창구를 기록한다.

Must Do · 실행할 것

  1. 가입 시점 기준으로 상품자료와 녹취를 원본 보존하고 버전을 고정한다.
  2. 무엇을 설명했는가/무엇을 확인했는가/누가 했는가 대조표를 만든다.
  3. 투자자 주장과 내부 기록의 일치·불일치 지점을 표시한다.
  4. 책임 주체와 대응 경로를 법무·준법 공동 검토로 넘기고 사실확인 전 결론을 외부에 통지하지 않는다.
