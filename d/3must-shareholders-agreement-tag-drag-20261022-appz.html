주주간계약의 동반매도·강제매도 조항을 검토할 때

적용 상황: 투자 유치·M&A를 앞두고 주주간계약을 검토하면서, 소수주주가 함께 팔 수 있는지(태그)와 최대주주가 반대주주까지 끌고 갈 수 있는지(드래그)를 확인해야 할 때 사용합니다.

Must Know · 알아야 할 것

  • 두 조항은 한 쌍입니다. 최대주주는 강제매도(드래그얼롱)로 딜을 성사시키고, 소수주주는 동반매도(태그얼롱)로 같은 조건에 함께 나갑니다.
  • 한쪽만 있으면 균형이 깨집니다. 동반매도만 있으면 매수자가 전체 지분 확보를 조건으로 걸 때 딜이 막히고, 강제매도만 있으면 소수주주가 조건 협상 없이 밀려납니다.
  • 발동 요건이 '이사회 결의'만으로 되어 있으면 지분 동의 요건이 없는 것과 같아, 실제 매각 국면에서 해석 다툼이 생깁니다.
  • '동등 조건'은 문구로 정의되어야 작동합니다. 가격만 같고 대금 지급 시기·조건이 다르면 소수주주에게 불리합니다.
  • 위반 시 효과(손해배상·강제이행)가 없으면 조항은 선언에 그칩니다.

Must Check · 확인할 것

  • 주주간계약에 두 조항이 모두 있는지
  • 드래그얼롱 발동 요건(지분율 기준·동의 주체·이사회 결의 여부)
  • 태그얼롱 조건이 최대주주와 동등한지(가격·대금 지급 시기·조건)
  • 적용 대상 거래 유형(지분 매각·합병·영업양도 등)의 정의
  • 예외 사유(반대주주의 주식매수청구권 행사 등)
  • 위반 시 효과와 이행 강제 수단
  • 정관·주주총회 결의 요건과의 관계
  • 행사 통지 기한과 방식

Must Do · 실행할 것

  1. 두 조항 원문을 표로 옮기고 요건·조건·예외·효과 네 칸을 채웁니다. 빈 칸이 곧 보완 지점입니다.
  2. 어느 쪽에 유리하게 기울어져 있는지 진단하고, 협상 카드로 정리합니다.
  3. 드래그얼롱 발동 요건을 지분율 기준으로 명확히 하는 수정안을 만듭니다.
  4. 태그얼롱에 '동등 조건'의 정의(가격·대금 지급 방식·조건)를 넣습니다.
  5. 예외 사유와 위반 시 효과 조항을 보완합니다.
  6. 매각을 추진하기 전 주주명부·지분율과 조항 요건을 대조해 실제 발동 가능성을 확인합니다.
