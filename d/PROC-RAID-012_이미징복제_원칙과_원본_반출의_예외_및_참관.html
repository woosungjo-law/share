PROC-RAID-012 | 이미징(복제) 원칙과 원본 반출의 예외 및 참관

3줄 요약

- 디지털 증거는 원본 저장매체 대신 '이미징(복제본)'을 압수하는 것이 원칙이며, 원본 반출은 기술적 곤란·데이터 대량·위변조 우려 등 예외적 사유가 필요하다

- 수사관이 이미징을 수행할 때는 쓰기차단기(Write Blocker) 사용 여부와 해시값(SHA-256 등) 산출 과정을 반드시 확인·기록해야 한다

- 이미징 완료 후 원본 저장매체는 즉시 반환되어야 하며, 이미징 복제본이 압수된 경우에도 참관권과 영장 범위 심사는 동일하게 적용된다

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


[011] 디지털 포렌식 대응 -> [012] 이미징·원본반출 -> [013] 진술거부권·임의조사

1. 이번 단계에서 반드시 할 일

- [ ] 수사관이 사용하는 포렌식 장비에 쓰기차단기(Write Blocker)가 연결되어 있는지 육안으로 확인하고, 미연결 시 즉시 지적한다

- [ ] 이미징 시작 전 원본 저장매체의 해시값(SHA-256 또는 MD5)을 산출·기록하고, 이미징 완료 후 복제본의 해시값과 일치하는지 대조 확인한다

- [ ] 이미징 대상 데이터의 범위(전체 파티션/특정 폴더)가 영장 기재 범위와 일치하는지 확인한다

- [ ] 원본 저장매체 반출이 예정된 경우, "형소법 제106조 제3항 단서에 해당하는 예외 사유가 무엇인지 구체적으로 설명해 달라"고 요청하고, 사유를 기록한다

- [ ] 이미징 완료 직후 원본 저장매체의 반환을 요구하고, 반환 시각·매체 상태를 기록한다

- [ ] 이미징 과정 전체를 녹화하고, 중단·재시작이 발생한 경우 그 시점과 사유를 별도 기록한다

- [ ] 수사관이 이미징 복제본을 분석용 노트북으로 가져가려 할 때 "압수된 복제본도 영장 범위 내에서만 분석 가능하다"는 점을 상기시킨다

2. 준비물

3. 작성·제출물

4. 흔한 실수

- "이미징은 기술적인 거니까 믿고 맡긴다"며 과정을 지켜보지 않음: 쓰기차단기 미사용 시 원본 저장매체의 데이터가 변경(modify time·메타데이터)될 수 있고, 위법 이미징은 증거능력 다툼의 대상이 될 수 있음. 반드시 참관해야 함

- 원본 저장매체를 반환받지 않고 수사관이 가져가도록 방치: 원본 반출이 예외 원칙인데도 아무 이의 없이 반출을 허용하면, 추후 '원본 반출 동의'로 해석될 여지가 있음. 현장에서 반환 요청을 하고 불응 시 즉시 이의제기

- 이미징 완료 후 복제본만 압수되었는데 "원본은 그대로 있으니 문제없다"고 안심: 복제본에는 동일한 데이터가 포함되어 있고, 수사팀이 복제본 전체를 분석·열람할 권한을 가지게 됨. 영장 범위를 벗어난 데이터가 포함되었는지는 별도로 확인해야 함

- 서버 이미징 시 회사 IT 담당자가 직접 이미징 명령어를 입력: 수사관의 요청이라도 자발적 이미징은 '임의제출'로 평가될 가능성이 있음. 수사관 자체 장비와 절차로 수행하도록 해야 함

5. 전문가 상담 신호

위험도: 상담 권장

- 수사관이 '영장에 저장매체 반출이 명시되었다'며 원본 반출을 고집하고, 구체적 예외 사유를 설명하지 않는 경우 → 영장 기재의 적법성·구체성에 대한 법리 검토 필요

- 기업이 DRM·암호화 솔루션을 사용 중이어서 수사관의 일반 이미징 도구로 복제가 불가능한 경우 → 기업이 복호화 키 제공을 거부할 권리(진술거부권과의 관계) 및 기술적 대안 검토

- 이미징 대상이 20TB 이상의 대규모 NAS·스토리지인 경우 → 이미징 자체가 현실적으로 불가능할 수 있으며, 선별적 복제·키워드 기반 수색 등 대안 협의가 필요

6. 인접 절차 연결

- 선행: PROC-RAID-011 (디지털 포렌식 대응) · 후속: PROC-RAID-013 (진술거부권·임의조사)
