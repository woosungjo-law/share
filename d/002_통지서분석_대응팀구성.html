통지서 분석·대응팀 구성

3줄 요약

- 통지서를 받은 즉시 조사 유형·세목·기간·일정을 분석하고 초동 대응팀을 꾸려야 한다.

- 대응팀은 법무총괄·세무전담·회계전담·법률전담·자료관리·기록보고 등 6개 역할로 구성한다.

- 외부 세무사·회계사·변호사 선임은 팀 구성과 동시에 진행한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


조사 유형·범위 파악(001) -> [통지서 분석·팀 구성] -> 외부 전문가 선임(003)

1. 이번 단계에서 반드시 할 일

- [ ] 통지서 내용 분석(유형·세목·기간·일정·요구자료·담당관)

- [ ] 대응팀 6개 역할별 담당자 지정

- [ ] 비상연락망 구축·단체 대화방 개설

- [ ] 외부 전문가(세무사·회계사·변호사) 연락·선임 착수

- [ ] 전사 자료 보존 명령 공지

4. 흔한 실수

- 통지서 분석 없이 무작정 세무사에 전달 — 경영진이 조사 전반을 파악하지 못함

- 대응팀 구성 지연 — 조사 시작 후 혼선·대응 누락 발생

- 자료 보존 명령 누락 — 직원이 관련 자료 삭제·변경해 조세범처벌법 위험

5. 전문가 상담 신호

위험도: 혼자 가능

- 단, 통지서에 범칙조사 혐의가 있으면 즉시 형사 변호사 선임(003 카드)
