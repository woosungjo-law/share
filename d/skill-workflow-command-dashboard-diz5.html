운영 원칙

계층역할정리 기준
COMMANDS자연어·슬래시 명령을 정본으로 보내는 라우터트리거, owner, canonical, 첫 동작만 남긴다.
WORKFLOWS실제 실행 절차, 파이프라인, 체크리스트의 정본상세 절차는 여기 또는 각 WIKI 정본 문서에 둔다.
SKILLS툴이 언제 어떤 능력을 켜야 하는지 알려주는 카드긴 절차를 복붙하지 않고 canonical workflow를 가리킨다.

2026-07-14 정리 결과: 웹게시와 법률-문제해결은 포인터화했고, 사례형 법률컬럼 옛 파이프라인은 신규 실행 중지(deprecated)로 고정했다.
