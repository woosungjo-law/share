임원보수한도 주총 승인: '정관상 한도'와 '실제 지급' 사이의 간극 해소

SECTION

3줄 요약 (TL;DR)

  • 상법 제388조: 이사 보수는 정관에 액수를 정하거나 주주총회 결의로 한도를 정해야 한다. 한도를 초과한 지급은 무효이며, 반환 청구 대상이 될 수 있다(대법원 2018다290436).
  • 핵심 간극 3가지: ①정관·주총이 정한 '총액 한도'와 이사회가 분배한 '개별 실제 지급액' 사이의 괴리, ②보수항목(급여·상여·퇴직금)별 한도 설정 누락, ③퇴직금·스톡옵션의 보수 해당 여부 불명확성
  • 2025년 두 대법원 판결이 간극을 좁혔다: 2025다214605(포괄 위임 금지→이사회 개별 분배 결의 필수), 2025다219931(주주인 이사 보수 한도 안건 의결권 제한). 법무팀은 정관·내규·주총 결의를 이 기준에 맞춰 전면 정비해야 한다.
SECTION

1. '정관상 한도'와 '실제 지급' 사이의 간극

한눈에: 상법 제388조는 이사 보수를 정관 또는 주주총회가 결정하도록 강행규정으로 정한다. 그러나 실무에서는 정관이나 주총이 '총액 한도'만 정하고, 이사회나 대표이사가 개별 보수를 결정하는 방식이 관행화되어 있다. 이 '간극'이 최근 대법원 판결로 위법 리스크에 노출되었다.

1.1 보수 결정 3층 체계

층위 결정 주체 결정 사항 실무 현실 리스크
1층 정관 보수액 직접 명시 (드문 경우) "임원급여지급규정에 따른다"는 포괄 위임 ❌ 포괄 위임 무효
2층 주주총회 보수 총액·한도액 승인 총액만 승인, 항목별 구분 없음 ⚠️ 퇴직금 등 누락
3층 이사회 개별 이사 배분 결정 대표이사에게 사실상 위임 ❌ 위임 범위 위반

[근거·조문] 상법 제388조(이사의 보수) — 이사의 보수는 정관에 그 액을 정하지 아니한 때에는 주주총회의 결의로 이를 정한다. 내부 WIKI 검증 (D-이사보수결정_위임한계, canonical) + MCP FOUND (MST 284143)

1.2 보수 개념의 범위 — '급여'만이 아니다

대법원은 보수의 개념을 넓게 해석한다. 단순히 급여뿐만 아니라 직무수행의 대가로 지급되는 모든 금전이 보수에 포함된다.

항목 보수 해당 여부 근거
급여 ✅ 당연히 보수 —
상여·성과급 ✅ 보수 실적 연동 여부 불문
퇴직금 ✅ 보수(2019다296617) 주총 승인 없이 지급 시 무효
스톡옵션(행사이익) ✅ 보수로 보는 견해 다수 부여 시 주총 승인 필요
주택자금 대여 ❌ 업무 무관 시 보수 아님 가지급금으로 처리
법인카드 사적 사용 ❌ 보수 아님 (횡령 문제) 별도 문제

[근거·판례] 대법원 2019. 12. 27. 선고 2019다296617 판결 — 퇴직금도 이사 보수에 포함되므로, 주주총회 결의 없이 퇴직금 지급 기준을 정하거나 지급하는 것은 무효 내부 WIKI 검증 (D-이사보수논란회사가, canonical)

2. 간극 ① — 한도 설정의 문제

한눈에: 주총이 '보수 총액 50억 원'이라는 포괄적 한도만 정하고, 항목별·이사별 구분 없이 운용하면 실질적 통제가 불가능하다. 2025다214605는 이사회가 개별 이사의 보수를 구체적으로 분배하는 결의를 해야 한다고 명시했다.

2.1 문제되는 관행

관행 내용 리스크
포괄 한도 설정 "임원 보수 총액 50억 원 이내"만 정함 개별 이사 과다 보수 통제 불가
대표이사 위임 이사회 결의 없이 대표이사가 개별 보수 결정 2025다214605로 전면 금지
임원급여지급규정 위임 정관이 '임원급여지급규정에 따른다'고만 규정 포괄 위임으로 무효
항목별 구분 없음 급여·상여·퇴직금을 하나의 한도로 통합 퇴직금 과다 지급 리스크
비등기 임원과 혼합 등기·비등기 임원 보수를 혼합하여 한도 설정 등기이사 한도가 비준수될 위험

2.2 적법 한도 설정 방법 (2025다214605 기준)

[근거·판례] 대법원 2025. 12. 11. 선고 2025다214605 판결 — 정관 또는 주주총회에서 임원의 보수 총액 내지 한도액만을 정하고 개별 이사에 대한 지급액 등 구체적인 사항을 이사회에 위임하는 것은 가능하지만, 이사의 보수에 관한 사항을 이사회에 포괄적으로 위임하거나 대표이사에게 직접 위임하는 것은 허용되지 않는다. 내부 WIKI 검증 (D-이사보수결정_위임한계, canonical)

표준 주총 결의안 예시:

제X호 의안: 이사 보수 한도 승인의 건

당기 정기주주총회는 이사의 보수 한도를 다음과 같이 정한다.

  1. 총액 한도: 이사 전원의 보수 총액은 50억 원(퇴직금 포함)을 초과하지 아니한다.
  2. 항목별 한도: 급여 30억 원, 상여금 15억 원, 퇴직금 5억 원
  3. 개별 분배: 개별 이사에 대한 구체적 보수 분배는 이사회 결의로 정하되, 각 이사의 직책·책임·성과를 반영하여 합리적으로 산정한다.
  4. 사후 보고: 집행 결과를 차기 정기주주총회에 보고한다.

2.3 실무 정비 체크리스트

  • [ ] 정관이 대표이사에게 보수 결정을 위임하고 있는지 확인 → 개정 필요
  • [ ] 주총 보수 한도 결의가 '총액'만 있고 항목별 구분이 없는지 확인 → 개선
  • [ ] 퇴직금 지급 기준이 주총 승인을 받았는지 확인 → 미승인 시 정비
  • [ ] 이사회 결의로 각 이사의 개별 보수액을 결정하고 있는지 확인
  • [ ] 결의록에 개별 보수 분배의 기준과 근거가 명시되어 있는지 확인

3. 간극 ② — 주주인 이사의 의결권 제한

한눈에: 대법원 2025다219931은 주주인 이사가 이사 보수 한도 안건에서 특별이해관계인으로서 의결권을 행사할 수 없다고 판시했다. 이는 대주주가 이사를 겸하는 가족기업·중견기업에 특히 중요한 변화다.

3.1 적용 요건

요건 내용
지위 요건 의결권 행사자가 주주인 동시에 이사일 것
안건 요건 이사 보수 한도액을 정하는 안건일 것 (개별 보수뿐 아니라 전체 한도도 포함)
이해관계 보수 한도가 해당 이사의 장래 보수에 영향을 미칠 수 있을 것
효과 해당 주주의 의결권 행사 불가 + 정족수 산정 시 발행주식총수에서 제외
예외 1인 주주 겸 대표이사 등 주총 성립 불가능한 경우

[근거·조례] 대법원 2026. 4. 2. 선고 2025다219931 판결 — "보수한도액은 향후 개별 이사에 대한 구체적인 보수액을 결정하는 데 중요한 영향을 미칠 수밖에 없다"며 주주인 이사는 보수한도액 결의에서 의결권을 행사할 수 없다고 명시 내부 WIKI 검증

3.2 실무 영향

상황 기존 관행 변경 후
대주주 겸 이사가 주총 보수 한도 투표 가능 ❌ 불가
소수주주만으로 정족수 충족 판단 대주주 포함 산정 ❌ 대주주 주식 제외 후 산정
보수 한도 인상 안건 통과 요건 용이 ❌ 까다로워짐
1인 주주 겸 대표이사 — ✅ 예외 인정 (회사 운영 마비 방지)

3.3 대응 방안

  • 공격 측(소수주주): 대주주 겸 이사가 보수 한도 안건에 참여했다면 결의 취소 소송(상법 제376조, 결의일 2개월) 제기 가능
  • 방어 측(회사): ①보수 한도 결의 시 주주인 이사는 의결권 행사 자제 ②의사록에 기권 사실과 정족수 계산 근거 명시 ③소규모 회사 특례(자본금 10억 미만, 제388조 단서) 검토

4. 간극 해소를 위한 법무팀 5대 액션 플랜

한눈에: 아래 5개 액션을 순서대로 실행하면 정관상 한도와 실제 지급 사이의 간극을 90% 해소할 수 있다. 2025년 두 대법원 판결을 반영한 전면 정비가 필요하다.

ACTION 1: 정관 진단 및 개정 (긴급)

  • [ ] 정관에 "임원급여지급규정에 따라 대표이사가 결정" 조항 있는지 확인 → 즉시 개정
  • [ ] 정관에 보수 결정 위임 범위를 "주총 한도 내 이사회 결의로 분배" 로 한정
  • [ ] 퇴직금 지급 기준을 정관 또는 주총 결의 사항으로 명시

ACTION 2: 주총 결의 정비

  • [ ] 보수 한도 결의 시 총액뿐 아니라 항목별(급여·상여·퇴직금) 한도 설정
  • [ ] 주주인 이사는 보수 한도 안건에서 의결권 배제 (2025다219931)
  • [ ] 의사록에 의결권 배제 근거·정족수 계산·분배 기준 명확히 기재

ACTION 3: 이사회 결의 내실화

  • [ ] 주총 한도 내 개별 이사별 보수액 구체적 배분 결의 (2025다214605)
  • [ ] 결의록에 배분 기준(직책·책임·성과)과 근거 명시
  • [ ] 포괄 위임 금지 — 대표이사 개인 판단으로 보수 결정 금지

ACTION 4: 보수위원회 활용

  • [ ] 상장사: 보수위원회 설치(기관투자자 평가·의결권 자문사 대응)
  • [ ] 중견기업: 보수위원회 권장 (독립성·투명성 확보)
  • [ ] ISO 30414 인센티브 기준 등 객관적 보수 기준 도입 검토

ACTION 5: 사후 관리

  • [ ] 보수 집행 결과를 차기 주총에 보고 (투명성 확보)
  • [ ] 공시 의무 확인(상장사: 임원보수 공시, 자본시장법 제159조)
  • [ ] D&O 보험 가입 범위와 보수 정책의 정합성 확인

자주 묻는 질문 (Q&A)

Q1. 정관이나 주총 결의 없이 이사회 결의만으로 지급한 보수는 어떻게 되나요? 무효입니다. 상법 제388조는 강행규정으로, 이사회 결의만으로 이사 보수를 지급하는 것은 위법입니다(대법원 2018다290436). 회사는 해당 이사에게 이미 지급한 보수를 부당이득으로 반환 청구할 수 있습니다(서울동부지법 2023가합102999). 개별 이사 입장에서는 보수 청구권 자체가 발생하지 않으므로, 사전에 정관 또는 주총 결의를 통해 보수 지급 근거를 마련해야 합니다.

Q2. 퇴직금도 주총 승인이 필요한가요? 네, 필요합니다. 대법원 2019다296617은 퇴직금도 이사 보수에 포함된다고 판시했습니다. 따라서 퇴직금 지급 기준과 한도도 주주총회 승인을 받아야 합니다. 퇴직금만 별도의 주총 결의 없이 관행적으로 지급해 온 회사는 즉시 정비가 필요합니다.

Q3. 대표이사가 정관·주총 결의 없이 자신의 보수를 결정해도 되나요? 안 됩니다. 상법 제388조는 이사 스스로 보수를 결정하는 것을 금지합니다. 대표이사도 '이사'이므로 자신의 보수는 주총(또는 정관)이 정해야 합니다. 2025다214605는 대표이사에게 보수 결정권을 위임하는 정관 규정도 무효라고 명시했습니다.

Q4. 비등기 임원의 보수도 주총 승인이 필요한가요? 필요하지 않습니다. 상법 제388조는 '이사'(등기임원)의 보수에 적용되므로, 비등기 임원(미등기 임원)의 보수는 주총 결의 대상이 아닙니다. 다만 비등기 임원에 과도한 보수를 지급하여 등기이사 보수 한도를 우회하는 행위(예: 이사를 비등기로 전환 후 고액 보수)는 상법 제388조 취지를 잠탈하는 것으로 무효 가능성이 있으므로 주의해야 합니다.

Q5. 2025다219931 판결 이후 보수 한도 결의는 어떻게 진행해야 하나요? 주주인 이사는 보수 한도 안건에서 의결권을 행사할 수 없습니다. 따라서 ①주총 소집 전 주주인 이사 명단을 확정하고, ②해당 이사의 주식 수를 발행주식총수에서 제외한 후 정족수를 산정하며, ③의사록에 의결권 배제 사실과 정족수 계산 근거를 명확히 기재해야 합니다. 1인 주주 겸 대표이사인 경우 예외가 인정될 수 있으나, 법률 자문을 받는 것이 안전합니다.
