이 업무를 로펌에 맡길까 — 비용·기밀·전문성으로 점수 매겨 정하는 법

적용 상황: 이 업무를 로펌에 맡길까 — 비용·기밀·전문성으로 점수 매겨 정하는 법

Must Know · 알아야 할 것

  • 판단 기준은 세 가지입니다. 비용(내부 처리 시간당 기회비용 대 로펌 시간당 요금), 기밀(외부 공개 시 리스크 수준), 전문성(내부 보유 역량 대 필요 역량). 각 1~5점으로 매기고 비중은 비용 40%, 기밀 30%, 전문성 30%를 적용합니다.
  • 합산 점수의 의미는 이렇게 나눕니다. 4.0 이상은 적극 위임, 3.0~3.9는 부분 위임, 2.0~2.9는 내부 처리 우선, 2.0 미만은 반드시 내부 처리입니다.
  • 점수보다 먼저 걸리는 업무가 있습니다. 사내 조사처럼 기밀과 독립성 때문에 외부에 맡기면 목적 자체가 훼손되는 일, 소송 수행처럼 변호인 선임이 필요한 일, 특허·상표 출원처럼 자격이 필요한 일은 점수와 무관하게 결론이 정해집니다.
  • 기밀 점수는 "지금 공개되면 얼마나 곤란한가"로 매깁니다. 위임 자체가 NDA 체결과 자료 범위 축소를 전제로 한다는 점을 점수에 반영해야 합니다.
  • 이 카드는 위임 여부를 정하는 절차입니다. 선임이 필요한지 자체를 유형별로 판단하는 기준은 「로펌 선임이 필요한가 — 유형별 필요성 판단과 내부 대응 가능성」 카드를 먼저 봅니다.

Must Check · 확인할 것

  • 업무 유형을 특정했는가(계약 검토·M&A 실사·소송·규제 대응·출원·노동 자문·해외 리서치 등)
  • 내부 처리 시 실제 투입 시간과 그 시간의 기회비용을 계산했는가
  • 로펌 견적을 최소 2곳 이상 받아 시간당·총액으로 비교했는가
  • 이 업무가 외부에 나갈 때 공개되는 자료 범위를 특정했는가
  • 내부에 해당 전문성이 있는지, 없다면 학습 비용이 얼마인지 확인했는가
  • 자격 요건(변호사·변리사)이 걸리는 업무인지 확인했는가
  • 기밀 유지 때문에 외부 위임이 부적절한 업무인지 확인했는가
  • 위임 시 보고 라인과 내부 검토자를 지정했는가

Must Do · 실행할 것

  1. 업무를 한 문장으로 특정합니다. "계약 검토"가 아니라 "A사와의 공급계약 3건 검토, 이사회 전까지"처럼 범위와 기한을 붙입니다.
  2. 세 항목에 점수를 매깁니다. 근거를 점수 옆에 한 줄씩 적습니다. 근거 없는 점수는 다음 사람이 재현할 수 없습니다.
  3. 비중을 곱해 합산합니다. 결과가 경계값(2.0·3.0·4.0) 근처면 점수를 다시 확인하고, 왜 경계에 걸렸는지 기록합니다.
  4. 결론을 네 갈래 중 하나로 적습니다. 적극 위임 / 부분 위임(조사·초안은 내부, 검토·의견은 외부) / 내부 처리 우선 / 반드시 내부 처리.
  5. 위임으로 정해졌으면 후보 로펌 3곳을 추리고 RFP를 보냅니다. 견적에는 업무 범위, 산출물, 기한, 담당 인력, 비용 상한을 함께 요구합니다.
  6. 선정 후 NDA를 체결하고, 자료 전달 범위와 보고 라인, 중간 점검 시점을 정합니다.
  7. 업무 종료 후 실제 소요 시간·비용·품질을 기록합니다. 다음 분기의 같은 유형 판단에서 이 기록을 근거로 씁니다.
