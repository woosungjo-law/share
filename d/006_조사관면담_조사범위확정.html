조사관 면담·조사 범위 확정

3줄 요약

- 조사 초기 조사관과의 면담에서 조사 범위·일정·방식을 명확히 확정해야 한다.

- 통지서 내용과 실제 조사 범위가 다르면 즉시 이의를 제기하고 서면으로 확인받아야 한다.

- 단일 창구(세무사 또는 법무)로 조사관과의 커뮤니케이션을 통일하는 것이 바람직하다.

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


조사통지·연기신청(005) -> [조사관 면담·범위 확정] -> 자료 제출 1차 대응(007)

1. 이번 단계에서 반드시 할 일

- [ ] 조사관 면담 준비(참석자·자료·질문 리스트)

- [ ] 조사 범위 재확인(통지서 세목·기간 일치 여부)

- [ ] 조사 일정·장소·방식(서면/현장) 협의

- [ ] 단일 창구 지정(세무사 또는 법무팀)

- [ ] 면담 내용·결과 기록·대응팀 공유

2. 준비물

준비물왜 필요한가준비 상태

대응팀 명단·역할표면담 시 조사관 제출·협의미확인
조사 장소(별도 회의실)조사관 업무 공간 제공미확인
면담 기록 양식일시·참석자·주요 내용 기록미확인

3. 작성·제출물

문서제출처주의점
조사 범위·일정 확인서(내부)대응팀조사관 구두 확인 내용 기록·보관
단일 창구 안내(내부)전 직원조사관 질문 시 단일 창구로 안내

4. 흔한 실수

- 조사관 면담에 세무사·변호사 없이 임원만 참석 — 권리 행사 모름·불리한 진술

- 면담 내용을 기록하지 않음 — 나중에 조사 범위·일정 다툴 때 증거 부족

- 모든 직원이 조사관 질문에 직접 응대 — 답변 불일치·조사 범위 확대

5. 전문가 상담 신호

위험도: 혼자 가능(세무사 동석 권장)
