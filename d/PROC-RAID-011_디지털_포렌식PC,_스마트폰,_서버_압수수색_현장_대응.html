PROC-RAID-011 | 디지털 포렌식(PC, 스마트폰, 서버) 압수수색 현장 대응

3줄 요약

- 전자정보 압수수색은 '저장매체 전체 반출'이 원칙이 아니며, 형소법 제106조 제3항에 따라 '출력·복제'가 우선이고 예외적으로만 저장매체를 반출할 수 있다

- 수사관이 현장에서 PC·노트북·서버에 직접 연결하여 포렌식 이미징을 수행할 경우, 영장 범위를 벗어난 전자정보의 열람·복제가 발생하지 않도록 참관이 필수적이다

- 기업의 운영 서버·클라우드 자원에 대한 압수는 업무 중단 손실이 크므로, 수사관과 협의하여 미러링·이미징 방식과 일정을 조정할 필요가 있다

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


[010] 문서·실물 압수 대응 -> [011] 디지털 포렌식 대응 -> [012] 이미징·원본반출

1. 이번 단계에서 반드시 할 일

- [ ] 수사관이 사용할 포렌식 장비(쓰기차단기, 이미징 장비, 분석 노트북)의 모델명·일련번호를 기록한다

- [ ] 압수 대상 저장매체(PC, 노트북, 외장하드, USB)의 전원을 끄고 봉인테이프로 포장을 요청하기 전에, 수사관이 현장에서 직접 부팅하거나 연결하는 행위를 감시한다

- [ ] "형소법 제106조 제3항에 따라 저장매체보다는 특정 전자정보의 출력·복제를 먼저 요청한다"고 말하고, 영장 범위 내 파일만 선택적 복제하도록 요구한다

- [ ] 운영 서버(ERP, 메일 서버, DB 서버)가 압수 대상일 경우, "서버를 즉시 정지하면 회사 전체 업무가 중단된다"는 사실을 수사관에게 설명하고, 대안으로 핫미러링·스냅샷 이미징 또는 업무 시간 외 이미징을 제안한다

- [ ] 클라우드(AWS, Azure, GCP, 네이버클라우드) 자원이 대상일 경우, CSP(클라우드 서비스 제공자)의 법적 대응 절차에 따라 이미징이 이루어질 수 있음을 인지하고 클라우드 계정·권한 정보를 함부로 제공하지 않는다

- [ ] 모든 포렌식 과정(케이블 연결, 부팅, 파일 선택, 복제)을 눈으로 직접 참관하고, 휴대폰 영상으로 기록한다

- [ ] 수사관이 특정 파일·폴더를 열람하려 할 때마다 "지금 여는 파일의 영장 관련성을 설명해 달라"고 요청한다

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 수사관이 "PC를 전부 가져간다"고 하자 "알겠다"고 수락: 대법원 2011모1839는 저장매체 반출이 원칙이 아니며, '영장 범위 내 전자정보만을 선별하여 출력·복제'가 우선임을 명확히 함. 저장매체 반출은 예외적 사유(기술적 복제 불가, 대량으로 선별 불가 등)가 필요

- IT 담당자가 "도와주겠다"며 직접 PC 전원을 켜거나 비밀번호 입력: 이는 임의처분으로 오인될 수 있음. 수사관이 요청해도 "변호인 지시로 IT 담당자는 어떠한 기술 조작도 할 수 없다"고 답하고, 수사관 자체 장비로 진행하도록 해야 함

- 클라우드 계정 정보를 '협조' 차원에서 제공: 클라우드에 저장된 데이터는 관할권 문제가 복잡하고, 영장의 집행 범위가 국내 저장매체에 한정될 수 있음. CSP가 법적 절차(형사사법협조)를 통해 별도로 대응하도록 하고 먼저 회사가 임의로 접근권한을 제공하지 말아야 함

5. 전문가 상담 신호

위험도: 전문가 필요

- 수사관이 서버 본체를 직접 반출하려 하면서 운영 중단이 불가피하다는 점을 인정하지 않는 경우 → 법원의 집행 방법 변경 신청(형소법 제106조 제4항) 검토 필요

- 클라우드 인프라(AWS 서울 리전 등) 자체가 압수 대상에 포함된 경우 → 영장의 역외 적용 범위·CSP의 이용약관상 대응 절차·외국 정부와의 충돌 가능성을 종합 검토해야 함

- 기업의 암호화·난독화 기술(DRM, EDR, 전체 암호화)이 적용된 데이터로 수사관 복제가 불가능한 경우

6. 인접 절차 연결

- 선행: PROC-RAID-010 (문서·실물 압수 대응) · 후속: PROC-RAID-012 (이미징·원본 반출)

- 디지털 증거 압수의 사후 통제: PROC-RAID-015 (압수 전자정보 열람 정지 가처분) / PROC-RAID-017 (위법수집증거 배제)
