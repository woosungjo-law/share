PROC-RAID-015 | 압수물 목록 확인 시 주의사항 (서명 전 꼼꼼한 대조)

3줄 요약

- 압수목록에 서명·날인하면 "내용을 확인하고 이의가 없다"는 증거효과가 발생하므로, 반드시 실제 압수물과 일일이 대조 후 서명

- 목록 누락·오기재(예: 물건명·수량·일련번호 불일치)는 추후 환부청구·증거개시 과정에서 압수물 동일성을 다투기 어렵게 만듦

- 현장에서 대조가 불가능할 정도로 방대하면 "수령은 하되 내용 확인 후 이의제기 가능함을 유보한다"는 취지를 기재하고 서명

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


014(압수조서·목록교부요구) -> [015] -> 016(준항고)

1. 이번 단계에서 반드시 할 일

- [ ] 압수물을 1건씩 꺼내 목록 기재사항(품명·수량·일련번호·규격·색상)과 육안 대조하고 사진 촬영

- [ ] 저장매체(노트북·외장하드·USB)는 시리얼번호를 별도 기록하고 기기가 실제 촬영된 사진과 함께 대조

- [ ] 서명 전에 "서명이 확인의 의미가 있음을 이해하였으며, 추후 정밀 대조 후 이의제기 권리를 유보한다"는 문구를 목록 여백에 필기하고 서명

- [ ] 목록에 영장 범위를 벗어난 물건이 포함되어 있으면 즉시 "영장 범위 외 물건이 포함되어 있습니다"라고 이의제기

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 수사관이 "확인용이니 일단 서명해 달라"고 재촉하는데 따라 서명함: 서명 후 "압수목록에 서명·날인하였으므로 압수물의 동일성에 이의가 없는 것으로 본다"는 실무 관행에 걸려 이후 이의제기가 곤란해짐. 서명 재촉은 오히려 대조를 철저히 해야 할 신호.

- 포괄 기재(예: "서류 1박스", "파일 다수")를 그대로 받아들임: 포괄 기재는 압수물 특정 요건을 희석시켜 수사기관에 유리하지만, 피압수자 측에서는 추후 특정 물건의 압수 여부를 입증하기 어려워짐. "어떤 서류인지 목록에 기재해 달라"고 요구해야 함.

- 저장매체 압수 시 내부 파일 목록(트리 구조)을 요구하지 않음: 저장매체 자체를 압수한 경우, 압수목록에 "OOO 노트북 1대"라고만 기재되는데, 그 안의 특정 파일이 영장범위를 넘는지 추후 다투려면 압수 직후의 파일 트리 구조가 필요함.

5. 전문가 상담 신호

위험도: 상담 권장

- 압수물 수량이 50건 이상이거나 저장매체 3대 이상 압수되어 현장 대조가 물리적으로 불가능한 경우

- 영장 기재 범위를 명백히 초과한 물건(예: 영장은 회계자료인데 개인 휴대폰까지 압수)이 발견된 경우

- 수사관이 목록 작성을 거부하거나 수량·물건명을 허위 기재한 정황이 있는 경우

6. 인접 절차 연결

- 선행: (내사·수사) · 후속: 형사고소상품 피의자 트랙
