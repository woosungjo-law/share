3MUST · 기업법무

법무팀은 조건부 승인이라고 했는데 보고서에는 승인만 남았을 때

적용 상황: 법무팀이 조건을 붙여 검토 의견을 냈는데, 이사회·경영진 보고나 현업 전달 과정에서 조건이 빠진 채 사업이 진행되고 있는 상황을 발견한 담당자. 범위: 이 카드는 조건부 승인의 문언 관리와 이행 확인 절차만 다룹니다. 조건 미충족 시 계약·행정상 효력의 최종 법률 판단, 제재 수위, 손해배상 범위는 다루지 않습니다.

Must Know · 알아야 할 것

  • 조건을 붙인 승인은 조건이 충족되기 전에는 승인으로서 효력이 발생하지 않는 것이 원칙입니다. 따라서 조건이 사라지면 남은 '승인'은 법무 의견과 다른 내용이 됩니다.
  • 왜곡은 한 번에 일어나지 않고 단계적으로 진행됩니다. 조건이 생략되고, 표현이 완화되고, 시간이 지나면서 조건의 존재 자체가 망각됩니다.
  • 가장 많이 끊기는 지점은 구두 전달과 요약 보고입니다. 회의 구두 보고, 이사회 보고서 요약, 메신저 공유 과정에서 조건 절이 잘립니다.
  • 조건은 내용만 적어서는 작동하지 않습니다. 충족 주체, 기한, 확인 방법, 미충족 시 효과가 함께 있어야 관리가 됩니다.
  • 확인 게이트 없이 '승인'이라는 단어를 쓰면, 이후 사고에서 남는 것은 조건이 아니라 승인이라는 단어뿐입니다.
  • 조건 미충족 상태의 진행은 개별 담당자의 일탈이 아니라 회사 내부 승인 절차와 리스크 관리 체계의 미비로 평가될 수 있습니다.
  • 보고자가 조건을 빼는 이유는 대부분 부정적 어감을 피하려는 것입니다. 어감 문제는 문구 설계로 풀어야 하고, 조건을 지우는 방식으로 풀면 안 됩니다.
  • 조건이 여러 건이면 번호와 담당이 없을 때 누락됩니다. 한 문서 안에서 번호 목록으로 고정해야 추적이 됩니다.

Must Check · 확인할 것

  • 법무 검토 의견 원문과 조건 조항 전체 문언
  • 조건별 충족 주체·기한·확인 방법이 명시되어 있는지
  • 조건 미충족 시 효과(승인 효력, 재검토 필요 여부)가 적혀 있는지
  • 경영진·이사회 보고서에 조건이 실제로 기재되었는지
  • 구두 보고·메신저·회의록에 조건이 남아 있는지
  • 현업 부서가 조건의 존재를 인지하고 있는지
  • 조건 이행 여부를 통보하는 절차와 담당자가 지정되어 있는지
  • 법무팀이 충족을 확인하는 게이트가 실제로 운영되는지
  • 조건 충족 증빙(완료 통지, 계약서, 승인서)이 보관되어 있는지
  • 이미 조건 미충족 상태로 진행된 단계가 있는지
  • 조건과 함께 검토된 전제(자료·범위·가정)가 여전히 유효한지
  • 재검토가 필요한 시점과 재검토 요청 경로

Must Do · 실행할 것

  1. 법무 검토 의견 원문을 확보해 조건을 번호 목록으로 다시 정리하고, 문서 전면에 조건 박스로 배치합니다.
  2. 조건별로 충족 주체, 기한, 확인 방법, 미충족 시 효과를 네 칸으로 적어 한 장 요약을 만듭니다.
  3. 경영진 보고서와 현업 전달 자료에 조건이 빠져 있으면, 다음 보고 전에 조건부 승인 문안으로 교체하고 교체 사실을 기록합니다.
  4. 현업 부서에 조건 충족 시 법무팀에 통보하도록 서면으로 요청하고, 통보 양식과 담당자를 지정합니다.
  5. 법무팀 내부에 확인 게이트 담당을 정하고, 통보 접수일·확인일·확인 결과를 대장에 기록합니다.
  6. 조건 충족이 확인되기 전에는 최종 승인 문서를 발행하지 않고, 진행 상태를 조건부로 표시합니다.
  7. 이미 진행된 단계가 있으면 사실관계를 정리해 경영진과 법무 책임자에게 보고하고 보완 계획을 세웁니다.
  8. 조건부 승인 추적 대장을 만들어 조건·담당·기한·상태·증빙 위치를 주기적으로 갱신합니다.
잠깐 멈추고 검토할 때

조건이 이미 삭제된 문서로 대외 발송·계약 체결·신고가 완료된 경우 · 조건 미충족 상태에서 규제기관 조사나 사고가 발생한 경우 · 경영진이 조건 삭제를 명시적으로 요구하거나 보고 문구를 압박하는 경우 · 조건의 충족 여부를 판단할 자료 자체가 없거나 담당이 공석인 경우 · 조건과 함께 전제된 사실관계가 바뀌어 조건 자체를 다시 설계해야 하는 경우 · 조건이 여러 부서에 걸쳐 있어 단일 확인 주체를 정할 수 없는 경우

원자료: 기업법무 법무리스크 의사결정 심화 EP-005(조건부 승인의 3단계 왜곡, 위험 신호, 조건 이행 3단계 체계, 표준 문안, 실패 패턴)

제한: 조문 번호와 판례 사건번호, 승인 효력에 관한 최종 법률 판단, 제재·손해배상 범위는 본 카드에서 제외했습니다. 문언 관리와 확인 절차만 정리했습니다.
