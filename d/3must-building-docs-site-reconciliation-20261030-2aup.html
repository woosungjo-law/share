3MUST · 부동산법

공사 진행 중 건축 관련 문서와 현장 상태를 대조할 때

적용 상황: 공사 담당자나 건물 관리자가 여러 버전의 도면·공문·공사 기록을 갖고 있고, 현재 현장과 어느 문서를 비교해야 할지 불분명할 때 사용합니다. 범위: 받은 문서의 발급·작성 정보와 현장 사진·공정 기록을 보존하고, 차이와 미확인 항목을 담당자에게 전달하는 절차입니다. 허가·신고 대상인지, 공사가 적법한지, 시정명령이나 제재가 가능한지 판단하지 않습니다.

Must Know · 알아야 할 것

  • 도면이나 안내문에 적힌 내용과 현장 모습이 다르더라도 그 차이만으로 위법 여부나 문서의 효력을 단정할 수 없습니다.
  • 문서에 적힌 명칭과 발급기관을 그대로 기록합니다. 직접 “허가됨”, “위반건축물” 등으로 법적 상태를 새로 판정하지 않습니다.
  • 최초 문서와 변경 문서를 모두 보존하고, 현장에서 확인한 날짜와 위치를 함께 적어야 나중에 서로 다른 시점을 섞지 않습니다.
  • 현재 문서가 최신본인지, 현장 변경이 있었는지 모르면 추측 대신 미확인으로 남깁니다.

Must Check · 확인할 것

  • 주소·지번·건물명·동·층 등 자료에 표시된 대상 식별 정보
  • 허가·신고 관련 문서, 승인 도면, 변경본, 전달받은 공문과 발급·수신 날짜
  • 공사 일정표, 작업일지, 변경 요청과 승인·회신 기록, 사진 원본과 촬영 위치·날짜
  • 문서마다 작성자·발급기관·버전·파일명·수정일이 표시되어 있는지
  • 현재 현장에서 관찰한 항목과 문서에서 확인한 항목이 각각 무엇인지
  • 미확인 사항을 설명할 담당자(건축사·시공 담당자·소유자·문서 발급기관)

Must Do · 실행할 것

  1. 원본 문서를 수정하지 않고 보관합니다. 같은 문서의 이전본과 변경본은 파일명과 날짜를 구분해 둡니다.
  2. 현장 사진은 촬영한 날짜·위치·방향을 덧붙이고 원본 파일을 보존합니다. 사진만으로 원인이나 법적 상태를 추정하지 않습니다.
  3. 표에 확인 항목 / 문서의 기재 / 현장 관찰 / 자료 날짜·버전 / 차이 / 확인 담당자 / 확인 상태를 기록합니다.
  4. 문서 간 표시가 다르거나 변경 이력이 비어 있으면, 어느 문서가 기준인지 스스로 선택하지 말고 관련 문서와 질문을 묶어 담당자에게 보냅니다.
  5. 공사·운영·거래 결정이 필요한 경우, 확인되지 않은 차이를 먼저 공유하고 답변·결정·근거 문서의 위치를 기록합니다.
잠깐 멈추고 검토할 때

관할 기관의 시정·보완·중지 등 공식 통지나 답변을 받았을 때 · 현재 도면과 현장 상태가 다르거나 어떤 버전이 유효한지 확인되지 않을 때 · 공사·사용·매매 등 일정이 임박했는데 확인할 담당자나 의사결정자가 정해지지 않았을 때 · 안전에 영향을 줄 수 있는 현장 상태를 발견했을 때

원자료: 건축 관련 문서와 공사 단계가 함께 등장하는 원문의 주제 범위만 참고했습니다.
