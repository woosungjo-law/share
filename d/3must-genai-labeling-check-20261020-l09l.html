AI가 만든 콘텐츠를 서비스에 올리기 전 표시를 점검할 때

적용 상황: 마케팅·콘텐츠팀이 AI로 생성·변조한 이미지·영상·음성·문구를 광고나 서비스 화면에 사용하려는 경우. 범위: 표시 의무의 법적 범위와 위반 시 제재 수준은 단정하지 않습니다. 출력물 유형 확인, 표시 방법 결정, 적용·기록, 내부 기준 마련을 다룹니다.

Must Know · 알아야 할 것

  • AI가 만들었다는 사실을 이용자가 쉽게 알 수 있어야 합니다. 숨기거나 흐리게 처리하면 표시로 보기 어렵습니다.
  • 유형마다 요구가 다릅니다. 이미지·영상·음성처럼 실제와 혼동될 수 있는 콘텐츠는 표시 수준이 더 높습니다.
  • 실존 인물의 음성·얼굴을 변조한 콘텐츠는 별도의 위험이 겹칩니다. 표시와 함께 사용 권한·초상·명예 문제를 확인해야 합니다.
  • 표시는 화면 설계의 문제입니다. 기획 단계에서 정하지 않으면 배포 직전에 붙이게 되고, 눈에 띄지 않게 됩니다.
  • 내부 기준이 없으면 담당자마다 판단이 달라집니다. 유형별 기준표를 만들어 두는 것이 가장 빠른 대응입니다.

Must Check · 확인할 것

  • 콘텐츠가 완전 생성인지, 일부 변조인지, 단순 편집인지 구분했는가.
  • 이미지·영상·음성·텍스트 중 어떤 유형인지, 조합된 형태인지 확인했는가.
  • 실존 인물·실제 사건을 소재로 했는가.
  • 표시 문구·아이콘·고지 위치가 이용자 눈에 띄는 곳에 있는가.
  • 표시를 제거하거나 우회할 수 있는 경로가 있는가.
  • 광고·제휴 콘텐츠로 나갈 때 추가 고지가 필요한가.
  • 이용약관·처리방침에 AI 사용 사실이 반영되어 있는가.

Must Do · 실행할 것

  1. 담당자는 콘텐츠 목록표를 만들고 각 항목에 생성 방식 / 유형 / 인물 등장 여부 / 표시 방법을 적습니다.
  2. 유형별 표시 기준표를 만들고, 각 콘텐츠가 기준을 충족하는지 표시합니다.
  3. 미충족 항목은 표시를 추가하거나 사용을 보류합니다. 보류 사유와 대체안을 기록합니다.
  4. 배포 전 화면에서 실제로 보이는지 확인하고, 확인자와 확인일을 남깁니다.
  5. 실존 인물 관련 콘텐츠는 사용 권한·초상·명예 리스크 검토를 별도로 거칩니다.
  6. 배포 후 이용자 문의·삭제 요구에 대응할 창구와 절차를 정합니다.
  7. 유형별 기준표를 내부 지침으로 확정해 다음 제작부터 적용합니다.
잠깐 멈추고 검토할 때

실존 인물의 음성·얼굴을 합성한 콘텐츠인 경우 · 선거·공공 이슈와 관련된 콘텐츠인 경우 · 표시를 빼고 싶다는 요청이 있는 경우 · 이미 배포된 콘텐츠에서 표시 누락이 발견된 경우 · 해외 플랫폼에 동시 게시해 다른 규제도 적용되는 경우
