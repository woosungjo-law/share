규제·인허가 지형 파악

3줄 요약

- 인허가·규제 이슈는 소관 기관·근거법령·재량 범위를 먼저 확정해야 전략이 나온다.

- 동일 업종·규모의 선례를 찾아 기관의 실무 관행과 처리 기간을 가늠한다.

- 기관의 재량 범위(기속행위 vs 재량행위)를 파악해 대응 강도를 조정한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사전)


(규제·인허가 이슈 발생) -> [지형 파악] -> 리스크·이해관계자 매핑(002)

1. 이번 단계에서 반드시 할 일

- [ ] 소관 부처·기관·지자체 부서 확정

- [ ] 근거 법령·하위규정(시행령·시행규칙·고시·훈령) 확인

- [ ] 기관의 재량 범위(기속·재량·기술적 재량) 식별

- [ ] 유사 사례·선례(동종 업계 인허가 사례) 수집

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 소관 기관 착각 — 이송·지연·각하 위험

- 근거법령의 하위규정(고시·훈령) 누락 — 실제 심사 기준을 놓침

- 재량행위를 기속행위로 오해 — 과도한 대응 또는 대응 소홀

- 관할 관청의 사전 컨설팅 제도를 모르고 정식 신청부터 진행

5. 전문가 상담 신호

위험도: 혼자 가능

- 소관 부처·법령이 다수·복잡하게 얽힌 경우

- 규제 샌드박스·특례 적용 가능성 검토가 필요한 경우

6. 인접 절차 연결

선행: (규제·인허가 이슈 발생) · 후속: 002 리스크·이해관계자 매핑 → 불복 시 PROC-ADMN 행정심판소송상품
