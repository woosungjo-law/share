3MUST · 기업법무 · INCIDENT INTAKE

개인정보 파일을
잘못된 수신자에게 보냈을 때

발송 기록을 보존하고 수신자에게 삭제를 요청한 뒤, 회신과 시스템 기록을 함께 확보해 담당자에게 인계합니다.

적용 상황 특정 수신자에게 이메일이나 공유 링크를 잘못 보내 파일이 전달되었을 가능성이 있을 때

범위 연락·기록 보존·사실 확인 절차. 사고 해당 여부와 신고·통지 의무·기한·면제는 판단하지 않습니다.

Must Know · 먼저 기억할 것

  • 취소·차단 시도와 별개로 원본 메일, 전송 기록, 접근 로그를 보존합니다.
  • 구두 답변과 확인 자료를 구분하고, 미확인 사항은 완료로 표시하지 않습니다.
  • 원본 파일과 수신자 정보는 접근을 제한해 다룹니다.

Must Check · 사실 확인

  • 수신자, 발송 시각, 메시지 ID
  • 파일 이름·버전과 포함 정보의 종류
  • 취소·권한 회수 시도와 결과
  • 열람·다운로드·전달 기록
  • 수신자 답변과 삭제 근거
  • 미확인 항목·담당자·다음 확인 시점

Must Do · 지금 진행할 순서

1

전송을 멈추고 기록을 보존합니다

발송 취소나 공유 권한 회수를 시도하고 시각·결과를 남깁니다. 메일 헤더, 첨부파일 버전, 접근 기록은 보존하고 원본은 수정하지 않습니다.

2

수신자에게 바로 연락합니다

파일을 열람·복사·저장·전달하거나 다시 올리지 말아 달라고 요청합니다. 이미 열람·전달·저장했다면 그 범위도 알려 달라고 합니다. 확인 가능한 위치의 사본 삭제를 요청합니다.

3

회신과 기술 기록을 연결합니다

수신자, 연락 시각, 요청과 답변을 기록합니다. 파일명·버전, 열람·전달 여부, 삭제 위치·시각, 남은 사본 여부를 확인하고 원본 메일·시스템 로그와 함께 제한 보관합니다.

4

확인 사실과 미확인점을 인계합니다

개인정보·보안·법무 담당자에게 경위, 파일 범위, 회수 조치, 회신, 시스템 기록, 미확인 항목을 전달합니다. 외부 안내나 신고 필요성은 담당자가 별도로 판단합니다.

완료 확인

  • 발송·회수 시도 기록의 위치가 남아 있다.
  • 수신자 회신이 시각과 내용별로 정리됐다.
  • 확인되지 않은 내용은 미확인으로 표시했다.
  • 담당자에게 사실과 미확인 사항을 함께 인계했다.

원자료의 오발송 대응 절차에서 연락·삭제 요청·객관적 확인 자료 확보만 추렸습니다. 법률상 신고·통지 판단은 포함하지 않습니다. 실제 사고에서는 조직의 사고 대응 및 기록 보존 절차를 확인하세요.
