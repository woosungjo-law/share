조사 연장·범칙조사 전환 대응

3줄 요약

- 일반통합조사의 조사 기간은 통상 20~30일이며, 중대한 위법 혐의가 있는 경우 연장될 수 있다.

- 조사관이 범칙조사(조세범처벌법 위반 혐의)로 전환하면 일반 세무사만으로 대응할 수 없고 반드시 형사 변호인을 선임해야 한다.

- 범칙조사로 전환되면 진술 거부권·변호인 참여권이 더욱 중요해지므로 즉시 법률 대응 체계로 전환해야 한다.

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후

- [ ] 연장 한도(1차+2차) 초과 여부 점검

- [ ] 범칙조사 전환 징후 감시(압수수색·참고인 조사·금융계좌 추적)

- [ ] 범칙조사 전환 시 즉시 형사 변호인 선임

- [ ] 진술 거부권·변호인 참여권 적극 행사

4. 흔한 실수

- 일반 세무사만으로 범칙조사에 대응 — 형사 절차·증거 법칙 이해 부족

- 연장 통지 없이 조사가 계속되는데도 이의제기 안 함 — 묵시적 동의로 간주될 위험

- 범칙조사 전환 후에도 기존처럼 자료를 무제한 제출 — 자기부죄 증거 제공

5. 전문가 상담 신호

위험도: 전문가 필요

- 조사관이 압수수색 영장·참고인 출석 요구서를 제시

- 범칙조사 전환 통지를 받은 경우 — 즉시 형사 변호사 선임

- 조사 기간이 법정 한도를 초과하여 연장된 경우
