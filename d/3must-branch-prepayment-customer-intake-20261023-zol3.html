3MUST · 회사법 · 접수와 사실 확인

지점 고객이 선입금 후 상품을 받지 못했다고 접수했을 때

적용 상황: 지점 거래 고객이 대금을 먼저 지급했지만 상품을 받지 못했다고 본사에 알렸을 때, 거래 자료와 확인할 사실을 모아 담당자에게 인계합니다.

범위: 접수·자료 확인·내부 인계 절차만 다룹니다. 회사나 임직원의 법적 책임, 환급·배상 의무는 판단하지 않습니다.

고객 진술 · 문서로 확인된 사실 · 추가 확인 항목을 구분해 시간순으로 기록합니다.

Must Know · 먼저 알아야 할 것

  • 고객 설명과 확인된 기록을 분리합니다.
  • 주문부터 접수까지 거래 흐름을 시간순으로 정리합니다.
  • 내부 권한자료와 고객에게 제시된 자료를 함께 확인하되 책임 결론은 내리지 않습니다.

Must Check · 반드시 확인할 것

  • 제안 내용, 지급일·금액, 상품과 인도 예정일
  • 주문서·계약서·영수증·입금자료·대화 기록
  • 인도·취소·환급의 현재 처리 상태와 담당자
  • 지점 권한·할인 한도와 고객에게 제공된 안내
  • 유사 거래·추가 문의 여부 및 각 자료의 확인 상태

Must Do · 지금 할 일

  1. 접수 시각·채널·담당 부서와 고객 요청을 기록합니다.
  2. 제안 → 지급 → 인도 예정 → 현재 상태 → 접수 순으로 타임라인을 만듭니다.
  3. 자료는 원형대로 모으고 불일치는 추정하지 말고 확인 항목으로 남깁니다.
  4. 지점 내부 권한표와 외부 안내자료, 승인 기록을 대조합니다.
  5. 재무·영업 담당자에게 거래기록과 유사 문의 확인을 요청합니다.
  6. 고객에게 접수 사실·확인 창구·다음 안내 시점을 알립니다. 책임이나 환급을 미리 약속하지 않습니다.
멈추고 검토할 때 유사 피해가 반복되거나 기록이 맞지 않을 때, 내부 권한과 외부 안내가 다를 때, 환급·배상 합의 요구나 외부 기관 연락이 있을 때, 자료 공유 범위가 불명확할 때는 법무 담당자에게 인계합니다.
