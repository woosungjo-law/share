3MUST · 특수법률

카페·베이커리를 열거나 제빵·제과를 직접 만들 때 신고·허가를 확인할 때

적용 상황: 카페·디저트·베이커리를 열려고 하는데, 커피만 파는 경우와 빵·쿠키·디저트를 직접 제조·판매하는 경우의 신고·허가가 어떻게 다른지 개업 전에 확인해야 하는 자영업자

Must Know · 알아야 할 것

  • 카페 영업은 무엇을 만드는지에 따라 신고·허가가 갈립니다. 커피·음료·간단한 조리만 하면 휴게음식점(신고)으로 충분하지만, 빵·쿠키·디저트를 직접 제조·판매하면 식품제조·가공업 허가가 별도로 필요할 수 있습니다 — 정확한 구분은 관할 기관·최신 법령으로 확인합니다.
  • 외부에서 만든 제품을 그대로 납품받아 파는 것과, 원두를 직접 로스팅·가공해 파는 것은 요건이 다릅니다. 제조·가공에 해당하는지 먼저 짚습니다.
  • 원산지 표시가 별도로 붙습니다. 커피원두·우유 등 표시 의무 대상인 원재료를 확인합니다 — 표시 대상·방법은 최신 기준으로 확인합니다.
  • 배달·테이크아웃은 포장 온도·밀봉·유통기한 등 별도 위생 관리가 필요합니다.

Must Check · 확인할 것

  • 우리가 직접 제조·가공하는 품목이 있는지(빵·쿠키·디저트·로스팅) — 있으면 제조·가공업 허가 여부를 확인했는지
  • 커피·음료만 판매하는 경우 휴게음식점 신고로 충분한지 관할 기관에 확인했는지
  • 원산지 표시 의무 대상 원재료(커피원두·우유 등)를 확인했는지
  • 배달·테이크아웃 시 포장 온도·밀봉·유통기한 관리 기준을 준비했는지
  • 조리 시설(토스트·샌드위치 등) 기준을 갖췄는지
  • HACCP 등 별도 의무가 해당되는 규모·업종인지 확인했는지

Must Do · 실행할 것

  1. 우리 영업 형태(커피만/직접 제조/외부 납품)를 확정합니다.
  2. 직접 제조·가공이 있으면 식품제조·가공업 허가 필요 여부를 관할 기관에 확인합니다.
  3. 영업신고·허가 서류와 시설 기준을 준비합니다.
  4. 원산지 표시 대상 원재료와 표시 방법을 정리해 메뉴·진열에 반영합니다.
  5. 배달·테이크아웃의 포장·온도·유통기한 관리 절차를 정합니다.
잠깐 멈추고 검토할 때

직접 제빵·제과를 신고 없이 시작했다면 — 제조·가공업 허가가 필요한 경우 무허가 영업이 될 수 있으므로 즉시 확인하세요. · 원산지 표시를 누락했다면 — 표시 의무 위반으로 과태료 등 제재 대상이 될 수 있으므로 표시를 정비하세요. · 식중독·위생 사고가 났다면 — 영업정지·과태료 대응과 함께 보건소·관할 기관 신고 절차를 확인하세요.

원자료: D-RD-자영업자-카페·디저트·베이커리 영업법률(recursive doctrine)

법률 확인(2026-11-12): 식품위생법상 영업허가·신고·등록의 세부 구분은 대통령령에 위임된 구조라 조문 번호를 인용하지 않았습니다. 이 카드는 신고·허가 판별과 표시·위생 확인 절차만 안내합니다.

미확인·제한: 휴게음식점·식품제조가공업의 정확한 구분, HACCP 의무 대상, 원산지 표시 대상·방법, 과태료 액수는 관할 기관·최신 법령으로 확인이 필요합니다.
