규제산업 회사를 인수 검토할 때 인허가 자료를 먼저 모아야 할 때

적용 상황: 대상회사가 인허가·등록·지정 관련 자료를 보유한다고 설명하지만, 거래팀이 범위와 자료 상태를 한 번에 파악하기 어려운 초기 검토에 사용합니다. 범위: 자료 목록화와 법률·산업 전문가 확인을 연결하는 운영 절차입니다. 허가의 승계 여부, 변경신고·승인 필요성, 거래 조건이나 기간을 판단하지 않습니다.

Must Know · 알아야 할 것

  • 회사가 보유했다고 설명한 자료와 실제 운영에 사용되는 자료를 맞춰 보는 것이 첫 단계입니다.
  • 인허가의 법적 상태나 거래 후 효력은 문서 제목만으로 결론내리지 않습니다. 거래 구조와 적용 규정을 전문가가 확인해야 합니다.
  • 인수 일정에 넣는 날짜는 담당자·규제기관 또는 법률전문가가 확인한 일정과 내부 목표일을 구분해 표시합니다.

Must Check · 확인할 것

  • 대상 법인·사업장별로 운영 중인 사업과 관련 자료의 목록이 작성되었는가?
  • 각 자료의 명칭, 발급·갱신 표기, 보유 법인, 사업장, 문서 위치가 원본과 대조되었는가?
  • 조건·첨부·변경 내역·기관과 주고받은 문서가 함께 수집되었는가?
  • 대상회사 설명과 실제 문서에 적힌 법인명·사업장·운영범위의 차이가 기록되었는가?
  • 거래에서 예정한 인수 주체·지분 또는 자산 범위·운영계획 등 확인 질문의 전제가 정리되었는가?
  • 승계·변경·신고·승인 필요성에 관한 법률 질문과 답변 담당자가 지정되었는가?
  • 거래 일정의 검증된 외부 기한과 내부 목표일이 따로 표시되어 있는가?

Must Do · 실행할 것

  1. 대상회사에 현재 사업·법인·사업장별 인허가 관련 문서 목록과 원본 위치를 요청합니다.
  2. 목록의 각 항목에 문서상 명칭, 보유 법인·사업장, 발급·갱신 표기, 첨부·변경문서, 담당자를 기록합니다.
  3. 설명과 문서가 일치하지 않거나 자료가 누락된 항목은 결론을 추정하지 말고 확인 질문과 자료요청으로 분리합니다.
  4. 거래팀이 예상하는 거래구조와 운영변화를 사실자료로 정리해 법률·산업 전문가에게 승계·변경·기관 협의 여부를 질문합니다.
  5. 전문가 확인 전에는 승인 완료나 일정 확정을 표시하지 않습니다. 답변 출처·담당자·확인일과 미해결 질문을 이슈표에 남깁니다.
  6. 확인된 외부 일정과 내부 목표일을 거래 일정표에 반영하고, 자료 지연·답변 변경 시 업데이트 책임자를 정합니다.
