현장조사·질문답변 대응

3줄 요약

- 현장조사에서 조사관의 질문에는 세무사·변호사 동석 아래 사실만 답변해야 한다.

- 추측·가정·의견을 요구하는 질문은 답변을 거부하거나 '추후 확인 후 회신'으로 대응한다.

- 모든 질문과 답변은 일시·내용·참석자를 기록해 두어야 나중에 다툼이 있을 때 증거가 된다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


자료 제출 1차 대응(007) -> [현장조사·질문답변 대응] -> 쟁점별 소명·증빙 준비(009)

1. 이번 단계에서 반드시 할 일

- [ ] 세무사·변호사 동석하여 조사관 질문 응대

- [ ] 사실만 답변하고 추측·의견 배제

- [ ] 즉시 답변 곤란한 질문은 '확인 후 회신'으로 대응

- [ ] 모든 질문·답변 일지 기록(일시·질문·답변·참석자)

- [ ] 단일 창구 외 직원의 조사관 접촉 차단

2. 준비물

준비물왜 필요한가준비 상태
질문·답변 기록지 양식체계적 기록·보관미확인

3. 작성·제출물

문서제출처주의점
질문·답변 일지(내부)법무팀 보관일시·질문자·질문내용·답변자·답변내용 기재
일일 상황 보고서(내부)대응팀·경영진당일 진행·쟁점·리스크 요약

4. 흔한 실수

- 세무사·변호사 동석 없이 임원이 단독 응대 — 불리한 진술·권리 포기

- 답변 내용을 기록하지 않음 — 나중에 '조사관이 그렇게 말했다' vs '아니오' 다툼

- '모르겠다'는 답변을 반복 — 조사관의 부정적 판단 유발, '확인 후 회신'으로 대응

- 질문의도 파악 없이 즉시 답변 — 질문 범위·의도를 먼저 확인

5. 전문가 상담 신호

위험도: 상담 권장

- 조사관이 범칙조사 전환을 시사하는 질문

- 자기부죄거부권(헌법 제12조) 행사 필요성 검토

- 답변 내용이 형사 책임으로 연결될 가능성
