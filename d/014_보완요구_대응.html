보완요구 대응

3줄 요약

- 기관의 보완요구는 흠결이 있는 사항을 보충할 기회이지만, 기한 내 미응답 시 각하·기각 사유가 된다.

- 보완요구 내용을 분석해 단순 흠결(서류미비)과 실질 흠결(요건 미충족)을 구분해 대응한다.

- 보완 기간 연장이 필요한 경우 기한 만료 전에 사유를 소명해 연장을 요청한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 대응)


(앞선 단계) -> [보완요구 대응] -> 의견제출·청문 대응(015)

1. 이번 단계에서 반드시 할 일

- [ ] 보완요구서의 내용·근거·기한 확인

- [ ] 보완 필요 사항을 단순 흠결·실질 흠결로 분류

- [ ] 보완 자료 준비(필요시 외부 전문가 협력)

- [ ] 보완 기한 연장 필요 시 기한 전 요청

- [ ] 보완 답변서 작성·제출

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 보완 기한을 놓쳐 각하·기각

- 보완요구의 의도를 오해해 엉뚱한 자료 제출

- 단순 보완인데 과도한 자료·소명 제출 — 오히려 새로운 쟁점 부각

- 보완 후 추가 보완요구 가능성을 고려하지 않고 일정 관리 소홀

5. 전문가 상담 신호

위험도: 혼자 가능

- 보완요구가 반복되거나 기관과 이견이 있는 경우

- 보완 불가능한 흠결(결격사유·요건 미달)이 발견된 경우

6. 인접 절차 연결

선행: 013 · 후속: 015 의견제출·청문 대응

7. 근거 조문·판례
