상대방 무응답·연락두절 대응

3줄 요약

  • 내용증명을 보냈는데도 채무자가 응답하지 않으면, 추가 독촉(재내용증명·등기우편)을 검토한다.
  • 연락두절 상태가 지속되면 지급명령(독촉절차)으로 전환할 시점을 판단한다.
  • 무응답 상태에서 시효가 계속 진행되므로, 시효중단 조치를 병행해야 한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 대응)

연락·통화(007) -> [무응답·연락두절 대응] -> 부인·다툼 대응(009)

1. 이번 단계에서 반드시 할 일

  • 내용증명 송달 여부 확인(반송 여부·등기조회)
  • 추가 독촉장(재내용증명·등기우편) 발송 검토
  • 주소 불일치 시 채무자 주소 재확인(주민등록등본·사업자등록증)
  • 지급명령·소송 전환 시점 결정

2. 준비물

준비물 왜 필요한가 준비 상태
내용증명 등본2(발송인 보관용) 발송 사실 증명 미확인
등기조회 결과 송달 여부 확인 미확인
채무자 주민등록등본 정확한 주소 확인 미확인

3. 작성·제출물

문서 제출처 주의점
재독촉장(선택) 채무자 등기우편 내용증명보다 간이 발송, 독촉 사실 기록 유지
지급명령 신청서(준비) 법원 무응답 상태 지속 시 신속 전환

4. 흔한 실수

  • 무응답인데 계속 내용증명만 반복 발송 — 시간·비용 낭비, 지급명령 전환 검토 필요
  • 채무자의 주소가 변경됐는데도 기존 주소로 계속 발송 — 송달 효력 없음
  • 시효 진행 간과 — 내용증명 후 6개월 내 추가 조치(민법 제174조)

5. 전문가 상담 신호

위험도: 상담 권장

  • 채무자가 주소를 이전하거나 잠적한 정황
  • 채무자가 법인이고 폐업·해산 위험
  • 지급명령·소송 전환 시점 판단이 어려운 경우

6. 인접 절차 연결

선행: PROC-DEMD-007(연락·통화) · 후속: PROC-DEMD-015(지급명령)
