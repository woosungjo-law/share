인허가 신청서·첨부서류 접수

3줄 요약

- 인허가 신청은 필수서류 완비·기재사항 정확성·수수료 납부·접수증 확인이 기본이다.

- 접수 방식(방문·우편·전자)에 따라 처리 기간과 보완 절차가 다를 수 있다.

- 접수증(점수증)을 반드시 발급받아 기산일을 확정한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 착수)


정보공개 대응(007) -> [인허가 신청서 접수] -> 원보이스 체계 구축(009)

1. 이번 단계에서 반드시 할 일

- [ ] 근거 법령상 신청서 필수 기재사항·첨부서류 점검

- [ ] 신청서 작성(사실관계·법리 검토 완료)

- [ ] 접수 방법(방문·전자·우편) 선택

- [ ] 접수증·점수증 발급 확인

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 서류 미비로 보완요구 — 처리 기간 지연

- 접수증 미발급 — 신청 시점 분쟁 시 입증 곤란

- 전자접수 시스템 오류에 대한 백업(방문·우편) 미확보

- 기재 착오로 신청 자체가 각하되는 경우

5. 전문가 상담 신호

위험도: 혼자 가능

- 신청서 작성이 복잡하고 첨부서류가 방대한 경우

- 법리 검토가 필요한 쟁점이 신청서에 포함된 경우

6. 인접 절차 연결

선행: 007 · 후속: 009 원보이스 체계 구축
