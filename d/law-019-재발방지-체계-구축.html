재발방지 체계 구축(ISMS-P·교육·감사)

3줄 요약

  • 유출 사고 후 재발방지 대책 수립·이행은 과징금 감경·신뢰 회복의 핵심이다.
  • ISMS-P 인증·임직원 보안 교육 정례화·내부 감사 체계는 대표적 재발방지 수단이다.
  • 재발방지 노력의 문서화는 차후 유출 시 감경 사유로 인정될 수 있다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사후)

사고 종결 -> [재발방지 체계 구축] -> 정기 점검·갱신

1. 이번 단계에서 반드시 할 일

  • 사고 원인 분석 기반 재발방지 대책 수립
  • ISMS-P 인증 획득·갱신 검토(대상 기관 해당 시)
  • 임직원 개인정보 보호 교육 정례화(연 1회 이상)
  • 내부 감사·모의 훈련 체계 구축
  • 사고 대응 매뉴얼 개정·보완
  • 재발방지 대책 이행 현황 정기 보고 체계 확립

2. 준비물

준비물 왜 필요한가 준비 상태
사고 원인 분석 보고서 대책 수립 근거 미확인
ISMS-P 인증 기준·체크리스트 인증 준비 미확인
교육 자료·프로그램 정기 교육 실행 미확인
내부 감사 계획서 감사 체계 구축 미확인

3. 작성·제출물

문서 제출처 주의점
재발방지 대책 보고서 경영진·개인정보위(요구 시) 구체적·측정 가능·기한 설정
개인정보 보호 교육 이력 내부 보관 연 1회 이상, 참석자·교육 내용 기록
내부 감사 결과 보고서 내부 보관 발견 사항·조치 완료까지 추적

4. 흔한 실수

  • '보여주기'식 재발방지 대책 — 실제 효과 없음
  • 1회성 교육으로 종결 — 정례화 필요
  • 내부 감사 결과 후속 조치 없음 — 무용지물
  • ISMS-P 인증만 목표로 삼고 실제 보안 수준 개선 소홀

5. 전문가 상담 신호

위험도: 상담 권장

  • ISMS-P 인증 의무 대상 해당 여부가 불확실한 경우
  • 재발방지 대책에 상당한 예산·조직 개편이 필요한 경우
  • 사고 원인 분석에 외부 전문가가 필요한 경우

6. 인접 절차 연결

선행: PROC-PRIV-011(시정명령·개선계획) · 후속: 정기 점검·갱신 사이클
