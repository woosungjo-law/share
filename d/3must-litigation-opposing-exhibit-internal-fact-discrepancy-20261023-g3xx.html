상대방 자료와 사내 설명이 맞지 않을 때 사실관계를 재확인할 때

적용 상황: 분쟁 대응 중 상대방이 제시한 자료와 사내에서 파악한 설명이 서로 다를 때, 특정인을 탓하거나 결론을 서두르기 전에 자료의 출처와 누락된 경위를 다시 확인한다.

Must Know · 알아야 할 것

  • 자료의 불일치는 누락·은폐·허위 설명을 곧바로 뜻하지 않는다. 자료 작성 시점, 보유 부서, 대화 맥락과 버전을 확인하기 전에는 원인을 단정하지 않는다.
  • 이 카드는 사실을 다시 수집하고 차이를 기록하는 절차다. 증거의 법적 효력, 제출 의무, 소송 전략이나 개인 책임을 판단하지 않는다.

Must Check · 확인할 것

  • 상대방 자료가 언제·어떤 경로로 확보되어 전달되었는지, 현재 받은 파일과 원본·사본 구분을 기록했는가?
  • 차이가 나는 문장·날짜·첨부·발신수신자를 특정하고, 사내 설명의 근거 자료와 나란히 놓았는가?
  • 관련 기간·거래·키워드·시스템을 업무상 필요한 범위로 한정하고, 자료 보유 부서와 시스템 담당자를 확인했는가?
  • 면담 대상자별로 직접 본 사실, 전해 들은 내용, 기억이 불확실한 부분을 구분해 기록했는가?
  • 개인정보·영업비밀·사건 관련 자료의 접근 범위와 검색 권한을 담당자에게 확인했는가?
  • 각 자료의 파일명·작성일·버전·보유처와 아직 확인되지 않은 항목을 남겼는가?

Must Do · 실행할 것

  1. 발견된 불일치를 중립적인 질문으로 바꾼다. 예: “이 날짜의 회신이 현재 전달된 메일 묶음에 포함되지 않은 경위를 확인할 수 있을까요?”
  2. 상대방 자료와 사내 자료를 각각 원래 받은 상태로 보관하고, 어느 쪽도 덮어쓰거나 수정하지 않는다.
  3. 차이점 표에 항목, 각 자료의 출처·날짜·보유처, 확인된 사실, 설명자의 진술, 미확인 사항을 분리해 적는다.
  4. 관련 부서와 시스템 담당자에게 범위가 정해진 검색·확인을 요청한다. 필요한 경우 접근권한과 개인정보·영업비밀 검토를 먼저 거친다.
  5. 당사자별 면담은 열린 질문으로 진행하고 답변의 근거 자료와 기억의 한계를 함께 기록한다. 특정 답변을 강요하거나 사후에 문안을 맞추지 않는다.
  6. 새 자료가 기존 설명과 다시 충돌하면 불일치 자체를 기록하고, 사건 담당 법률전문가에게 새로 확인된 사실과 미확인 부분을 함께 전달한다.
