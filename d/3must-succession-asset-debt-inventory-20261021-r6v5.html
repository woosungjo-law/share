3MUST · 가족·상속법

상속개시 소식을 듣고 재산과 채무 정리를 시작할 때

적용 상황: 가족의 상속개시 소식을 듣고, 회사·개인 재산과 채무를 정리해 다음 절차를 준비해야 할 때 법무 담당자가 임직원·가족의 초기 정리를 도울 때 사용합니다.

Must Know · 알아야 할 것

  • 무엇을 했는지가 결과를 바꿉니다. 정리라며 재산을 처리하면 선택의 폭이 좁아질 수 있습니다.
  • 법정 기한 안에 선택이 필요한 절차가 있으므로, 정확한 기한은 가정법원·전문가 확인으로 특정합니다.
  • 이 단계의 임무는 선택이 아니라 재산·채무·가족 관계의 정확한 수집입니다.
  • 규모가 불확실할수록 '모르는 상태로 기한 넘기기'가 가장 위험합니다. 불확실하면 상담을 앞당깁니다.
  • 보증·연대채무처럼 눈에 보이지 않는 채무가 큰 경우가 있습니다. 범위를 넓혀 점검합니다.

Must Check · 확인할 것

  • 상속개시 사실과 시점, 이를 안 날짜 — 공식 문서로 확인
  • 상속재산 목록 — 부동산, 예금·투자, 자동차, 보험, 채권, 사업 지분
  • 상속채무 목록 — 대출, 보증, 미납 세금·공과금, 미지급 대금
  • 파악이 어려운 항목 — 공유자산, 해외 자산, 보증 채무
  • 이미 수행된 재산 관련 처분 행위 — 매각, 인출, 이전 (시점·경위 기록)
  • 가족 관계와 상속인 전원의 확인 여부
  • 외부 상담용 기본 서류 — 신분증명, 가족관계증명, 재산·채무 증빙

Must Do · 실행할 것

  1. 상속개시 사실과 안 날짜를 문서로 기록하고 가족 내 담당자 지정
  2. 재산·채무 목록을 아는 범위에서 먼저 작성하고 빠진 항목 점검 주기 설정
  3. 외부 상담 전에는 재산 처분 보류 — 필요하면 사유와 범위를 문서화
  4. 신용 정보·공적 기록 조회로 채무 범위 점검, 보증·연대채무를 거래처에 확인
  5. 목록을 지참해 외부 전문가(변호사·세무사) 상담 예약, 예약까지 기간도 기록
  6. 가족 전원에게 목록과 다음 일정 공유 — 정보 비대칭은 이견의 주원인
잠깐 멈추고 검토할 때채권자 추심이나 가압류·경매 진행 정황이 보일 때, 재산 대부분이 특정 자산에 몰려 평가가 필요할 때, 가족 내 상속인 범위에 이견이 있거나 찾지 못한 상속인이 있을 때, 기한이 얼마 남지 않았다는 사실을 뒤늦게 알았을 때에는 정리보다 즉시 전문가 상담과 특별 검토 경로 확인이 우선합니다.
