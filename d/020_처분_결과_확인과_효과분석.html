처분 결과 확인과 효과 분석

3줄 요약

- 인허가·행정처분 결과는 인용·거부·조건부 인용·일부 인용 등 다양한 형태로 나뉘며, 결과 유형별 후속 조치가 다르다.

- 인용 시 부관·조건부 부과 여부를 확인하고, 거부 시 불복 기간·재신청 가능성을 검토한다.

- 결정문 수령일을 기준으로 불복·재신청·이행 기간이 기산되므로 수령일을 반드시 확정한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 결정)


(앞선 대응 단계) -> [처분 결과 확인] -> 조건부·부관 대응(021)

1. 이번 단계에서 반드시 할 일

- [ ] 결정문 수령일·방식(등기·직접·전자) 확인

- [ ] 결과 유형 분류(인용·거부·조건부·일부·취하·각하)

- [ ] 부관·조건·기한·의무 부과 여부 확인

- [ ] 인용 시 사후 이행 의무(보고·검사·유지) 파악

- [ ] 거부 시 불복 기간·재신청 가능성 검토

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 결정문을 수령하고도 불복 기간을 놓침 — 불변기간 도과

- 조건부 인용의 조건 이행 기한을 인지하지 못함 — 허가 취소 사유

- 결정문 수령일을 분실·미확인 — 기간 산정 분쟁

- 거부 사유를 분석하지 않고 무조건 불복 진행

5. 전문가 상담 신호

위험도: 혼자 가능

- 거부 사유가 법리 해석에 관한 복잡한 쟁점인 경우

- 조건부 인용의 조건 이행이 현실적으로 곤란한 경우

6. 인접 절차 연결

선행: 019 · 후속: 021 조건부 인허가·부관 대응
