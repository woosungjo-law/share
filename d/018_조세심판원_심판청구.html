조세심판원 심판청구

3줄 요약

- 조세심판원 심판청구는 국세청으로부터 독립된 기관이 심리하는 절차로, 심사청구보다 객관성과 전문성이 높다.

- 심사청구를 거친 후(필수) 심판청구를 할 수 있으며, 심판청구의 기각 결정에도 불복하면 행정소송을 제기할 수 있다.

- 심판청구는 전문적인 세무 법리 검토가 필요하므로 변호사·세무사의 조력이 필수적이다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


이의신청·심사청구(017) -> [조세심판원 심판청구] -> 행정소송 제기(019)

1. 이번 단계에서 반드시 할 일

- [ ] 심판청구 요건 확인(심사청구 경유·90일 기한)

- [ ] 심판청구서 작성(청구 취지·이유·증빙)

- [ ] 변호사·세무사 선임(심판청구는 전문성 필수)

- [ ] 심리 진행(서면 심리·구술 심리 대비)

- [ ] 결정문 수령·분석·후속 전략 수립

2. 준비물

준비물왜 필요한가준비 상태
심사청구 결정서(기각 결정)심판청구 경유 요건 충족 확인미확인
심판청구서 양식(조세심판원)청구서 작성미확인
쟁점별 법리 검토 의견서(변호사·세무사)청구 이유 법리 주장미확인

3. 작성·제출물

문서제출처주의점
심판청구서조세심판원청구 기한(기각 결정 통지일 90일) 엄수
법리 의견서·증빙 자료조세심판원쟁점별 체계적 정리·제출
참고인 진술(필요 시)조세심판원구술 심리 시 활용

4. 흔한 실수

- 심사청구 없이 바로 심판청구 — 각하 사유

- 심판청구 기한(90일) 도과 — 권리 소멸

- 전문가 선임 없이 직접 청구·심리 대응 — 법리 주장 부실

- 심판청구 결정에 불복하지 않고 종료 — 행정소송으로 이어갈 지 검토 필요

5. 전문가 상담 신호

위험도: 전문가 필요

- 조세심판원 심판청구는 변호사·세무사 선임 필수 수준

- 쟁점이 복잡·다수이고 추징 세액이 큰 사안

- 심판청구 기각 시 행정소송 제기까지 고려

6. 인접 절차 연결

선행: 017 · 후속: 019 행정소송 제기
