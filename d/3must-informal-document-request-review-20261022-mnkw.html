비공식 자료 요청을 받았을 때 제공 전 점검할 것

적용 상황: 상대방이 “참고용”, “비공식”, “잠깐만”이라는 조건으로 내부 자료를 요청했을 때 사용합니다.

Must Know · 알아야 할 것

  • 비공식이라는 말만으로 자료의 사용·보관·재제공을 통제할 수 있다고 가정하지 않습니다.
  • 제공 전 목적, 범위, 민감도, 검토 이력, 조건과 승인자를 정합니다.
  • 변호인 의견서·내부 법률검토·전략자료는 일반 현황자료와 같은 등급으로 다루지 않습니다.

Must Check · 확인할 것

  • 요청자·요청 목적·필요 자료·사용 기간을 문서로 받았는가
  • 자료에 내부 법률검토·전략·개인정보·영업비밀이 포함되는가
  • 제공 등급과 법무 승인자가 정해졌는가
  • NDA 또는 자료 제공 조건 합의서가 체결되었는가
  • 제공 범위·목적·금지 사용·반환·폐기 조건이 명시되어 있는가
  • 제공 파일·일시·경로·수령자를 기록할 수 있는가

Must Do · 실행할 것

  1. 구두 요청에 즉시 응하지 말고 요청 목적과 자료 목록을 서면으로 받습니다.
  2. 자료를 제공 불가·조건부·제공 가능으로 분류하고 법무 승인을 받습니다.
  3. 조건부 제공이면 NDA 또는 합의서에 목적·범위·복제·재제공·반환·폐기 조건을 적습니다.
  4. 제공본에서 불필요한 자료를 제거하고 버전·파일목록을 확정합니다.
  5. 제공 시각·수령자·경로·조건을 기록하고 회수·폐기 확인 일정을 등록합니다.
  6. 조건 위반이나 오제공이 발견되면 즉시 법무에 보고하고 회수·파기 요청 여부를 검토합니다.
