3MUST · 특수법률

하도급사가 발주자인 우리 회사에 직접 지급을 요청했을 때

적용 상황: 현장 하도급사가 원사업자로부터 대금을 받지 못했다며 발주자인 우리 회사에 직접 지급을 요청했거나, 공사 중단을 이유로 즉시 지급을 압박하는 경우. 범위: 직접지급 요건의 성립 여부와 지급 의무의 범위를 판단하지 않습니다. 요청 접수 후 확인해야 할 자료, 보류 기준, 보고·회신 절차를 다룹니다.

Must Know · 알아야 할 것

  • 직접 지급 요청은 단순 독촉이 아닙니다. 요건과 지급 범위를 확인하지 않고 지급하면 이중지급 위험이 생깁니다.
  • 공사 중단을 막아야 한다는 요구와 이중지급을 피해야 한다는 요구는 충돌합니다. 둘 중 하나를 즉흥적으로 고르지 말고 조건부 지급 범위를 먼저 계산합니다.
  • 판단 축은 다섯 개입니다. 적용 대상인지, 지급 사유가 있는지, 요청이 언제 도달했는지, 원사업자에게 줄 잔대금이 얼마인지, 선행 압류·양도 통지가 있는지입니다.
  • 이미 원사업자에게 지급한 금액이 정리되지 않으면 지급 가능 범위를 계산할 수 없습니다. 재무 자료가 먼저입니다.
  • 요청 도달일은 나중에 다툼이 됩니다. 접수 경로와 시각을 원본 그대로 남깁니다.

Must Check · 확인할 것

  • 요청서의 발신자·청구 금액·청구 사유·도달일을 표로 옮겼는가(내용증명·이메일·접수대장 원본 포함).
  • 원도급계약·하도급계약 구조와 당사자 규모 자료로 적용 대상 여부를 확인할 수 있는가.
  • 미지급 내역(회차·금액·기성검사 여부)과 지급불능 관련 자료가 있는가.
  • 원사업자에 대한 기지급액·잔대금·정산 예정액이 재무에서 확인됐는가.
  • 원사업자 채권자들의 압류·가압류·채권양도 통지가 있는지, 있으면 금액과 순서를 확인했는가.
  • 기성검사 미완료·하자보수·계약상 항변 등 지급을 보류할 사유가 있는가.
  • 요청에 대한 회신 담당과 회신 기한이 정해져 있는가.

Must Do · 실행할 것

  1. 사업부는 요청을 받은 당일 법무·재무에 공유하고, 요청서 사본을 원본 형태로 보관합니다.
  2. 재무는 기지급액 / 잔대금 / 압류·가압류 / 양도통지를 동결 기준으로 정리해 법무에 넘깁니다.
  3. 법무는 다섯 축 표를 만들어 확인됨 / 미확인 / 해당 없음으로 채웁니다. 미확인 항목이 남아 있으면 지급 보류로 표시합니다.
  4. 지급 전에는 원사업자·수급사업자에게 각각 회신해, 확인 중이라는 사실과 확인 항목·회신 예정 시점을 남깁니다.
  5. 임원 보고에는 공사 중단 위험 / 이중지급 위험 / 확인 필요 항목 / 권고안을 함께 적습니다.
  6. 확인이 끝나면 지급 가능 범위와 조건(항변·공제·보증)을 문서로 확정하고, 지급 실행일과 승인자를 기록합니다.
잠깐 멈추고 검토할 때

이미 원사업자나 수급사업자에게 대금이 지급된 경우 · 복수의 압류·가압류가 경합하거나 채권양도 통지가 있는 경우 · 요청 도달일을 두고 다툼이 있는 경우 · 공사 중단이 임박해 조건부 지급 여부를 즉시 결정해야 하는 경우 · 원사업자의 지급불능·회생 신청 등으로 다른 거래처에도 같은 상황이 번질 수 있는 경우
