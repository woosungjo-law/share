사전컨설팅·사전협의 제도 활용

3줄 요약

- 많은 규제기관이 정식 신청 전 사전컨설팅·사전협의 제도를 운영한다. 이를 활용하면 요건·절차를 미리 확인해 신청 리스크를 줄일 수 있다.

- 사전협의는 공식(유권해석·심의청구)과 비공식(실무자 면담·사전질의)으로 나뉘며, 단계별로 활용한다.

- 사전협의 결과는 법적 구속력이 제한적일 수 있으나, 기관의 실무적 입장을 확인하는 데 유용하다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사전)


리스크 탐지(004) -> [사전컨설팅·사전협의] -> 법률 리스크 평가(006)

1. 이번 단계에서 반드시 할 일

- [ ] 소관 기관의 사전컨설팅·사전협의 제도 존재 여부 확인

- [ ] 공식 협의(유권해석·사전심사)와 비공식 협의(실무자 질의) 경로 파악

- [ ] 질의서·설명자료 작성(핵심 쟁점·사실관계·법리 검토 포함)

- [ ] 협의 결과 기록·관리

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 비공식 협의 결과를 법적으로 확정된 것처럼 오해

- 사전질의 시 불리한 사실을 축소·은닉 — 이후 신청서와 상충 시 신뢰 하락

- 협의 결과를 문서로 남기지 않음 — 추후 기관 입장 변경 시 증빙 곤란

- 협의 단계에서 기관 담당자와 불필요한 마찰

5. 전문가 상담 신호

위험도: 혼자 가능

- 사전협의 결과가 불리하게 나와 대응 전략 전환이 필요한 경우

- 법적 유권해석이 필요한 쟁점이 포함된 경우

6. 인접 절차 연결
