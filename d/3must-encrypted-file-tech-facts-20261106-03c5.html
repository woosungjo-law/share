3 MUST · TECHNICAL FACT CHECK

암호화된 파일이 외부로 나갔을 때 기술 사실을 확인할 때

파일이 외부로 전송되었거나 저장소 밖에서 발견된 상황에서 파일·암호화 설정·키 접근·반출 경로를 사실과 근거에 따라 정리합니다.

범위 기술 사실을 수집하고 기록합니다. 유출의 법적 분류, 신고·통지 여부와 기한, 책임·감경 효과는 판단하지 않습니다.

Must Know · 먼저 알아야 할 것

  • 파일이 암호화됐다는 설명만으로 실제 상태를 단정하지 않습니다.
  • 파일 접근과 키 접근을 별도로 확인합니다.
  • 원자료·담당자 설명·미확인 사항을 구분합니다.

Must Check · 반드시 확인할 것

  • 파일 식별자·위치·최초 확인 시각
  • 당시 암호화 설정·제품·버전과 근거 자료
  • 키 보관 위치·담당 시스템·접근 권한
  • 반출 시각·경로·계정·전송 로그
  • 키·비밀번호·인증정보 접근 흔적
  • 확인 사실·진술·미확인 항목 구분

Must Do · 지금 할 일

  1. 파일명 대신 내부 식별자를 쓰고 대상과 확인 시각을 기록합니다.
  2. 파일이 있던 시스템과 외부 반출 경로, 관련 로그 위치를 연결합니다.
  3. 해당 시점의 암호화 설정과 키 보관 위치를 확인합니다. 현재 화면만으로 과거 상태를 단정하지 않습니다.
  4. 파일·키 접근 기록을 나눠 시각·계정·작업 결과를 표로 정리합니다.
  5. 원자료와 확인용 사본을 구분해 보존하고 자료 위치·담당자를 남깁니다.
  6. 자료가 없거나 불일치하면 미확인으로 표시해 기술 담당자에게 넘깁니다.
