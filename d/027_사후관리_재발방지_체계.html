사후관리·재발방지 체계

3줄 요약

- 인허가 취득·행정처분 종료 후에도 사후 이행 의무(보고·검사·유지)와 재발방지 체계를 지속 관리해야 한다.

- 처분 원인이 된 위반 사항의 근본 원인을 분석하고, 재발방지 대책을 수립·이행한다.

- 사후관리 소홀로 인한 추가 제재를 방지하기 위해 정기 모니터링 체계를 구축한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사후)


재신청 전략(026) -> [사후관리·재발방지] -> 위기대응 매뉴얼(028)

1. 이번 단계에서 반드시 할 일

- [ ] 인허가·처분 관련 사후 이행 의무 목록화(보고·검사·시설유지·교육)

- [ ] 이행 의무별 담당자·일정·증빙 체계 수립

- [ ] 처분·제재의 근본 원인 분석(Root Cause Analysis)

- [ ] 재발방지 대책 수립·이행(내부 통제 강화·교육·모니터링)

- [ ] 정기 점검·감사 체계(분기·반기) 구축

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 인허가 취득 후 사후 의무 관리 소홀 — 허가 취소·제재

- 처분 원인 분석 없이 재발방지 대책 수립 — 근본 원인 미해결

- 재발방지 대책을 수립만 하고 이행·점검 부재

- 법무팀 단독으로 관리 — 현업 참여 부재로 실효성 저하

5. 전문가 상담 신호

위험도: 혼자 가능

- 반복적·유사 위반이 발생하고 있는 경우
