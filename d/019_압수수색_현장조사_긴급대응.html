압수수색·현장조사 긴급대응

3줄 요약

- 압수수색(형사)과 현장조사(행정)는 법적 근거·절차·권한이 다르므로 초동 대응부터 구분해야 한다.

- 현장에서는 임의제출 거부권·변호인 입회권·진술거부권을 행사하고, 조사관의 권한·범위를 확인한다.

- 모든 상황을 기록하고, 임직원 개별 응대·즉답을 금지하며 단일 창구(법무팀)로 통일한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 대응)


시정조치(018) -> [압수수색·현장조사 긴급대응] -> 처분 결과 확인(020)

1. 이번 단계에서 반드시 할 일

- [ ] 압수수색(영장) vs 현장조사(행정조사) 구분

- [ ] 영장·증표·조사 범위 확인 및 사진 촬영

- [ ] 변호인 즉시 연락·입회 요청

- [ ] 자료보존(Legal Hold) 발동

- [ ] 임직원 대상 현장 대응 요령 전파(즉답 금지·단일 창구)

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 압수수색과 행정조사를 혼동해 대응 — 권리 행사 타이밍 상실

- 영장 없이도 임의제출 동의 — 불필요한 증거 제공

- 현장에서 직원 개별 진술 — 내부 입장 차이 노출

- 전자정보 압수 시 범위 협의 없이 전체 하드디스크 제공

- 압수수색 후 사후 대응(압수물 반환·이의신청)을 검토하지 않음

5. 전문가 상담 신호

위험도: 전문가 필요

- 압수수색과 행정조사가 동시에 진행되는 경우

- 전자정보 대량 압수 시 범위 협의·필터링이 필요한 경우

- 임원·핵심 관계자가 조사 대상인 경우

6. 인접 절차 연결

선행: 018 · 후속: 020 처분 결과 확인과 효과 분석
