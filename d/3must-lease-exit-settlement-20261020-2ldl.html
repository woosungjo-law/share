3MUST · 부동산법

임대차가 끝나 명도와 보증금 반환을 정리할 때

적용 상황: 사옥·사무실 임대차가 만료·해지되어 임차인이 보증금 반환을 요구하고, 임대인 측에서 원상회복·연체료를 이유로 공제를 주장하는 경우. 범위: 동시이행 관계의 법리, 지연손해금 기산점, 공제 항목의 정당성은 판단하지 않습니다. 종료일 확정, 정산표 작성, 이행 제공 증거 확보, 통지 절차를 다룹니다.

Must Know · 알아야 할 것

  • 임차인이 나가야 하는 의무와 임대인의 보증금 반환 의무는 따로 움직이지 않습니다. 먼저 이행해야 하는 쪽을 정하지 않으면 지연 책임의 기산점이 흔들립니다.
  • 보증금을 돌려주지 않으면 임차인이 곧바로 불법점유자가 된다고 단정할 수 없습니다. 이 오해가 분쟁을 키웁니다.
  • 종료 사유에 따라 기준일이 달라집니다. 기간 만료인지, 해지 통지인지, 합의 해지인지 먼저 확정합니다.
  • 공제 항목은 근거 자료가 있어야 합니다. 견적·사진·계산서 없이 금액만 제시하면 협상에서 밀립니다.
  • 명도 제공은 객관적으로 남겨야 합니다. 열쇠 반환, 출입 비밀번호 전달, 잔존물 정리 확인서가 그 증거입니다.

Must Check · 확인할 것

  • 종료일과 종료 사유(만료·해지·합의)를 계약서·통지서로 확인했는가.
  • 종료일 기준 보증금 잔액과 연체 차임·관리비를 계산했는가.
  • 원상회복 범위와 공제 항목별 근거(견적·사진·시공 기록)가 있는가.
  • 종료일 이후 점유 기간에 대한 사용료 상당액을 일 단위로 계산했는가.
  • 임차인이 이행을 제공한 사실(열쇠·출입권한·잔존물)이 기록으로 남아 있는가.
  • 반환·공제 금액과 지급 시점을 문서로 통지했는가.
  • 계약서의 원상회복·정산 특약이 현재 계산과 어긋나지 않는가.
  • 분쟁이 길어질 경우 보증금과 미납액의 상계 순서를 어떻게 설명할지 정했는가.

Must Do · 실행할 것

  1. 담당자는 종료일·보증금·연체액·공제 항목·사용료 상당액을 한 장 정산표로 만듭니다.
  2. 정산표에서 즉시 반환 / 조건부 공제 / 다툼 있는 항목을 구분해 표시합니다.
  3. 임차인과 협의해 명도 일정과 검사 방식을 정하고, 검사 결과를 사진과 확인서로 남깁니다.
  4. 명도 제공과 동시에 반환할 금액·공제 내역·지급일을 서면으로 통지합니다.
  5. 다툼이 있는 항목은 별도 목록으로 분리해 조정·소송 여부를 검토합니다.
  6. 종결 후 실제 반환·지급 내역과 잔존 분쟁을 기록해 계약 종료 처리를 마무리합니다.
잠깐 멈추고 검토할 때

임차인이 보증금 반환 없이 먼저 명도하라는 요구에 반발하는 경우 · 원상회복 공제액이 보증금의 상당 부분을 차지하는 경우 · 임차인이 이미 다른 곳으로 이전해 연락이 어려운 경우 · 전대차·무단 점유자·권리금 회수 요구가 섞여 있는 경우 · 보증금 일부가 다른 채권의 압류 대상이 된 경우
