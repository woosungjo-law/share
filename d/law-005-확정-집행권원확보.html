확정과 집행권원 확보

3줄 요약

  • 이의가 없거나 이의 취하·각하 확정 시 지급명령은 확정판결과 같은 효력이 있다.
  • 확정 여부와 송달·확정 관련 서류를 확보한다.
  • 집행 전 채무자 재산과 집행 대상의 특정이 필요하다.

0. 지금 당신의 위치

대응: 이의신청 확인 → [확정·집행권원] → 집행 연계(006)

1. 이번 단계에서 반드시 할 일

  • 이의신청 유무·취하·각하 확정 확인
  • 확정 지급명령 및 필요한 증명서 보관
  • 채무자 재산·집행 대상 조사

2. 준비물

준비물 왜 필요한가 준비 상태
지급명령·송달·확정 자료 집행권원 확인 확인
재산·채권 정보 집행 대상 특정 확인

3. 작성·제출물

문서 제출처 주의점
집행문·확정 관련 서류 집행기관 사건별 필요서류 확인

4. 흔한 실수

  • 지급명령 발령만으로 확정됐다고 판단 — 이의 기간 확인 누락
  • 집행 대상 없이 집행 신청 — 비용·시간 손실

5. 전문가 상담 신호

위험도: 상담 권장 — 확정 여부나 집행서류가 불명확한 경우

6. 인접 절차 연결

선행: PROC-ORDR-004 · 후속: PROC-ORDR-006 / PROC-EXEC

7. 근거 조문·판례

근거 의미 검증상태
민사소송법 제474조 지급명령의 확정판결과 같은 효력 MCP 통과(L2)
민사집행법 제56조 제3호 확정 지급명령의 집행권원성 MCP 통과(L2)

8. 다음 단계

상담 CTA

지급명령·송달·확정 자료와 재산정보를 준비해 집행 가능성 상담을 신청한다.
