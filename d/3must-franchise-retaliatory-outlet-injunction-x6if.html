분쟁조정 신청 후 보복성 중복출점 — 위법성 판단과 출점금지 가처분 대응

적용 상황: 분쟁조정을 신청한 직후 본사가 인근에 동일·유사 업종 점포 개설을 추진하고, 출점금지 가처분을 검토하는 경우

Must Know · 알아야 할 것

보복조치 금지(가맹사업법 제12조의5, 원자료 기준): 분쟁조정 신청 이유 불이익·계열회사·타 사업자 통한 보복 금지. 불이익은 예시에 한정되지 않고 실질 판단(의도·경위·내용·정도 종합). 보복성 핵심: 조정 이후 근접 출점이 보복조치로 기능하는지(시점·내부문건·차별). 가처분 관건은 권리+보전 필요성 소명. 제12조의5 위반 시 제37조의2 3배 배상.

Must Check · 확인할 것

  • 조정 신청일·출점 의사 표시일·계약일·공사 착수일 일자별 정리("신청 직후 급가속" 유리)
  • 내부 지시·가맹모집 공지·통화 녹취·"취하하면 조정" 발언 등 보복 동기 정황 확보
  • 매출 하락 예상·상권 중첩(거리·배달권역)·지원·공급 축소 내역 정리
  • 영업지역 내 유사 점포 설치가 '영업지역 침해'인지 검토
  • 가처분 청구취지 "출점 중지"(필요 시 공급·지원 제한 중지 병합) 설계
  • 계속 영업 의사·준비 상태 구체 소명 자료(보전 필요성 핵심)
  • 손해 항목(매출감소·고정비·폐기비) 초기 분리 산정

Must Do · 실행할 것

  1. 타임라인 즉시 고정: 신청일→출점표시일→계약일→공사착수일 일자별 정리(급가속이 승부처)
  2. 보복 동기 증거 확보: 내부지시·모집공지·녹취·"취하하면 조정" 정황증거
  3. 불이익 실질 입증: 매출하락 예상·상권중첩·지원공급 축소 내역 제시
  4. 가처분 설계: 출점 중지(+필요 시 공급·지원 제한 중지 병합), 계속 영업 의사·준비 상태 명확 소명
  5. 손해배상 병행: 보복 인정 시 3배 범위 대비, 매출감소·고정비·폐기비용 조기 분리
잠깐 멈추고 검토할 때가처분이 왜 급한가요? 출점·공사 진행되면 회복 어려움 — 보전 필요성 소명이 관건, 보복인지 어떻게 입증? 신청 직후 급가속 + 내부문건·차별 = 강력한 정황증거, 무엇을 소명? 권리+보전 필요성, 특히 계속 영업 의사·준비 상태 구체적으로, 손해배상은? 보복 인정 시 3배 범위, 매출감소·고정비·폐기비 초기 분리
