외부 로펌 자문을 받을 때 보고 경로와 내부 검토를 정할 때

적용 상황: 회사가 외부 로펌 자문을 여러 부서·경영진과 공유하면서 사실과 선택지를 일관되게 검토해야 할 때 사용한다.

Must Know · 알아야 할 것

  • 외부 자문은 어떤 질문과 사실을 검토했는지, 누가 내부에서 확인하고 의사결정 자료로 전달했는지 함께 남겨야 한다.
  • 내부 보고 경로는 조직의 승인 체계에 맞춰 정한다. 로펌·임직원의 직접 연락 자체가 위법하거나 계약 위반이라고 단정하지 않는다.

Must Check · 확인할 것

  • 의뢰 담당자, 자문 수신자, 내부 검토자와 최종 의사결정자를 지정했는가?
  • 외부 로펌과 합의한 정기 보고 방식·긴급 연락 경로·산출물 전달 경로가 기록돼 있는가?
  • 자문 결과가 어느 사실관계와 질문 범위를 전제로 하는지 표시돼 있는가?
  • 경영진 보고에 주요 가정·불확실성·추가 확인 항목이 함께 들어가는가?
  • 자문 원본·내부 요약·결정 기록의 접근 권한과 보관 위치가 정해져 있는가?

Must Do · 실행할 것

  1. 의뢰 시작 때 내부 창구와 자문 전달 방식을 로펌 및 관련 부서에 공유한다.
  2. 자문 질문·첨부 사실자료·요청 산출물·기한을 한 곳에 기록한다.
  3. 회신을 받은 법무팀은 질문 범위와 사실 전제가 맞는지 확인하고 추가 질문을 표시한다.
  4. 경영진에는 자문 원문을 임의로 결론화하지 말고 쟁점·선택지·미확인 사실을 구분해 보고한다.
  5. 회의에서 나온 추가 지시와 결정, 후속 담당자·기한을 같은 업무 기록에 연결한다.
잠깐 멈추고 검토할 때
