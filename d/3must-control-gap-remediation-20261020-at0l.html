3MUST · 금융·투자법

내부통제 점검에서 미흡사항이 확인됐을 때

적용 상황: 준법·감사·운영 점검에서 내부 절차가 누락되거나 실제 이행 기록이 부족한 점이 발견된 경우. 범위: 금융규제 위반 여부나 이사·회사 책임을 판단하지 않습니다. 발견사항의 기록·영향 확인·개선조치 추적에 한정합니다.

Must Know · 알아야 할 것

  • 규정이 있다는 사실과 실제 실행 기록은 별도로 확인합니다.
  • 미흡사항을 발견하면 원본 기록을 보존하고, 사후에 과거 기록을 보완해 당시 실행처럼 보이게 만들지 않습니다.

Must Check · 확인할 것

  • 발견된 업무·시스템·기간·대상과 점검 방법을 구체적으로 기록합니다.
  • 규정·교육·권한 설정·실제 로그·승인·보고 기록을 서로 대조합니다.
  • 영향 범위와 계속 진행 중인 위험을 운영 책임자와 확인합니다.
  • 임시 통제, 담당자, 완료 목표일과 잔여 위험의 승인자를 지정합니다.
  • 개선 후 작동 확인 방법과 재점검 일정을 정합니다.

Must Do · 실행할 것

  1. 점검자는 원본 로그·보고서·교육 이력·운영 기록을 보존하고 발견 시점을 남깁니다.
  2. 준법·운영 책임자는 현재 위험을 낮추는 임시 조치를 정하고 적용 범위를 기록합니다.
  3. 원인·영향 분석과 시정조치마다 책임자·완료 증거·검증자를 지정합니다.
  4. 개선 결과는 실제 로그나 샘플 확인으로 검증하고, 실패하면 조치를 다시 엽니다.
  5. 중요한 미해결 위험은 정해진 내부 보고선에 올리고 결정과 수용 사유를 기록합니다.
잠깐 멈추고 검토할 때

고객·시장·자산에 영향을 주는 진행 중인 위험이 발견된 경우 · 보고·기록이 없거나 사후 변경 정황이 있는 경우 · 규제기관 문의·검사·자료제출 요청이 시작된 경우
