저작권 침해 주장을 받거나 침해를 발견했을 때 대조할 것

적용 상황: 우리 콘텐츠를 무단 사용했다는 연락을 받았거나, 반대로 우리 콘텐츠가 다른 곳에서 쓰이는 것을 발견해 무엇을 확인할지 정리해야 할 때

Must Know · 알아야 할 것

  • 저작권 문제는 "누가 권리자인지"와 "무엇을 얼마나 썼는지"를 대조하는 일에서 시작합니다. 이 두 가지가 정리되지 않으면 협의도 요청도 진전되기 어렵습니다.
  • 이 카드는 사실관계 대조 절차입니다. 침해인지 아닌지, 인용이 허용되는지, 얼마를 배상해야 하는지는 판단하지 않습니다.

Must Check · 확인할 것

  • 연락을 받은 날짜와 경로(내용증명·이메일·플랫폼 통지)
  • 우리 입장: 권리자인지, 이용자로 지목된 쪽인지
  • 문제 된 콘텐츠의 위치(URL·파일명·게시물)
  • 원저작물의 제목·저작자·공개 시점
  • 우리 쪽 사용 근거: 직접 제작, 허락, 구매, 외주 계약
  • 상대가 요구한 내용(삭제·중단·출처 표시·협의)
  • 상대가 제시한 기한

Must Do · 실행할 것

  1. 우리 입장(권리자·이용자)을 먼저 정하고, 그에 맞춰 확인 항목을 나눕니다.
  2. 문제 된 콘텐츠와 원저작물을 나란히 놓고 화면·파일을 그대로 보관합니다.
  3. 사용 근거 자료(계약서, 라이선스, 구매 내역, 외주 계약)를 찾아 한곳에 모읍니다.
  4. 콘텐츠를 만든 사람과 과정을 확인해 제작 기록을 남깁니다.
  5. 삭제·수정 요청을 받았다면 즉시 지우지 말고, 담당자 확인 후 처리 순서와 시점을 기록합니다.
  6. 상대에게 보낼 답변에는 확인된 사실과 아직 확인 중인 내용을 구분해 적습니다.
  7. 처리 결과(삭제·출처 표시·협의)와 그 근거를 기록으로 남깁니다.
잠깐 멈추고 검토할 때
