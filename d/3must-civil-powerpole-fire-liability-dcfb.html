3MUST · 민사법

전신주 전도·화재 사고 — 여러 당사자 중 누구에게 책임을 물을 수 있나

적용 상황: 트럭이 정차 중인 버스를 충격 → 버스가 인도 전주를 충격 → 전신주가 넘어지며 고압선이 떨어져 공장 화재가 발생한 경우

Must Know · 알아야 할 것

공작물 책임(민법 제758조1항): 설치·보존 하자 시 점유자 배상, 점유자 무과실이면 소유자. 개정 실화책임법은 경감 특례만, 책임 성립은 일반 민법(대법원 2010다71318). 연소 부분도 상당인과관계 있으면 758조 적용(중대 과실 아니면 제3조 경감). '하자'=통상 안전성 미달, 위험성 비례 방호의무(2004다21053). 공동원인 법리(2009다101343·2013다61602). 전주 설치만으로 전력회사 하자 볼 수 없고 버스 충격 예상 안전시설 의무 인정 어려움.

Must Check · 확인할 것

  • 사고 경위(트럭→버스→전주→고압선→화재) 시간순 정리
  • 트럭·버스 운전자 과실(속도·정차·충격)
  • 전주·변압기 설치·보존 하자(노후·부식·고정)
  • 전력회사 전주 충격 예상 안전시설 의무 여부
  • 직접 손해와 연소 손해 구분
  • 실화자 중대 과실 여부(경감 배제)
  • 당사자별 책임 비율(과실상계) 구성

Must Do · 실행할 것

  1. 사고 경위 고정: 트럭→버스→전주→고압선→화재 인과 연쇄를 시간순·객관 자료로
  2. 당사자별 과실 정리: 트럭(속도·추돌), 버스(정차위치·충격), 전력회사(하자·안전시설)
  3. 공작물 하자 입증: 전주·변압기 노후·부식·고정 등 통상 안전성 미달 정황
  4. 실화책임법 검토: 중대 과실 여부, 연소 손해 경감 가능성
  5. 청구 구조 설계: 직접·연소 손해 구분, 당사자별 과실 비율 반영
잠깐 멈추고 검토할 때모두에게 청구되나? 각자 과실·하자로 판단, 전력회사는 전주 설치만으로 인정 어려움, 연소 공장 피해도 배상? 상당인과관계 있으면 대상, 중대 과실 아니면 경감, 핵심 쟁점? 공작물 하자 + 공동원인 + 당사자별 과실비율, 전력회사 책임? 버스 충격 예상 안전시설 의무 인정 어려움, 경감은? 실화자 중대 과실 여부가 관건, 연소 손해 적용
