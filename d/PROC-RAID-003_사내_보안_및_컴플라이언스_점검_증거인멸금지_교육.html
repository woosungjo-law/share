PROC-RAID-003 | 사내 보안 및 컴플라이언스 점검 (증거인멸금지 교육)

3줄 요약

- 압수수색 임박 시점에 자료 삭제·은닉·위조 행위는 형법 제155조 증거인멸죄(5년 이하 징역)로 처벌되며, 법인도 양벌규정으로 책임을 진다.

- IT 부서는 데이터 보존 명령(legal hold)을 즉시 발령하고, 자동 삭제 정책(스케줄러·백업 순환)을 일시 정지해야 한다.

- 전 직원 대상 증거인멸금지 교육을 실시하고, 개인 기기·클라우드·메신저 포함 모든 통신 채널의 데이터 보존을 안내한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


002(영장이해) -> [003(보안점검)] -> 004(임원가이드) -> 005(현장대응)

1. 이번 단계에서 반드시 할 일

- [ ] IT 부서에 구두·서면 '데이터 보존 명령(Legal Hold)' 발령 — 서버·DB·메일·메신저(카카오톡·잔디·슬랙)의 자동 삭제 스케줄러·로그 순환·백업 덮어쓰기 즉시 중단

- [ ] 형법 제155조 증거인멸죄의 구성요건과 법정형(5년 이하, 모해 목적 시 10년 이하)이 포함된 '증거인멸금지 안내문'을 전 직원 이메일 발송

- [ ] 각 부서별 보관 중인 문서·파일·회계자료의 현황을 리스트업하고, 삭제 이력(audit log)을 원격지에 백업

- [ ] 개인 이메일·클라우드(드라이브·원드라이브·AWS S3)에 저장된 업무자료의 중앙화 및 접근 권한 긴급 정리

- [ ] 사내 CCTV 및 출입카드 로그의 보존 기간(통상 30~60일)과 정상 작동 여부 확인 — 추후 영장 집행 과정의 적법성 입증 자료

- [ ] 법무팀과 IT 보안팀 합동으로 압수 대상이 될 주요 전자정보(회계·계약·이사회 회의록·주요 의사결정 메일)의 위치와 규모 사전 파악

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 실수: '평소 하던 백업 순환(예: 7일 주기 덮어쓰기)이라 문제없다'고 생각하고 중단하지 않음 — 수사 착수 후 덮어쓰기된 자료는 복구 불가, 검찰은 이를 의도적 은닉으로 추정 가능

- 실수: 임원이 개인적으로 관련 자료를 USB·외장하드에 복사해 집으로 가져감 — 설령 방어 목적이라도 형법 제155조 은닉죄 성립 위험

- 실수: 카카오톡 대화방을 정리(삭제)하도록 부서장이 지시 — 메신저 삭제는 가장 흔한 증거인멸 유형으로, 디지털 포렌식으로 복구 시 고의 입증 결정적 단서

- 실수: 수사 소식을 들은 직원이 혼자 판단해 '관련 없는 내 파일'을 지움 — 관련성 판단은 수사기관·법원의 몫, 사전 삭제 자체가 위법

5. 전문가 상담 신호

위험도: 상담 권장

- 이미 일부 자료가 삭제된 사실을 나중에 발견한 경우 — 변호사와 협의해 자진 제출·소명 방안 마련

- 회사가 금융·의료·공공 분야로 개인정보보호법 위반이 중첩될 위험이 있는 경우

위험도: 전문가 필요

- 임원 개인 기기에 업무 자료와 개인 자료가 혼재되어 있고, 해당 임원이 수사 대상자인 경우

- 법률 리스크가 높은 해외 서버(중국·러시아 등)에 데이터가 저장되어 있는 경우

6. 인접 절차 연결

- 선행: PROC-RAID-002(영장이해) — 영장의 압수 대상 범위에 따라 보존 범위 결정

- 후속: PROC-RAID-004(임원가이드) — IT 부서 점검 결과를 임원 가이드에 반영
