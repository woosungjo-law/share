# NDA 아이디어 귀속 분쟁 — 협업 중 나온 아이디어, 소유권은 누구에게?

## TL;DR — 3줄 요약

- NDA(비밀유지계약)는 **비밀유지 의무**를 부과할 뿐, **아이디어의 소유권을 자동으로 귀속시키지 않는다.**
- 협업 중 나온 아이디어의 소유권이 문제될 때, NDA만으로는 부족하고 **IP 귀속 조항(IP Assignment Clause)**이 별도로 필요하다.
- 이 체크리스트는 NDA 체결 전 점검사항, 아이디어 귀속 분쟁의 위험 신호, 첫 대응, 근거 법령·판례를 정리한다.

## 1. 문제상황 — "협업사와 미팅 중 나온 아이디어, 귀속은 누구에게?"

**사례**: 스타트업 A는 협업사 B와의 미팅에서 신규 서비스 기획안을 공유했다. 양측은 NDA를 체결했지만, 아이디어 귀속에 관한 조항은 없었다. 이후 B사가 A사의 아이디어와 유사한 서비스를 독자 출시했다. A사는 NDA 위반을 주장했지만, B사는 "NDA는 비밀유지 의무일 뿐 아이디어 사용 자체를 금지하지 않는다"고 반박했다.

**핵심**: NDA는 상대방이 비밀정보를 누설하지 못하게 막을 뿐, 아이디어 자체의 소유권이나 사용권까지 정하지는 않는다. 별도의 IP 귀속 합의(IP Assignment Agreement) 또는 공동개발 계약(Joint Development Agreement)이 없으면, 협업 중 나온 아이디어의 권리는 누구에게도 명확히 귀속되지 않는다.

## 2. 핵심 쟁점 — NDA의 비밀유지 vs 아이디어 귀속

| 구분 | NDA (비밀유지계약) | IP 귀속 계약 |
|------|-------------------|-------------|
| **목적** | 비밀정보의 누설·사용 금지 | 아이디어·성과물의 소유권 귀속 |
| **적용 범위** | 계약에서 정의된 '비밀정보' | 협업 중 창출된 모든 지식재산 |
| **위반 효과** | 손해배상·가처분 | 소유권 이전 청구·침해 금지 |
| **별도 계약 필요성** | 단독 체결 가능 | IP 귀속 조항 없으면 분쟁 발생 |

### 쟁점 1 — NDA 문언이 '영업비밀'로 한정된 경우

계약상 '영업비밀'을 부정경쟁방지법상 영업비밀과 같은 의미로 해석하면(2022나2016206), 영업비밀 성립요건(비공지성·경제적유용성·비밀관리성)을 충족하지 못한 아이디어는 계약책임도 무너질 위험이 있다.

### 쟁점 2 — 아이디어 자체의 법적 보호

영업비밀 요건을 충족하지 못하는 아이디어는 부정경쟁방지법 제2조 제1호 차목(아이디어 도용)으로 보호받을 수 있다(2020다220607). 단, 구체화된 아이디어에 한하고, 제공목적 위반 부정사용이 입증되어야 한다.

### 쟁점 3 — 구두 계약·이메일만 있는 경우

구두로만 아이디어를 공유하거나 이메일로만 협의한 경우, 제공 기록·회의록·이메일·제공 목적 명시 등이 사후 입증의 핵심 증거가 된다.

## 3. 체크리스트 — NDA 체결 전 점검사항

### 3.1 NDA 기본 점검

- [ ] NDA에 비밀정보 범위가 구체적으로 정의되어 있는가?
- [ ] '영업비밀'에 한정되지 않고 '비공개 기밀정보'로 확장 정의되었는가?
- [ ] 비밀유지 기간이 명시되어 있는가? (계약 종료 후 2~5년)
- [ ] 목적 외 사용 금지 조항이 명확한가?
- [ ] 정보 반환·폐기 의무가 규정되어 있는가?

### 3.2 IP 귀속 점검 (핵심)

- [ ] NDA 또는 별도 계약에 **IP 귀속 조항(IP Assignment Clause)**이 있는가?
- [ ] 협업 중 창출된 아이디어·성과물의 소유권 귀속 주체가 명시되어 있는가?
- [ ] 공동 개발인 경우 공동 소유 조건(지분·실시권·수익 배분)이 정해져 있는가?
- [ ] 사전 보유 기술(Background IP)과 협업 중 창출 기술(Foreground IP)이 구분되어 있는가?
- [ ] 상대방의 기존 지식(Pre-existing Knowledge) 예외 조항이 있는가?
- [ ] 공동 개발 결과물의 제3자 라이선스·재사용 조건이 명시되어 있는가?

### 3.3 공동 개발 vs 단독 개발

- [ ] 양측이 각자의 아이디어를 기여하는 구조인가? → 공동 개발 계약 필요
- [ ] 일방이 아이디어를 제공하고 상대방이 실행하는 구조인가? → IP 귀속 조항 중심
- [ ] 용역·위탁 관계인가? → 저작권법상 창작자 귀속 원칙, 별도 약정 필요
- [ ] 공동 연구·공동 개발 시 Joint IP Agreement 체결 여부 확인

## 4. 위험 신호 — 아이디어 귀속 분쟁의 전조

### 위험 신호 1: 귀속 조항이 전혀 없는 NDA

NDA에 비밀유지 의무만 있고 아이디어 귀속에 관한 언급이 전혀 없으면, 상대방이 아이디어를 사용해도 NDA 위반이 아닐 수 있다.

### 위험 신호 2: 구두 계약·이메일만 있는 협업

서면 계약 없이 구두 또는 이메일로만 아이디어를 공유한 경우, 제공 범위·목적·시점 입증이 어렵다.

### 위험 신호 3: 피칭 전 NDA 미체결

아이디어 제공 전 NDA를 체결하지 않으면, 사후에 영업비밀·차목 보호를 주장하더라도 비밀관리성 입증이 곤란하다(2019가합552402).

### 위험 신호 4: NDA 문언이 '영업비밀'로 한정

NDA상 비밀정보 범위가 '영업비밀'로만 정의된 경우, 영업비밀 요건 불충족 시 계약 보호도 무너질 위험(2022나2016206).

### 위험 신호 5: "아이디어는 공유 자산"이라는 묵시적 인식

미팅록·이메일에 "함께 만든다", "공동 기획" 등 표현이 있으면 추후 귀속 분쟁의 근거로 사용될 수 있음.

### 위험 신호 6: 사전 보유 기술과 신규 창출 기술 미구분

Background IP와 Foreground IP 구분 없이 협업하면, 각자의 기여 범위 확정이 불가능해 분쟁 발생.

## 5. 첫 대응 — 아이디어 귀속 분쟁 발생 시 5단계

### 1단계: 기존 NDA 재검토

NDA 문언에서 '비밀정보'의 범위 확인. IP 귀속 조항 유무 확인. '목적 외 사용 금지' 조항이 구체적인지 확인.

### 2단계: 귀속 합의(IP Assignment) 요청

NDA에 IP 귀속 조항이 없으면 즉시 별도 IP Assignment Agreement 체결 요청. 협업 중 창출된 모든 아이디어·성과물의 귀속 주체 명시. 공동 개발 시 공동 소유 조건(지분율·실시 방식·수익 배분) 협상.

### 3단계: 발송 전 기록 확보

아이디어 제공 내역(회의록·이메일·메신저) 날짜별 정리. 제공 시점에 비밀정보임을 표시했는지 확인. 제공 목적과 사용 제한을 명시한 문서(이메일·서면) 보존.

### 4단계: 법적 근거 검토

- 영업비밀(부정경쟁방지법 제2조 제2호) 해당 여부 → 비공지성·경제적유용성·비밀관리성
- 아이디어 도용(부정경쟁방지법 제2조 제1호 차목) 해당 여부 → 제공목적 위반 부정사용
- NDA 계약책임(민법 제390조) 검토
- 불법행위(민법 제750조) 우회 가능성

### 5단계: 내용증명·경고장 발송 → 협상 → 가처분·소송

침해 중단 요구 내용증명 발송. IP 귀속 및 사용료 협상 시도. 협상 결렬 시 가처분 신청·손해배상 청구.

## 7. FAQ

**Q1: NDA만 체결하면 아이디어가 보호되나요?**
A: NDA는 '비밀유지 의무'만 부과합니다. 아이디어 자체의 소유권을 보호하려면 별도의 IP 귀속 조항(IP Assignment)이 필요합니다. NDA만으로는 상대방이 아이디어를 사용해도 계약 위반이 아닐 수 있습니다.

**Q2: 영업비밀이 아닌 아이디어는 법적으로 보호받을 수 없나요?**
A: 부정경쟁방지법 제2조 제1호 차목은 영업비밀에 이르지 않는 아이디어도 보호합니다. 제공목적에 위반하여 부정하게 사용하는 것이 금지됩니다. 단, 구체화된 아이디어여야 하고 제공 시점의 목적·범위가 명확해야 합니다(2020다220607).

**Q3: 협업 중 양측이 각자 아이디어를 냈습니다. 귀속은 어떻게 되나요?**
A: 별도 약정이 없으면 원칙적으로 각자의 기여분은 각자에게 귀속됩니다. 공동 개발의 경우 공동 소유가 될 수 있지만, 권리관계가 불명확해 분쟁 소지가 큽니다. 협업 전에 공동 개발 계약(JDA)을 체결하여 지분·실시권·수익 배분을 정하는 것이 바람직합니다.

**Q4: 구두로만 아이디어를 공유했는데 보호받을 방법이 있나요?**
A: 구두 제공만으로도 부정경쟁방지법 차목 보호 주장은 가능합니다. 그러나 증명이 어려우므로, 제공 직후 이메일로 요약본을 송부하고(회의록·제공 목적·시점 명시) 상대방의 확인을 받아두어야 합니다.

**Q5: 상대방이 '독자 개발'이라며 아이디어 사용을 부인합니다. 어떻게 입증하나요?**
A: 제공 기록(회의록·이메일·메신저·음성녹취), 제공된 자료(PPT·기획서·도면), 상대방이 독자 개발이라고 주장하기 전 아이디어를 접할 다른 경로가 없었음을 입증해야 합니다. 영업비밀 원본증명 서비스(부정경쟁방지법 제9조의2)를 사전에 활용했다면 강력한 증거가 됩니다.

**Q6: 협업사가 NDA를 위반했습니다. 즉시 할 수 있는 법적 조치는?**
A: 우선 내용증명으로 침해 중단과 증거 보존을 요구하고, 긴급한 경우 가처분 신청(영업비밀 침해 금지·아이디어 사용 금지)을 고려합니다. 손해배상 청구는 병행 가능하나 입증 부담이 크므로, 사전에 증거를 최대한 확보해야 합니다.
