진술 청취·면담 실행 기술

3줄 요약

  • 면담은 '대화'가 아니라 '구조화된 정보 추출'이다. 해명하지 말고 기록의 힘으로 제압하라.
  • 상대의 프레임 공격(표적 조사 주장 등)에는 해명 대신 "기록하겠습니다"로 대응하고 즉시 다음 질문으로 넘어간다.
  • 면담 종료 즉시 요약본을 낭독하고 확인 서명을 받아 진술 번복을 방지한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 대응)

대상자 통지(010) -> [면담 실행] -> 증거 수집(012)

1. 이번 단계에서 반드시 할 일

  • [ ] 면담 시작 전 안내문 교부 및 서명 확인
  • [ ] 2인 1조(질문자+기록자) 면담 진행
  • [ ] 개방형 질문으로 시작 → 확인형 → 필요시 대립형으로 전환
  • [ ] 유도형 질문·가정 질문·감정적 반응 금지
  • [ ] 핵심 질문 후 최소 20초 침묵 유지(상대가 먼저 말하게)
  • [ ] 면담 종료 즉시 요약본 낭독·확인 서명

2. 준비물

| 준비물 | 왜 필요한가 | 준비 상태 | |---|---|---| | 면담 안내문(서면) | 면담 목적·권리·녹음 여부 사전 고지 | 미확인 | | 질문지(대상자별) | 구조화된 질문 순서 유지 | 미확인 | | 면담 기록지 양식 | 진술 내용과 질문 구분 기록 | 미확인 | | 면담 요약 확인서 | 종료 후 진술 확인 서명 | 미확인 |

3. 작성·제출물

| 문서 | 제출처 | 주의점 | |---|---|---| | 면담 기록(원본) | 법무팀(내부 보관, 비밀 유지) | 질문과 진술을 구분, 해석 배제 | | 면담 요약 확인서(서명본) | 법무팀(내부 보관) | 대상자 서명, '정정 사항 없음' 확인 | | 접촉 시도 일지(있는 경우) | 감사위원회(보고) | 비공식 접촉 발생 시 기록 |

4. 흔한 실수

  • 피조사자의 프레임 공격에 해명으로 반응 — 면담 주도권 상실
  • 침묵을 견디지 못하고 질문을 스스로 완화 — 정보 추출 밀도 하락
  • 참고인의 휴대폰 사용 방치 — 진술 오염
  • 면담 종료 후 확인 서명 생략 — 진술 번복 리스크

5. 전문가 상담 신호

위험도: 혼자 가능(단, 대립형 면담 필요 시 상담 권장)

  • 피조사자가 강하게 반발하거나 프레임 공격을 지속하는 경우
  • 중대한 법적 쟁점이 포함된 면담(전략 수립 별도 필요)

6. 인접 절차 연결

  • 선행: PROC-INVS-010 · 후속: PROC-INVS-012(증거 수집·기록)
