3MUST · 기업법무 · 실사 대응

실사 지적사항이 통보됐을 때 — 공시·면책·해결

적용 상황: 투자자·매수자 측 실사 결과 보고서나 지적사항 목록을 받았는데, 무엇을 먼저 시정하고 무엇을 계약에 반영할지 정리해야 할 때.

Must Know · 알아야 할 것

지적사항은 세 갈래로만 나눕니다 — 공시(고지하고 상대가 감수), 면책·보장 조건으로 처리(계약 문언 반영), 해결(실제 시정). 심각도(사실의 무게)와 처리 방식(협상 선택)은 다른 칸입니다. 불리한 항목을 빼고 목록을 만들면 나중에 드러날 때 회사 입장이 훨씬 나빠지므로, 빼는 대신 표현과 범위를 다듬습니다. "위법 가능성" 같은 법적 결론은 표에서 확정하지 말고 법률 검토 필요로 남깁니다.

처리 방식준비할 것
공시공시 자료 초안, 표현 점검
면책·보장상한·기간·공제 문언 대조, 협상 쟁점
해결시정 계획·담당·기한·완료 증빙

Must Check · 확인할 것

  • 실사 보고서·지적사항 원문과 범위
  • 이슈별 사실관계와 근거 자료
  • 이미 시정한 것과 남은 것의 구분
  • 계약서의 공시(Disclosure) 조항
  • 면책·손해배상의 상한·기간·공제 구조
  • 시정 소요 기간·비용·담당자
  • 밸류에이션·투자 조건에 미치는 영향
  • 경영진 보고 대상 항목
  • 투자자 유형별 민감도

Must Do · 실행할 것

  1. 지적사항을 한 줄씩 목록화합니다(번호·분야·내용·근거 자료).
  2. 각 항목에 심각도와 처리 방식을 따로 적습니다.
  3. 다섯 칸을 채웁니다 — 발견 사실 / 법률 검토 필요 / 회사 입장 / 해결 방안·담당·기한 / 계약 반영 방법.
  4. 시정 가능한 항목부터 조치하고 전·후 증빙을 남깁니다.
  5. 공시 항목은 공시 자료 초안으로 옮기고 과장·축소 여부를 다시 봅니다.
  6. 면책·보장 항목은 문언의 상한·기간·공제와 대조해 협상 쟁점을 정리합니다.
  7. 협상 영향 평가표를 채웁니다(가격 조정 가능성, 공시·면책 처리 비율, 사전 시정 건수, 반영 필요 조항, 경영진 보고 여부).
  8. 우선순위·담당·기한 표를 만들어 경영진 보고와 협상팀 공유를 마칩니다.
  9. 협상 종료 후 실제 반영 결과를 대응표에 표시해 기록으로 남깁니다.
잠깐 멈추고 검토할 때지적사항이 형사·규제 위반 가능성에 닿으면 협상 대응표와 별도로 법률 검토를 먼저 받습니다. 시정에 제3자·감독기관 협조가 필요해 협상 기한을 넘기면 조건부 합의 구조를 검토합니다. 투자자가 가격을 크게 낮추자고 하면 근거 자료와 영향 범위를 다시 대조합니다. 내부에서 특정 이슈를 빼자고 하면 근거와 위험을 문서로 남기고 상위 승인을 받습니다.
