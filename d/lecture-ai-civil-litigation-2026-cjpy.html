AI, 든든한 소송 도우미 만들기

AI에게 소장을 대신 써 달라고 맡기는 수업이 아닙니다. Claude Code Desktop의 Code → Local 작업공간에서 사건자료를 구조화하고, 개인정보·환각·출처 오류를 통제하며, 사람이 최종 판단하는 검토용 워크플로를 만듭니다.

기본 환경: Claude Code Desktop · Code → Local Cowork·CLI·Obsidian은 강의의 기본 경로가 아닙니다.

이 강의가 필요한 순간

자료가 회계 프로그램·휴대폰·메일·기억에 흩어져 무엇을 보여줘야 할지 모를 때
AI 요약에 사실·추측·출처 없는 법률 문장이 섞였는지 확인해야 할 때
개인정보를 익명화하고 안전한 작업공간에 넣어야 할 때
상대방 주장·증거·기한을 보고 다음 행동을 정해야 할 때
상담 전에 사건과 질문을 정확히 전달하고 싶을 때

수강 후 손에 남는 것

개인 프로젝트 폴더, WIKI 템플릿, 사건 입력팩, 익명화 체크리스트, 타임라인·쟁점·증거 분석표, 검토용 서면 골격, 절차 확인표, 출처 검증 로그, 교차검증 프롬프트, 사람 판단 게이트, AI 사용 운영규칙을 직접 완성합니다.

차별점과 FAQ

  • 도구보다 통제와 자료구조에서 시작합니다.
  • 전원 Claude Code Desktop `Code → Local` 실습, CLI는 필요하지 않습니다.
  • 한국법 MCP·OCR·옵시디언은 데모·사후 가이드로 분리합니다.
  • 실제 사건의 원본 개인정보 입력을 금지하고, 최종 제출·판단은 사람이 합니다.

ChatGPT 강의인가요?

아닙니다. 실습 기준은 Claude Code Desktop의 `Code → Local`이며 Cowork는 기본 경로가 아닙니다.

AI가 법률판단을 해주나요?

아닙니다. 교육용 정리·검토 보조 과정이며 법률자문과 제출물 완성본을 제공하지 않습니다.

실제 사건을 넣어도 되나요?

비식별화한 자료만 사용합니다. 원본 개인정보와 기밀자료는 입력하지 않습니다.

결제 전 확인할 한 문장

AI에게 사건을 맡기는 법이 아니라, Claude Code Desktop의 Code → Local에서 자료·출처·사람의 판단선을 함께 관리하고 싶다면 이 과정이 맞습니다.

본 페이지는 일반 교육 안내이며 특정 사건의 법률자문을 대체하지 않습니다. 실제 조치는 최신 법령·절차·사실관계를 별도로 확인해야 합니다.
