0. 한 줄 결론

치과의사가 한 일의 본질 = 싫어하던 반복 사무일(전화·서류대조·숫자정리·검색)을 기계에 넘기고, 판단·책임(진료)은 사람이 쥔 것.

1인 로펌 번역 = 아래 4개만 가져간다:

  1. 상담 intake 자동화 (녹취→요약→쟁점→초동메일 초안)
  2. 서류 OCR·대조표 자동화 (스캔→읽기→표로)
  3. 사건·재무 숫자 주간 리포트 (계산은 프로그램, 해석만 AI)
  4. SEO·GEO용 글 구조화 (기존 컬럼 투트랙과 연결)

시작점은 원문처럼 "거창한 계획"이 아니라 "짜증 1개"다. 지금 제일 짜증 나는 1개(상담 정리 or 영수증 or 초동메일)부터 한다.

1. 원문 분해 — 가져올 것 / 버릴 것

원문 모듈1인 로펌 판정이유
"환자정보 병원 밖으로 안 나간다" (로컬 LLM 올인)원칙만 계승, 수단은 변경비밀유지 의무 + 변호사법 ACP(제26조의2, 2026-01-29 신설). 다만 DGX급 로컬 LLM은 과투자 — 녹취·원문은 로컬, 요약·초안은 가명화 후 클라우드면 충분
뒷방 서버랙 12대 + UPS 6대버린다소규모 RAG 구축 수천만 원·월 수십만 원은 과투자. 노트북 1대 + 외장SSD/NAS + 월 2~3만 원 클라우드가 현실선
자체 PBX + 전화받는 AI버린다병목은 "전화를 못 받아서"가 아니라 "받은 상담을 정리·회신 못 해서"다. 통신사 전화 + 로컬 녹취·요약이면 충분

사내검색(RAG 자작)수단 변경해 가져온다새로 만들지 않는다. 기존 볼트 + Obsidian 검색이 1차, 그 위에 "가명화 후 클라우드 요약"만 얹는다
AI 채점 화면·블라인드 비교가져온다 (축소판)초동메일 2안을 변호사가 "1/2/비슷/둘 다 틀림" 4택으로만 고른다. 정답지 축적 = 성공/실패 사례표로 직결
일/주/월 경영리포트 (숫자는 프로그램, 해석은 AI)가져온다 (그대로)원문 최고의 대목. 집계는 표·스크립트가, AI는 해석·문장만. 계산을 AI에 맡기면 매출을 지어낸다
사내메신저 자작·TTS 방송버린다1인 로펌에 원내방송은 없다. 같은 시간이면 상담 DB 1개가 100배
전자동의서·서명패드절반만전자서명은 제도권 도구로 해결. "서명 시점 PDF가 사건폴더에 자동 저장" 규칙만 가져온다
에이전트 분업 + 원장 승인 게이트가져온다 (그대로)역할 분리 + 파괴적 조작(삭제·발송·약정 변경)은 변호사 승인. 그대로 쓴다
회계사 해지·SaaS 정리·마케팅비 0원절반만회계사(기장·신고)는 유지 — 장부가 증거다. SaaS는 작은 것부터, 마케팅비는 실험비로 전환. SEO·GEO 구조화는 가져온다

2. 전제 — 1인 로펌 AX 5원칙

  1. 비밀을 설계로 지킨다. 녹취 음성은 로컬에서만 처리, 클라우드 입력은 식별정보를 가린 뒤. 보관·삭제 권한은 변호사에게.
  2. 숫자는 프로그램이, 문장은 AI가. 착수금·미수금·손익분기 집계는 표가 계산, AI는 해석만. AI 금액은 [추정] 취급.
  3. 판단은 변호사가, AI는 제안까지만. AI는 약정·서면에 직접 쓰지 않고 초안·대조표까지만. 발송·제출·약정 변경은 승인 후에만.
  4. 짜증 1개부터, 서버 1대도 안 산다. 있는 노트북 + 무료 로컬 STT + 기존 클라우드 구독. 돈 쓰는 건 30일 뒤 숫자가 증명한 뒤.
  5. 채점은 4택 5초다. "1이 나음 / 2가 나음 / 비슷 / 둘 다 틀림" — 결과는 사례표에 누적.

3. 30일·90일 로드맵 (현실선)

3-1. 0~30일: 상담 intake 1개만 끝낸다

목표: "상담 끝나면 30분 정리"를 "5분 검수"로.

  • 상담 녹취 동의 멘트 고정 → 로컬 STT 1개 설치 → 전사→가명화→쟁점 3개→7파트 초동 2안→4택 검수→발송
  • 성공/실패 1건씩 사례표에 기록 (이게 원문의 "정답지"다)
  • 성공 기준: 정리 30분→10분 이하, 발송까지 24시간 이내

3-2. 31~90일: 서류뭉치 + 숫자 리포트

  • 스캔뭉치 1건 파일럿(50~100쪽) → 일자·금액·당사자 표, "확정/확인필요" 2열 필수
  • 주간 숫자 1장: dashboard + intake + receivables를 금요일 1표로 합치고 AI 해석 5줄
  • 컬럼 1편을 SEO·GEO형으로重整 (의뢰인 검색어 + AI 인용 구조)

3-3. 90일 뒤 분기점

숫자로만 판단: (a) 상담 정리 시간 (b) 서류표 외주비 (c) 초동→수임 전환율 (d) SaaS 구독료. 4개 중 2개 이상 개선 없으면 확장 중단. 서버·유료 RAG·전화 AI는 판정 통과 후에만 검토한다.

4. 영역별 자세한 적용법

4-1. 상담 intake (효용 1위)

  1. 받는다(사람) → 적는다(기계). AI가 전화를 먼저 받지 않는다. "끊고 5분 정리"가 현실이다.
  2. 가명화 후 2안 생성. 실명·연락처·계좌를 [의뢰인A]로 치환한 뒤 A안(7파트 정석)/B안(짧은 확답형). 변호사는 4택으로만 고른다.
  3. 7파트 구조 강제. 진단(쟁점·복잡성·리스크)은 공유, 처방(구체 법리·전략)은 유보, 게이트(필요 서류)·CTA(유료상담)를 반드시 포함. 게이트 없는 초안은 탈락 — 체리피킹(과거 사례) 방지.
  4. 정답지를 쌓는다. 매주 성공/실패 1행씩 사례표에 추가. 두 안이 갈린 상담부터 복기한다.
하지 말 것: 상담 전문 통째 클라우드 붙여넣기, 검수 없는 발송, AI가 먼저 받는 대표번호.

4-2. 서류뭉치 OCR·대조표 (효용 2위)

  1. 작게 시작: 50~100쪽 1건. 스캔 품질(300dpi·수평·흑백)이 모델보다 먼저다.
  2. 출력은 표 1개: 일자 | 문서명/쪽 | 금액·수량 | 당사자 | 쟁점연결 | 상태(확정/확인필요). 줄마다 원문 쪽 번호.
  3. 사람은 23%만 본다: 확인필요 행만 본다. 2분류가 없으면 OCR은 시간만 먹는다.
  4. 정확도 측정 1회: 모델 2개를 같은 10쪽에 붙여 적중률을 잰다. 감이 아니라 숫자로.
하지 말 것: "AI가 읽어줬으니 다 맞겠지" 확정, 쪽 번호 없는 요약, 원본 스캔 폐기.

4-3. 사건·지식 검색 (새로 만들지 않는다)

1차 = 기존 볼트 검색(사건·메모 → 법리·판례). 2차 = 가명화 후 클라우드 질문. 매주 같은 질문 3번 나오면 그때만 FAQ 1장을 만든다.

4-4. 재무·경영 1장 (원문 원칙 그대로)

  1. 연결은 수동으로 시작: 매주 금요일 15분, 통장 입금 1건씩 intake·retainer·receivables와 대조.
  2. 주간 1장 포맷 고정: 이번 주 입금 | 미수금 변동 | 손익분기까지 남은 액수 | 확인필요 3건. 계산은 표가, 해석 5줄은 AI가(근거 셀 번호 필수).
  3. 월간 합본은 분기 1회로. 셋이 같은 말이면 진짜 보고, 갈리면 들여다본다.

4-5. 마케팅 — 0원이 아니라 실험비로

기존 투트랙 유지. 트랙 A(생활밀착·네이버 SEO): 의뢰인 검색어 + FAQ 3문 3답 + CTA 1개. 트랙 B(고난도·페북+세무사): 판정 지표(적합 문의율·진단→수임률·소개 수). 글 끝에 GEO 3줄(핵심요약·근거·다음행동)을 정형으로 둔다.

4-6. 에이전트 운용

역할 3개만: ①초안 ②대조 ③정리. 승인 게이트 3개: 외부 발송, 약정·금액 변경, 파일 삭제·이동. 초안의 숫자·인용은 대조가 1회 검증한다.

5. 기밀·법적 체크리스트 (발송·전사 전 매번)

  • 녹취 전 동의 고지 멘트를 했는가 (본인 참여 대화 녹음은 적법, 제3자 몰래녹음은 징역형 — "기록 목적 녹취 동의" 고지가 안전)
  • 음성 원본을 외부 서버에 올리지 않았는가 (로컬 STT 우선)
  • 클라우드 입력에서 실명·주민번호·계좌·사건번호를 치환했는가
  • AI 산출물의 법령·판례 인용을 원문에서 1건씩 확인했는가
  • 발송·제출·약정 변경에 변호사 승인이 있는가
  • ACP 관점: 자문 목적 메일 제목·문서명에 목적 표시를 했는가

7. 기존 전략 파일과의 연결

  • sales_playbook: 초동 7파트 그대로. "2안→4택"과 사례 1행 누적 규칙을 사례표에 붙인다.
  • marketing_channels: SEO·GEO 실험 전 채널 1행(전환율·월비용) 먼저 기입.
  • positioning (draft): AX를 포지셔닝으로 내세우지 않는다. 내부 효율로만 쓴다.
  • revenue_models 다이제스트: 월간 해석에 이탈률·전환율·성과발생률 3지표만 얹는다.
  • 20260828 컬럼 보고서: 투트랙 유지. GEO 3줄만 추가한다.
  • networking_plan: 세무사 공유 테스트에 서류표·상담보고서 샘플 1장을 얹는다.

8. 다음 액션 3개 (이번 주)

  1. 제일 짜증 나는 1개를 골라 30일 파일럿으로 선언한다.
  2. 상담 녹취 동의 멘트 1줄을 고정하고 로컬 STT 1개를 설치한다.
  3. 금요일 dashboard에 주간 1장을 처음 붙인다.
