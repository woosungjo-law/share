공식 신고 없이 소문만 들렸을 때 조사를 시작할지 판단할 때

적용 상황: 직장 내 괴롭힘·성희롱·부적절한 언행에 관한 이야기를 공식 신고가 아닌 경로(동료의 말, 목격담, 익명 제보, 부서장 보고)로 듣게 된 경우입니다.

즉시 확인일시·장소·당사자·행위가 구체적 / 신체·정신 위험 / 반복 정황 / 직위 차이
예비 확인내용이 일부 구체적이나 경로가 불명확 / 당사자 의사 확인이 먼저 필요
기록 후 관찰추상적·단일 경로 / 특정 불가 / 위험 신호 없음

Must Know · 알아야 할 것

  • 소문과 사실은 다릅니다. 들은 내용을 그대로 사건으로 취급하면 피해자·당사자의 명예가 훼손될 수 있고, 반대로 무시하면 위험이 커집니다. 들어온 정보를 그대로 기록하고 확인된 사실과 구분합니다.
  • 판단 기준은 구체성·중대성·반복성·안전 위험입니다. 언제·어디서·누가·무엇을 했는지가 구체적이고, 신체·정신 건강에 위험이 있거나 반복 정황이 보이면 즉시 확인에 들어갑니다.
  • 출처가 불명확하고 내용이 추상적이라면 바로 조사 절차를 열기보다 담당자 수준의 예비 확인부터 시작하는 편이 낫습니다.
  • 확인 없는 즉시 통보는 위험합니다. 당사자에게 아직 확인되지 않은 이야기를 전달하면 관계가 악화되고 이후 확인이 어려워집니다.
  • 정보가 들어온 경로 자체를 기록해야 합니다. "누가 언제 누구에게서 들었는지"는 나중에 절차의 적정성을 설명하는 근거가 됩니다.
  • 정보 제공자를 보호해야 합니다. 몇 사람이 들었는지, 누구에게서 들었는지가 조사 과정에서 자연스럽게 드러나지 않도록 주의합니다.

Must Check · 확인할 것

  • 정보가 들어온 경로·시점·전달자(누가 누구에게)
  • 들은 내용의 구체성(일시·장소·당사자·행위)
  • 같은 내용이 여러 경로에서 반복되는지
  • 신체·정신 건강 위험 또는 즉시 조치가 필요한 정황
  • 관련 부서장·인사 담당자가 이미 알고 있는지
  • 본인이 신고를 원하지 않는지, 두려워하는 정황이 있는지
  • 유사한 과거 사안과 처리 기록이 있는지
  • 절차상 조사 개시 요건 해당 여부와 사내 규정
  • 기록 보관 위치와 접근 권한

Must Do · 실행할 것

  1. 들은 내용을 사실 그대로, "전달받은 정보"로 표시해 기록합니다(확인된 사실과 별도 칸).
  2. 정보 제공자를 특정할 수 없게 표현을 다듬고, 제공자가 불이익을 받지 않도록 유의합니다.
  3. 위험 신호(신체 위험·반복 정황·직위 차이)를 체크해 착수 여부를 판단합니다.
  4. 즉시 조치가 필요한 경우 근무 분리·연락 차단 등 안전 조치를 먼저 검토합니다.
  5. 담당자(인사·법무)에게 인계하고 예비 확인 범위와 질문 항목을 정합니다.
  6. 예비 확인은 사실 확인에 한정하고, 확인되지 않은 내용을 당사자에게 전달하지 않습니다.
  7. 예비 확인 결과에 따라 절차 개시·기록 보관·종결을 결정하고 결정자와 시각을 남깁니다.
  8. 사내 규정상 조사 개시 요건이 충족되면 접수·조사 절차로 전환하고 그 기록을 남깁니다.
