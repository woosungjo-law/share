상속재산분할 협의서 작성

TL;DR

상속재산분할협의는 공동상속인 전원의 합의가 필요한 법률행위. 분할협의서 작성 시 특별수익·기여분을 반영한 구체적 상속분 산정이 핵심. 채무초과 상태 상속인이 지분을 포기하면 사해행위취소 리스크 있음.

협의서 작성 체크리스트

  • [ ] 공동상속인 전원 참여 확인 (대리인·특별대리인 필요 여부)
  • [ ] 상속재산 목록 작성 (현존 재산·처분 대상재산 구분)
  • [ ] 특별수익 내역 확인 (생전증여·유증, 기간 제한 없음)
  • [ ] 기여분 주장 여부 확인 (엄격 요건, 상속재산 유지·증가 기여)
  • [ ] 구체적 상속분 계산 (법정상속분이 아님)
  • [ ] 분할 방식 결정 (현물분할·가액배상·경매)
  • [ ] 정산금 지급 조건·시기 명시
  • [ ] 채무 있는 상속인의 분할포기 → 사해행위 리스크 별도 검토
  • [ ] 협의서에 상속재산 목록·특별수익 고지·정산금 내역·각 상속인 확인 문구 포함

주의사항

  • 분할의 소급효(제1015조): 협의 완료 시 상속개시 시로 소급. 단 외부 채권자 관계에서는 보호되지 않을 수 있음
  • 사해행위 리스크: 채무초과 상속인이 상속지분 포기 = 원칙 사해행위 (2007다73765)
  • 소송 vs 심판 구분: 타인 채권은 별도 소송사항, 상속인 간 분할은 가정법원 심판
  • 초과특별수익자: 구체적 상속분 0 처리, 초과분 타인 법정상속분율 안분 공제
