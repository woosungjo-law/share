상속포기 vs 한정승인 vs 단순승인 — 3개월 선택이 운명을 결정한다

적용 상황: 상속개시 통보를 받은 후 3개월 내에 선택해야 하는 상속포기·한정승인·단순승인 중 어느 길을 선택해야 하는지 결정해야 하는 상황

Must Know · 알아야 할 것

민법 제1019조(상속의 세 가지 길): 단순승인(무한 책임)·한정승인(상속재산 한도 책임)·상속포기(소급효로 처음부터 상속인 아님). 제1026조(법정단순승인 사유): 재산 처분·3개월 경과·은닉·부정소비. M3 디자인에서는 단계 흐름을 세로 경로로_show하고 각 단계의 확인 증거를 연결

Must Check · 확인할 것

  • 상속개시일과 인지일 확인 — 3개월 기산점 확정 (누가·언제 상속을 알았는지)
  • 상속재산 목록 작성 — 부동산·예금·주식·채권·자동차 등 전부 확인
  • 상속채무 목록 작성 — 대출·보증·미납세금·공과금 등 전부 확인
  • 재산-채무 비교표 작성 — 재산 > 채무·재산 ≈ 채무·재산 < 채무 판단
  • 가족관계 확인 — 상속인 전원 파악 (가족관계증명서 발급)
  • 이미 처분행위 확인 — 통장 인출·차량 매각·채권 추심 등 이미 처분했는지 점검
  • 한정승인·포기 신고 준비 — 가정법원 서식, 필요 서류 확인
  • 법정단순승인 여부 점검 — 이미 처분행위를 했는지 확인
  • 채권자 독촉 대응 — 한정승인·포기 중임을 통지
  • 기간 만료 2주 전 알람 설정 — 특별한정승인 검토용
  • 숨은 재산 조사 — 미분할 부동산·금융자산·보험금 확인 (포기 후 발견 시 복구 불가)
  • 유류분 청구 필요성 검토 — 상속포기 시 유류분반환청구권 소멸 여부 우선 검토
  • 가업상속 여부 확인 — 가업상속공제·상속세 혜택 위해 포기 회피 여부 검토
  • 공동상속인 선택 방향 교차 확인 — 일부 포기·한정승인·단순승인 혼합 시 상호 영향 확인

Must Do · 실행할 것

  1. 피상속인 재산·채무 1차 파악: 등기부·통장·채권추심내역 조사
  2. 상속인 전원 명단 확인: 가족관계증명서 발급
  3. 재산 vs 채무 비교표 작성: 단순승인·한정승인·포기 권고
  4. 이미 처분행위 여부 확인: 통장 인출·차량 매각 등 이미 처분했는지 확인
  5. 가정법원 신고 일정 확정: 3개월 내 마감, 늦어도 2주 전 알람 설정 및 특별한정승인 검토 준비
잠깐 멈추고 검토할 때장례비는 정당 상속비용일 수 있으나 범위와 증명이 문제 (대법원 2010다30416), 인출 전 변호사 상담 필수, 3개월 경과 후라도 중과실 없이 상속채무 초과 사실을 안 날부터 3개월 내 특별한정승인 가능 (제1019조 제3항), 포기·한정승인은 신고 시점이 아니라 가정법원 수리심판 고지 시 효력 발생 (대법원 2013다73520), 한정승인은 변론종결 후 청구이의 가능하지만 상속포기는 변론종결 전에 반드시 주장해야 함 (대법원 2008다79876), 정당 지출은 지출 경위·영수증 보관해 대응 (대법원 2010다30416)
