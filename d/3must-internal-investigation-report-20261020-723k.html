내부조사 결과 보고서를 작성할 때

적용 상황: 임직원 비위·규정 위반 내부조사를 마치고 결과 보고서를 작성해 경영진에 제출하려는 경우. 범위: 조사 결과의 법적 평가, 징계·수사기관 신고 여부는 다루지 않습니다. 보고서 구조, 사실과 평가의 분리, 배포·보관 기준을 정리합니다.

Must Know · 알아야 할 것

  • 내부 보고서는 언젠가 외부에서 읽힐 수 있습니다. 사내 문서라는 전제로 쓰면 표현이 거칠어집니다.
  • 사실과 평가를 섞으면 둘 다 약해집니다. 조사에서 확인된 것과 작성자의 판단을 분리합니다.
  • 근거 없는 추정·인물 평가·감정적 표현은 보고서의 신뢰를 떨어뜨립니다.
  • 누가 읽을지 정해야 합니다. 경영진용 요약과 조사 기록 본문은 목적이 다릅니다.
  • 배포 범위와 보관 방식이 정해지지 않으면 유출·왜곡 위험이 생깁니다.

Must Check · 확인할 것

  • 보고서 목적과 법적 지위를 첫머리에 적었는가.
  • 사실·평가·권고·미확인 항목이 절로 분리되어 있는가.
  • 진술·자료 출처를 각 사실에 연결했는가.
  • 인물에 대한 주관적 평가 표현이 들어가 있지 않은가.
  • 조사 대상자에게 소명 기회를 주었는지 기록했는가.
  • 배포 대상과 등급(대외비 등)을 표시했는가.
  • 원자료·면담 기록의 보관 위치를 명시했는가.

Must Do · 실행할 것

  1. 작성자는 보고서 첫머리에 목적 / 조사 범위 / 조사 기간 / 작성자를 적습니다.
  2. 본문을 확인된 사실 / 평가 / 권고 / 미확인 네 절로 나눠 작성합니다.
  3. 각 사실에 증거 번호를 붙이고, 증거 목록을 별첨으로 만듭니다.
  4. 대상자 소명 내용과 조사 결과의 차이를 정리해 별도 항목으로 남깁니다.
  5. 배포 전 법무 책임자 검토를 거치고, 검토자·확인일을 기록합니다.
  6. 배포 대상·사본 관리·회수 절차를 정하고 문서에 표시합니다.
  7. 수사기관·외부 제출 가능성에 대비해 제출용 요약본을 별도로 준비합니다.
잠깐 멈추고 검토할 때

조사 대상자가 임원이거나 경영진과 이해관계가 있는 경우 · 형사 사건과 연결될 가능성이 있는 경우 · 보고서에 개인정보·민감정보가 다수 포함된 경우 · 외부 제출·공개 요구가 예상되는 경우 · 조사 과정의 절차 하자가 지적된 경우

제한: 증거능력·조사 특권·형사책임 판단은 제외했습니다.
