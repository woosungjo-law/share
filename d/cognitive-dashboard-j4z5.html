1

K-MMSE (Korean Mini-Mental State Examination)

개요

치매 선별을 위한 가장 보편적인 인지기능 검사. 30점 만점. 5~10분 소요. 19개 문항으로 구성.

평가 영역 (6개)

영역점수평가 내용
시간지남력5연도·월·날짜·요일·계절
장소지남력5국가·시도·구군·건물명·층/위치
기억등록33개 단어 즉시 기억
주의집중·계산5100에서 7씩 빼기 (5회)
기억회상3등록한 3개 단어 회상
언어·시공간9사물이름대기·문장따라말하기·쓰기·명령수행·모사

점수별 해석 기준

점수 범위판정일상생활 기능
24~30정상 (Normal)일상생활·금전관리 독립적 가능
20~23경도 인지장애 의심 / 치매 의심복잡한 금전거래·계약에 어려움 시작
15~19경도~중등도 치매일상적 금전관리 곤란, 타인 도움 필요
10~14중등도 치매시간·장소 인식 혼동, 전반적 도움 필요
0~9중증 치매전적 타인 의존, 기본적 의사소통도 제한
주의사항

연령·학력 보정: 고령(80대+)은 평균 점수 하락, 무학자는 +4점 보정, 고학력자는 동일 점수라도 실제 인지저하가 더 진행되었을 가능성
천장효과: 학력·지능이 높으면 MMSE 점수가 실제 인지저하보다 높게 나올 수 있음 → 추가 정밀검사(SNSB 등) 필요
진단명 ≠ 점수: 알츠하이머 진단 + MMSE 27이면, 진단은 내려졌으나 인지저하 정도는 매우 초기 단계임을 의미

2

CDR (Clinical Dementia Rating)

개요

치매의 중증도(단계)를 평가하는 척도. 환자·보호자 면담(30~90분)으로 6개 영역 평가. MMSE가 인지기능의 “양적” 측정이라면, CDR은 일상생활에서의 “기능적 영향”을 평가.

평가 영역 (6개)

#영역주요 평가 내용
1기억력 (Memory)최근·원거리 기억, 일상적 건망증
2지남력 (Orientation)시간·장소·사람 인식
3판단력·문제해결재정·일상 문제 대처, 유사성·차이점 이해
4사회활동 (Community Affairs)직장·단체 활동, 사회적 역할 수행
5가정·취미 (Home & Hobbies)집안일, 취미, 지적 관심 유지
6자기관리 (Personal Care)위생·옷차림·식사

단계별 해석

CDR판정기억력일상생활금전관리
0정상정상완전 독립완전 가능
0.5치매 의증경도 건망증대체로 독립, 타인 인지 가능단순 거래 가능, 복잡한 거래에 어려움 시작
1경도 치매최근 기억 유의미 저하복잡한 업무 곤란, 일상생활은 가능재정·계약 독립 처리 불가
2중등도 치매심한 기억장애독립적 활동 불가, 가정 내 단순업무만 가능금전관리 불가
3중증 치매단편적 기억만 잔존전적 의존, 의사소통 제한불가

Global CDR 결정 규칙

결정 알고리즘

전체 CDR 점수는 기억력(Memory) 점수를 기준으로 하고, 다른 5개 영역의 분포에 따라 알고리즘으로 결정:

  1. 기억력=0 → 다른 영역도 전부 0 또는 1개만 0.5 → CDR=0 / 그 외 → CDR=0.5
  2. 기억력=0.5 → 다른 영역 중 3개↑ 1 이상 → CDR=1 / 그 외 → CDR=0.5
  3. 기억력=1,2,3 → 다른 5개 중 3개↑의 공통 점수로 결정 / 불일치 시 기억력 점수
실무 Tip

Global CDR만 보지 말고 CDR-SB(Sum of Boxes, 0~18)도 확인할 것. CDR-SB가 진행도·미세 변화에 더 민감.

MMSE 27 / CDR 0.5 사례 심층 분석

문성회 님 사례 매핑

MMSE 27 (정상 범주 하단) + CDR 0.5 (치매 의증) → 표준 매핑상 특정후견 영역.

측면의미
의학적알츠하이머 진단은 있으나, 인지저하 정도는 매우 초기. 일상대화·단순의사결정 가능.
법적 (성년후견)불가능. “사무처리능력 지속적 결여” 소명 거의 불가.
법적 (한정후견)가능하나, “사무처리능력 부족”도 수치만으로는 부족. 생활사실 보강 필수.
법적 (특정후견)가장 적합. 특정 재산처분·계약 건별 후원이면 수치상 무리 없음.
실무 전략수치가 높더라도 (1) 알츠하이머 진행성 질환 (2) 실제 금전관리 곤란 사례 (3) 가족 진술 등을 보강하여 한정후견 청구 → 법원이 특정후견으로 낮추더라도 손해 없음.
