개인정보가 유출된 것을 알고 신고서를 채워야 할 때

적용 상황: 개인정보가 유출된 것을 알고 신고서를 채워야 할 때

Must Know · 알아야 할 것

  • 신고서의 칸은 자료 목록입니다. 칸마다 어떤 자료에서 답을 가져올지 먼저 정하면 빈칸이 줄어듭니다.
  • 유출 일시와 경위는 추정으로 쓰지 않습니다. 로그와 기록에서 확인된 시점만 적고, 확인 중인 내용은 확인 중으로 표시합니다.
  • 유출 규모는 건수와 정보주체 수를 구분합니다. 두 숫자의 산정 기준을 함께 남깁니다.
  • 신고 대상과 기한은 이 카드에서 정하지 않습니다. 법무가 확인한 뒤 신고 시점을 정합니다.

Must Check · 확인할 것

  • 유출을 인지한 날짜와 그 근거 기록
  • 유출 경위(해킹, 내부 실수, 내부 유출, 협력사 등)의 확인 자료
  • 유출된 개인정보 항목 목록(성명, 연락처, 계좌 등)과 확인 방법
  • 영향받은 정보주체 수와 건수의 산정 기준
  • 이미 취한 차단·추가 방지 조치의 기록
  • 개인정보 보호책임자 정보와 신고서 작성 담당자
  • 신고 대상 기관과 기한 (법무 확인)

Must Do · 실행할 것

  1. 유출 인지 기록(날짜, 최초 신호, 확인 경위)을 먼저 정리합니다.
  2. 신고서 칸별로 자료 출처를 표로 만듭니다: 칸, 필요한 자료, 자료 위치, 담당자.
  3. 유출 항목과 규모를 산정하고, 건수와 정보주체 수의 기준을 따로 적습니다.
  4. 차단과 추가 방지 조치를 날짜별로 기록하고 증빙을 붙입니다.
  5. 빈칸은 '확인 중'으로 남기고, 추정 숫자를 넣지 않습니다.
  6. 신고 여부와 시기, 제출 방법은 법무가 정하고, 결정 기록을 남깁니다.
잠깐 멈추고 검토할 때

유출 규모를 확정할 수 없는 경우 · 민감정보나 고유식별정보가 포함되었을 가능성이 있는 경우 · 수탁사나 협력사가 관련된 경우 (계약상 통지 의무 확인) · 신고 기한이 임박했거나 이미 지났을 가능성이 있는 경우 (법무가 즉시 확인)

원자료: 법무키트 PCK-PRI-073 DOC-004 개인정보위원회 신고서 양식 (칸 구조만 사용)

검토일: 2026-11-04

미확인·제한: 원자료의 신고 기한(인지 후 72시간), 시행령 조문, 신고 대상 판단은 확인하지 않아 쓰지 않았습니다. 양식이 현행 서식과 같은지도 확인이 필요합니다.

변경 기록: 초안. 양식의 법령 인용과 기한 문구를 빼고, 칸별 자료 준비와 확인 기록 절차만 남겼습니다.

일반적인 실무 참고자료입니다. 개별 사안에서는 사실관계와 적용 기준을 확인하세요.
