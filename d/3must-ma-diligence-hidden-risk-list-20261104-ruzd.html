적용 상황: M&A 실사에서 놓치기 쉬운 항목을 실사 목록에 넣을 때

Must Know · 알아야 할 것

  • 주주명부와 실질주주명부가 맞는지 확인해야 합니다. 예탁된 주식은 실질주주명부 기재가 주주명부와 같은 효력을 가집니다(자본시장법 제316조 제2항).
  • 두 명부에 같은 사람이 있으면 주식 수를 합산해 권리를 확인합니다(자본시장법 제316조 제3항).
  • 주주 명부의 기재는 주주가 주소를 바꾼 경우 주소 기준으로 통지가 이뤄집니다(상법 제363조 제1항). 명부의 주소 정보가 최신인지도 확인합니다.
  • IP 공동 소유, 라이선스 조건, 행정 제재와 조사 진행 여부는 별도 항목으로 확인합니다.

Must Check · 확인할 것

  • 주주명부와 실질주주명부의 일치 여부와 주식 수 합산 결과
  • 명부 폐쇄 기간 중 주식 변동 기록
  • 공유 주식과 명의신탁 주식의 권리 관계 자료
  • IP 공동 소유 여부와 라이선스 조건
  • 행정 제재, 조사, 진행 중인 신고 사건 목록
  • 명부의 주소 정보 최신 여부

Must Do · 실행할 것

  1. 실사 목록에 주주명부, 공유·명의 주식, IP 공동 소유, 행정 조사 항목을 별도 묶음으로 추가합니다.
  2. 주주명부와 실질주주명부를 주주별로 대조하고, 차이 항목을 표로 만듭니다.
  3. 명부 폐쇄 기간 중 주식 변동 기록을 요청합니다.
  4. IP와 라이선스 계약에서 공동 소유나 양도 제한 조건을 찾아 표시합니다.
  5. 행정 조사와 제재 현황을 회사에 서면으로 확인받고 기록에 남깁니다.
  6. 확인되지 않은 항목은 진술 및 보증에 반영할지 법무가 판단하도록 넘깁니다.
잠깐 멈추고 검토할 때

주주명부와 실질주주명부의 차이가 많은 경우 · 명의신탁 주식이 있다는 정황이 확인된 경우 · 조사나 제재가 진행 중인데 매도인이 알리지 않은 경우 · 라이선스 조건이 인수 후 해지 가능성을 보이는 경우
