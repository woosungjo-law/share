증거보전 긴급조치와 법적 홀드

3줄 요약

  • 증거보전에서 '나중에'는 없다. 보전과 법적 검토는 반드시 병렬로 진행하라.
  • 의혹 인지 즉시 이메일·문서·메신저 접근 권한을 동결하고 삭제 방지 조치를 실행하라.
  • 법적 검토 완료 전이라도 이메일 서버 측 삭제 방지·노트북 이미징·로그 추출은 즉시 가능한 조치다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사전)

범위 설정(003) -> [증거보전·법적 홀드] -> 포렌식(005)

1. 이번 단계에서 반드시 할 일

  • [ ] IT팀에 즉시 데이터 삭제 방지 설정 요청(이메일 서버·클라우드·문서 서버)
  • [ ] 대상자 업무용 PC·노트북 이미징(비트 단위 복제) 24시간 내 착수
  • [ ] 대상자에게 '자료 삭제·이동 금지' 공문 공식 발송
  • [ ] 외부저장장치 접속 로그·클라우드 접속 이력·출입 기록 보전 요청
  • [ ] 보전 과정의 모든 일시와 담당자 기록(Chain of Custody)

4. 흔한 실수

  • "법적 검토 먼저" 하다가 증거 인멸 골든타임 상실 — 보전과 검토는 병렬 진행
  • 이메일·메신저에만 집중하고 로그·클라우드·출입기록 누락
  • 대상자의 접근 권한을 그대로 유지 — 퇴직자·의혹 대상자 즉시 차단 필요

5. 전문가 상담 신호

위험도: 혼자 가능

  • 디지털 증거의 휘발성이 높은 경우(퇴직 예정자, 외부 저장장치 사용자)
  • 개인 휴대전화·사적 계정 확인이 필요한 경우 — 별도 동의·법적 검토 필수
