쟁점별 소명·증빙 준비

3줄 요약

- 조사관이 특정 항목을 집중적으로 질문하면 해당 쟁점에 대한 집중 소명이 필요하다.

- 소명은 사실관계 정리 → 법리 검토 → 증빙 자료 제출 순서로 체계적으로 준비한다.

- 소명자료를 제출할 때는 조사관이 이해하기 쉽도록 요약문과 함께 제출하는 것이 효과적이다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


현장조사 대응(008) -> [쟁점별 소명·증빙 준비] -> 조사 범위 이의제기(010)

1. 이번 단계에서 반드시 할 일

- [ ] 쟁점별 사실관계 정리(어떤 거래·어떤 이유로 쟁점이 되었는지)

- [ ] 관련 법령·세무 해석 검토(세무사·변호사)

- [ ] 증빙 자료 수집·정리(계약서·세금계산서·거래내역 등)

- [ ] 소명서 작성(쟁점·사실관계·법리·증빙 순서)

- [ ] 소명자료 제출 전 내부 검토·승인

2. 준비물

준비물왜 필요한가준비 상태
조사관 질문 리스트·지적 사항쟁점 특정미확인
관련 계약서·세금계산서·거래명세서증빙 자료미확인
관련 법령·고시·예규·판례(세무사 제공)법리 검토미확인
소명서 양식체계적 작성미확인

3. 작성·제출물

문서제출처주의점
쟁점별 소명서조사관쟁점→사실관계→법리→증빙 순서, 간결 명료
증빙 자료(사본)조사관원본 대조필 날인, 목록 첨부
추가 자료 요청 목록(내부)재무팀부족 자료 추가 수집 계획

4. 흔한 실수

- 소명서에 추측·가정을 포함 — 조사관에게 불리한 실마리 제공

- 증빙 없이 구두로만 소명 — 문서에 비해 신빙성 낮음

- 법리 검토 없이 사실관계만 제출 — 세무 쟁점의 핵심을 놓침

- 소명 기회를 적극 활용하지 않고 수동적 대응 — 결과에 불복하기 어려워짐

5. 전문가 상담 신호

위험도: 상담 권장

- 쟁점이 다수이고 법리 해석이 복잡한 사안

- 소명 자료가 불충분하여 보완이 어려운 경우

- 조사관이 특정 쟁점에 대해 부정적 견해를 명확히 표시

6. 인접 절차 연결

선행: 008 · 후속: 010 조사 범위 이의제기 / 013 과세전적부심 청구
