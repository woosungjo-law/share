3MUST · 기업법무

CEO향 법률의견 작성요령 — 경영진이 의사결정할 수 있게 번역하는 원칙·금지·포맷

적용 상황: CEO·경영진이 법률적 함의를 이해하고 사업 결정을 내릴 수 있도록 법률의견을 작성·전달하는 경우

Must Know · 알아야 할 것

6원칙: 조건 명시·선택지 제시(2개+)·1페이지·비즈니스 언어·불확실성 표시(높음/보통/낮음)·오인 방지. 자문 특권(제3자 공개 금지). 상황별 변수(긴급/정기/전략/규제) 강조·생략 요소 조정.

Must Check · 확인할 것

  • 의견이 1페이지를 넘지 않는지(배경·의견·조건·권고 순) 확인
  • 전제 조건 명시 및 조건 변경 시 의견 달라짐 표기 확인
  • 최소 2개 이상 선택지가 리스크 등급과 함께 비교되는지 확인
  • 법률 용어가 경영진 언어로 번역됐는지(예: '소멸시효 중단'→'채권 소멸 방어 조치')
  • 확신의 정도(높음/보통/낮음)가 표시됐는지 확인
  • '무조건·항상·절대·100%' 등 단정 표현이 대체 표현으로 바뀌었는지 확인
  • 자문 특권·제3자 공개 금지 문구 포함 여부 확인
  • 상황(긴급/정기/전략/규제)에 맞게 강조·생략 요소 조정됐는지 확인

Must Do · 실행할 것

  1. 조건·배경 정리: 사실관계 2~3문장, 전제 조건 명시, 조건 변경 시 의견 달라짐 표기
  2. 선택지 비교표 작성: Option A/B/C를 리스크 등급·내용·권고(추천/비추천/조건부)로 비교
  3. 법률 의견 3~5문장: 구체적 법리 평가, 법조문·판례 간략 인용, 확신의 정도 표기
  4. 금지 표현 치환: 단정 표현을 리스크·조건·법리 기반 표현으로 대체
  5. 권고·후속 조치: 법무팀 권고 1~2문장과 이유, 후속 조치 체크리스트(결정 기한·로펌 추가검토·부서 통보)
잠깐 멈추고 검토할 때CEO가 이해할 수 있나요? 법률 용어 번역·1페이지 원칙 지켰는지 확인, 선택지 없이 결론만 제시했나요? 최소 2개 이상 선택지·리스크 비교 확인(단일 결론은 오인 위험), 조건 없이 단정했나요? 전제 조건 명시·조건 변경 시 의견 달라짐 표기 확인, 자문 특권 문구 있나요? 제3자 공개 금지·Attorney-Client Privilege 문구 포함 여부 확인, 상황에 맞게 조정했나요? 긴급/정기/전략/규제 상황별 강조·생략 요소 적용 확인
