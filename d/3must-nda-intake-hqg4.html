신규 거래처 NDA 요청이 도착했을 때

적용 상황: 신규 거래처와 정보를 주고받기 전에 NDA 체결 요청이 들어온 경우. 범위: 요청 접수, 담당자 확인, 서명 후 기록 관리까지의 업무 흐름을 정리합니다. 개별 조항의 법률상 적정성이나 협상 결론을 대신 판단하지 않습니다.

Must Know · 알아야 할 것

  • 요청이 어느 단계인지 먼저 구분합니다: 우리 쪽 초안 작성, 상대방 양식 검토, 기존 NDA 범위 확인.
  • 정보 제공 주체가 한쪽인지 양쪽인지, 여러 당사자가 함께 참여하는지 파악합니다. 이 구분은 검토 경로를 정하기 위한 접수 정보입니다.
  • 이 카드는 조항별 법률 검토를 대체하지 않습니다. 해외 준거법, 개인정보, 정부·공공기관, 복수 당사자 등 별도 판단이 필요한 사안은 담당자에게 검토를 연결합니다.

Must Check · 확인할 것

  • 사업부가 설명한 정보 공유 목적과 대략적인 범위를 받았는가?
  • 상대방이 NDA 양식을 보냈는가, 우리 쪽 양식이 필요한가?
  • 한쪽·양쪽·복수 당사자 중 누가 정보를 주고받는가?
  • 이미 체결된 NDA와 적용 범위를 확인했는가?
  • 상대방 법인 정보와 서명권한 확인 경로를 정했는가?
  • 해외 거래·개인정보·공공기관·복수 당사자처럼 추가 검토가 필요한 사정이 있는가?

Must Do · 실행할 것

  1. 요청자와 사업 담당자를 확인하고, 정보 공유 목적·범위·필요 일정을 기록합니다.
  2. 상대방 양식 검토, 우리 쪽 양식 준비, 기존 NDA 확인 중 필요한 검토 경로를 정합니다.
  3. 조항 검토가 필요한 문서는 담당 검토자에게 전달하고, 검토 전에는 법률상 적정하다고 단정하지 않습니다.
  4. 체결이 끝나면 서명된 원본을 보관하고 계약관리대장에 등록합니다.
  5. 관련 사업부에 체결 사실과 관리 담당을 공유하고, 만료·갱신 확인일을 기록합니다.
잠깐 멈추고 검토할 때

세 곳 이상이 정보를 주고받거나, 해외 준거법·개인정보·정부·공공기관 문제가 포함된 경우 담당 검토자에게 연결합니다. · 기존 NDA와 새 요청의 적용 범위가 충돌하거나, 정보 공유 목적을 정하지 못했다면 초안을 확정하지 말고 쟁점을 기록합니다.
