신규 거래처 NDA 요청이 도착했을 때

정보를 주고받기 전에 요청 단계와 담당자를 정리하고, 체결 뒤 관리까지 연결합니다.

적용 범위 · 요청 접수와 업무 기록 흐름입니다. 개별 조항의 법률상 적정성이나 협상 결론을 대신 판단하지 않습니다.

Must Know · 알아야 할 기준

  • 우리 쪽 초안, 상대방 양식, 기존 NDA 확인 중 어디에 해당하는지 구분합니다.
  • 정보 제공 주체가 한쪽·양쪽·복수 중 어디인지 파악해 검토 경로를 정합니다.

Must Check · 확인할 것

  • 정보 공유 목적·범위와 필요 일정을 받았는가?
  • 기존 NDA와 적용 범위를 확인했는가?
  • 법인 정보·서명권한 확인 경로를 정했는가?
  • 해외 거래·개인정보·공공기관·복수 당사자 등 추가 검토 사정이 있는가?

Must Do · 실행할 것

  1. 요청자·사업 담당자·정보 공유 목적·필요 일정을 기록합니다.
  2. 상대방 양식 검토, 우리 양식 준비, 기존 NDA 확인 중 필요한 경로를 정합니다.
  3. 검토가 끝난 문서만 체결 절차로 넘기고, 법률상 적정성을 미리 단정하지 않습니다.
  4. 체결 뒤 원본 보관, 계약관리대장 등록, 사업부 공유, 만료·갱신일 기록을 마칩니다.
