3 MUST · MULTI-PARCEL INTAKE

인접한 여러 필지를 함께 매매할 때 조건을 묶어 확인할 때

필지마다 소유자·문서·대금 조건이 다를 때, 기본정보와 접근·사용 계획, 진행상태를 한 표에 모아 계약 담당자에게 전달합니다.

범위 거래자료의 사실확인·대조 절차입니다. 계약의 법적 성격·효력·해제·계약금 효과는 판단하지 않습니다.

Must Know · 먼저 알아야 할 것

  • 필지별 소유자·문서·대금 조건을 한 묶음 안에서 각각 구분합니다.
  • 접근·사용 관계는 확인 자료와 담당자 설명을 구분해 기록합니다.
  • 허가·협의 상태와 합의된 조건, 제안·미정 항목을 섞지 않습니다.

Must Check · 반드시 확인할 것

항목필지별 기록필지 간 확인
기본정보식별정보·등기 자료·기준일접근·인접 관계 자료
거래 주체소유자·매도인·담당자문서상 당사자 차이
사용 계획예정 용도·준비 항목다른 필지 계획에 미치는 운영상 영향
진행 상태허가·협의·현장 확인 담당과 상태공통 일정·선행 작업
조건·문서대금·지급일·제안/합의 표시문서별 차이·버전·연결 관계
  • 사실·상대방 설명·내부 계획을 구분
  • 근거 자료 위치와 확인 담당자 연결
  • 법률 검토 질문은 사실표와 분리

Must Do · 지금 할 일

  1. 거래 대상 필지별로 소유·계약·연락 자료를 별도 행에 정리합니다.
  2. 접근 경로와 사용 계획을 도면·공적 자료 또는 담당자 확인 내용에 연결합니다.
  3. 허가·협의·현장 확인의 상태, 담당자, 확인일, 남은 자료를 씁니다.
  4. 계약 초안·제안서·대화에서 필지별 대금과 지급 조건을 추려 차이를 표시합니다.
  5. 문서 버전과 조건 변경을 목록에서 추적합니다.
  6. 사실표와 미정 질문을 계약 담당자에게 넘기고 법적 구조·문구는 별도 검토로 남깁니다.
