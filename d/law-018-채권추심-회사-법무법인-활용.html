채권추심 회사·법무법인 활용

3줄 요약

  • 채권추심 회사(채권추심업 등록 업체)에 위탁하면 직접 추심의 번거로움을 줄일 수 있지만, 수수료(보통 성공보수 10~30%)가 발생한다.
  • 변호사·법무법인에 위임하면 법적 절차(지급명령·소송·강제집행)까지 일괄 처리 가능하지만 비용이 더 높다.
  • 채권추심업체는 채권추심법의 규제를 받으므로, 불법 추심 이력이 있는 업체는 피해야 한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사후)

강제집행(017) -> [채권추심 회사·법무법인 활용]

1. 이번 단계에서 반드시 할 일

  • 채권 위탁 추심 vs 직접 추심 비용·효율 비교
  • 채권추심 회사 등록 여부 확인(한국채권추심협회·금융감독원)
  • 위탁 계약서 조건(성공보수율·기간·위약금) 확인
  • 변호사 선임 시 법률상담·소송 대리 비용 비교
  • 채권추심 의뢰 시 채무자에 대한 통지(채권추심업법 준수)

2. 준비물

준비물 왜 필요한가 준비 상태
채권 관련 증빙자료 위탁 시 제출 필요 미확인
채권추심 업체 리스트 업체 선정 미확인
위탁 계약서 양식 조건 검토 미확인

3. 작성·제출물

문서 제출처 주의점
채권추심 위탁 계약서 채권추심 업체 성공보수·기간·철회 조건 확인
변호사 위임장(선택) 법무법인 소송·강제집행 대리

4. 흔한 실수

  • 등록되지 않은 불법 채권추심 업체에 의뢰 — 채무자에게도 불법 추심으로 문제, 채권자도 규제 대상
  • 위탁 후 채권추심 과정을 방치 — 불법 추심 발생 시 채권자도 책임
  • 채권 이관 후 직접 채무자와 접촉 — 채권추심 혼선, 법적 문제 발생 가능
  • 성공보수가 과도하게 높은 계약(회수 금액의 30% 초과) — 경제적 효율성 하락

5. 전문가 상담 신호

위험도: 상담 권장

  • 채권 금액이 크고(5천만 원 이상) 법적 절차가 필요한 경우
  • 채무자가 법인·외국인여서 특수한 절차가 필요한 경우
  • 채권추심 업체 선정 기준이 불명확한 경우
