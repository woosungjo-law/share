장례식장 견적과 실제 청구 내역을 대조할 때

적용 상황: 장례 서비스 견적을 받았거나 이용을 마친 뒤, 선택한 항목과 실제 청구 내용을 가족이 함께 정리하려는 상황.

Must Know · 알아야 할 것

  • 이 카드는 견적과 실제 이용·청구 자료를 정리하는 운영 참고자료다. 청구의 정당성, 계약 해지, 환급이나 비용 부담 의무를 판단하지 않는다.
  • 처음 받은 견적과 이용 중 추가된 항목, 최종 청구서를 나누어 두면 어떤 부분의 설명이 필요한지 확인하기 쉽다.
  • 자료에 없는 사용량·선택 내용·합의는 추측하지 말고 미확인으로 남긴다.

Must Check · 확인할 것

  • 견적서와 계약서에 적힌 서비스 범위, 항목별 금액, 작성일을 보관했는가.
  • 실제 선택하거나 사용한 물품·서비스의 항목과 수량을 확인할 자료가 있는가.
  • 이용 중 추가·변경한 항목은 내용, 시각, 요청·확인한 사람을 기록했는가.
  • 최종 청구서와 영수증의 항목·수량·금액이 서로 맞는가.
  • 장례식장과 주고받은 안내·질문·회신의 원본과 받은 날짜를 보관했는가.
  • 고인·유족의 개인정보가 불필요하게 복사되거나 공유되지 않도록 자료 접근 범위를 정했는가.

Must Do · 실행할 것

  1. 견적서·계약서·최종 청구서·영수증을 원본 그대로 보관하고, 각 자료를 받은 날짜와 경로를 적습니다.
  2. 항목마다 견적 내용 / 실제 선택·이용 내용 / 최종 청구 / 비교자료 / 차이 또는 질문을 한 줄씩 대조합니다.
  3. 추가·변경된 항목은 기억만으로 채우지 말고, 남아 있는 안내·메시지·확인 기록과 구분해 적습니다.
  4. 설명이 필요한 항목은 해당 항목과 확인하고 싶은 내용을 중립적으로 정리해 문의하고, 보낸 질문과 답변을 함께 보관합니다.
  5. 취소·환급·추가 비용의 책임이나 법적 권리가 쟁점이 되면, 원자료와 시간순 기록을 담당 전문가에게 전달해 별도로 검토합니다.
잠깐 멈추고 검토할 때

계약서·견적서·청구서의 항목이나 금액이 서로 다르고 자료만으로 이유를 확인할 수 없다. · 취소, 환급, 지급 보류 또는 비용 부담 의무에 관한 결론이 필요하다. · 여러 가족의 기억이 다르거나 개인정보가 포함된 문서를 넓게 공유하려는 상황이다.
