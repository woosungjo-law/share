PROC-RAID-007 | 영장 원본 확인 및 메모 (복사본 요구)

3줄 요약

- 영장 원본을 반드시 육안으로 직접 확인하고(팩스·모바일 이미지·사진은 원본이 아님), 법원 명칭·발부일자·판사 날인·사건번호·피의자·혐의사실·압수대상물품·수색장소 8개 항목을 전부 메모해야 한다

- 수사관에게 영장 사본 또는 촬영본의 즉시 교부를 요구할 권리가 있으며(형소법 제118조 단서 해석상 청구권 인정), 거부 시 현장 기록으로 남겨야 한다

- 영장 기재 내용과 실제 집행 범위가 다른 경우(초과수색·무관물건 압수)를 입증하려면 이 단계에서의 정확한 기록이 유일한 증거가 된다

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


PROC-RAID-006(변호사 호출) -> [PROC-RAID-007: 영장 원본 확인·복사] -> PROC-RAID-008(범위 적정성 확인)

1. 이번 단계에서 반드시 할 일

- [ ] 영장 원본을 직접 손에 쥐고 다음 8개 항목을 메모·촬영한다:

- ① 법원명(예: 서울중앙지방법원) ② 발부일자 ③ 사건번호(예: 2026-초-1234)

- ④ 피의자 성명·주소 ⑤ 혐의사실(구체적 법조문 포함)

- ⑥ 압수대상물품(전자정보·서류·현금·계좌 등 구체적 기재 확인)

- ⑦ 수색장소(주소+건물·층·호수까지 특정되었는지)

- ⑧ 유효기간(영장 하단 기재 — 기간 경과 시 집행 불가)

- [ ] 수사관에게 "영장 사본을 교부해달라"고 명시적으로 요구한다 — 구두 요구를 거부하면 거부 사실을 메모에 기재

- [ ] 사본 교부가 불가능하면 스마트폰으로 영장 전면(앞면+뒷면)을 촬영한다 — 수사관이 촬영 자체를 막으면 그 사실을 기록

- [ ] 영장의 압수대상물품과 수색장소가 구체적으로 특정되었는지 판단한다 — "관련 서류 일체" 등 포괄적 기재는 위법성 논란 가능

- [ ] 영장에 야간집행 금지 조항 또는 집행 가능 시간대가 명시되어 있는지 확인한다(야간=일반적으로 일몰 후~일출 전)

- [ ] 영장 원본에 임의로 메모·표시하지 않는다 — 훼손으로 항의받을 수 있음

- [ ] 영장의 유효기간(보통 발부일로부터 7일 이내)이 경과했는지 확인 경과 시 집행 거부 사유

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 실수 1: 영장을 1초만 흘낏 보고 "예, 맞습니다" 하고 넘김 → 영장 기재사항을 전혀 기억하지 못해 이후 집행 범위 다툼 불가

- 실수 2: 수사관이 "영장은 원본 1부고 저희 업무용이니 사진 찍지 마세요"라는 말에 수긍 → 영장 사본·촬영 요구는 당연한 권리, 거부 시 자기부죄금지 원칙·적법절차 침해 논란으로 연결

- 실수 3: 영장 확인 시 피의자만 확인하고 압수대상물품 특정 여부를 안 봄 → "전자정보 저장매체"만 기재된 포괄영장인데도 정당한 집행으로 수인

- 실수 4: 영장 사본 대신 "영장 번호만 메모해두겠다"고 넘김 → 나중에 정확한 영장 문언(피의자·혐의·범위)이 필요할 때 법원에서 영장 사본을 받으려면 별도의 절차가 필요하고 시간이 오래 걸림

- 실수 5: 영장 촬영 시 앞면만 찍고 뒷면(판사 날인·유효기간·야간집행제한)을 놓침 → 뒷면에 집행조건이 기재되어 있어도 입증 불가

5. 전문가 상담 신호

위험도: 상담 권장

- 영장에 압수대상물품이 '범죄사실과 관계된 전자정보 일체' 또는 '관련 문서 일체' 처럼 포괄적으로 기재된 경우 — 포괄영장의 증거능력 다툼 가능

- 영장에 기재된 수색장소가 회사 주소와 다른 경우(예: 다른 법인 주소·개인 주거지) — 오기·착오 가능성, 즉시 영장 재확인 필요

- 위험도: 전문가 필요

- 영장의 발부법원이 관할법원이 아닌 것으로 의심되는 경우(예: 서울 사업장인데 부산지법 영장) — 관할 위반 다툼

- 영장에 야간집행 가능 시간대가 명시되어 있는데 현 시각이 그 시간대를 벗어난 경우 — 집행 거부 사유

- 영장에 피의자의 이니셜·오기·연도 오류 등 명백한 기재 오류가 발견된 경우 — 영장 효력 자체 다툼

6. 인접 절차 연결

- 선행: PROC-RAID-006 (변호사 호출) — 변호사가 영장 확인을 원격으로 지도 가능 · 후속: PROC-RAID-008 (영장 집행 범위·압수 대상 적정성 확인)

- 병행: PROC-RAID-005에서 확인한 신분증 정보와 영장 정보를 대조 — 출동 수사관 소속이 영장 집행 권한이 있는 기관인지 확인
