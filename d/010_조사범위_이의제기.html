조사 범위 이의제기

3줄 요약

- 조사관이 통지서에 없는 세목·과세기간의 자료를 요구하거나 조사 범위를 넘는 질문을 하면 이의를 제기할 수 있다.

- 이의제기는 1차 구두 → 2차 서면(조사반장) → 3차 세무서장 → 4차 국세청 감사관으로 단계를 밟는다.

- 범위 이의제기는 초기에 할수록 효과적이며, 범위가 확정된 후에는 철회가 어렵다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


쟁점별 소명(009) -> [조사 범위 이의제기] -> 자료제출 거부·비밀유지(011)

1. 이번 단계에서 반드시 할 일

- [ ] 이의제기 대상 범위 특정(통지서 대비 초과된 부분)

- [ ] 1차 구두 이의 제기(조사관에게 즉시)

- [ ] 서면 이의제기 준비(사유·근거 법령 명시)

- [ ] 이의제기 진행 상황·결과 기록

- [ ] 필요 시 상급 기관(세무서장·국세청 감사관)에 이의 제기

2. 준비물

준비물왜 필요한가준비 상태
통지서 사본범위 기준 확인미확인
조사관 요구 자료·질문 내역 기록범위 초과 증빙미확인
서면 이의제기 양식·법률 검토 의견체계적 이의제기미확인

3. 작성·제출물

문서제출처주의점
조사 범위 이의제기서조사반장 → 세무서장범위 초과 구체적 명시·근거 법령 기재, 사본 보관
조사 범위 위반 신고서(필요 시)국세청 감사관최종 수단, 신중히 검토 후 사용

4. 흔한 실수

- 이의제기를 미루다가 범위가 확정됨 — 나중에 철회 어려움

- 구두로만 이의제기하고 서면 기록 없음 — 증거 부족

- 이의제기가 조사관의 감정을 상하게 할까 봐 주저함 — 권리 행사는 정당한 절차

5. 전문가 상담 신호

위험도: 상담 권장

- 이의제기가 받아들여지지 않아 상급 기관에 제기할 필요가 있는 경우

- 조사관이 이의제기를 이유로 조사 태도를 불리하게 변경하는 경우
