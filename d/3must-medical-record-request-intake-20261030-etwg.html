진료기록 열람·사본 요청이 들어왔을 때 처리 내역을 정리할 때

적용 상황: 의료기관에 환자 본인 또는 다른 사람이 진료기록 열람·사본을 요청해, 접수 내용과 내부 검토·처리 경위를 정리해야 할 때 사용합니다. 범위: 요청을 접수하고 필요한 확인을 담당자에게 넘기며, 검토 결과와 실제 전달 이력을 기록하는 내부 업무 절차입니다. 누가 법적으로 열람·발급을 청구할 수 있는지, 어떤 자료를 제공해야 하는지, 법정 처리기한·비용·거부사유는 판단하지 않습니다.

Must Know · 알아야 할 것

  • 요청을 접수했다는 사실과 기록을 외부에 전달해도 된다는 결정은 구분합니다.
  • 접수 담당자는 요청 내용을 사실대로 기록하고, 요청 주체·범위 확인은 기관의 담당 절차와 지정된 검토자에게 넘깁니다.
  • 진료기록에는 개인의 건강정보와 다른 사람의 정보가 함께 있을 수 있으므로, 열람·복사·전달 범위를 임의로 넓히지 않습니다.
  • 기록이 없거나 요청 내용과 맞지 않으면 새로 만들어 채우지 말고, 확인 결과와 미확인 사항을 분리해 둡니다.

Must Check · 확인할 것

  • 요청을 받은 날짜·시각·경로와 접수한 담당자
  • 요청서에 적힌 요청자 정보와 회신 가능한 연락 방법
  • 요청서에 표시된 환자·진료 기간·기록 종류·요청 목적의 범위
  • 본인 또는 다른 사람을 대신한 요청인지, 관련 확인을 맡을 담당자
  • 내부 검토 담당자·현재 상태·추가 확인 자료·회신 예정 정보
  • 기록이 여러 곳에 나뉘어 있는지, 제3자 정보나 다른 환자 정보가 섞였는지
  • 승인된 전달 방식과 실제 전달 여부를 나중에 확인할 수 있는 기록

Must Do · 실행할 것

  1. 요청서 원본과 접수 시각을 보존하고, 요청에 적힌 범위와 연락 방법을 그대로 기록합니다.
  2. 요청 주체와 처리 권한 확인은 지정된 의무기록·개인정보 담당자에게 넘깁니다. 접수자가 법적 자격이나 제공 범위를 직접 판단하지 않습니다.
  3. 기록 종류와 기간을 목록으로 정리하고, 어디에 어떤 자료가 있는지 내부 담당자에게 확인합니다. 요청된 범위를 넘는 자료를 임의로 모으거나 보내지 않습니다.
  4. 누락·불일치·제3자 정보가 보이면 별도 표시하고 담당 검토를 받습니다. 원본 기록을 덮어쓰거나 사후에 내용을 보충하지 않습니다.
  5. 검토 결과와 결정자를 요청 범위별로 기록합니다. 추가 확인 중이면 완료로 표시하지 않습니다.
  6. 전달 승인이 난 범위만 기관의 승인된 안전한 경로로 전달하고, 실제 전달한 자료·수신처·시각·담당자를 남깁니다.
잠깐 멈추고 검토할 때

요청자가 누구인지 또는 다른 사람을 대신해 요청할 수 있는지 확인되지 않은 경우 · 서로 다른 요청이 들어오거나 요청 범위가 달라 어느 내용을 처리할지 불분명한 경우 · 다른 환자·가족·직원의 정보가 섞여 있거나 외부 전달 범위를 정하기 어려운 경우 · 공식 문서에 회신 일정이 적혀 있거나 분쟁·수사·법원 제출과 연결된 요청인 경우 · 기록을 찾지 못했거나 이미 변경·이관·폐기된 흔적이 있어 현재 상태를 설명하기 어려운 경우

원자료: 진료기록 작성·보존·열람·발급·정보주체 분쟁을 다루는 내부 독트린의 주제만 참고했습니다.
