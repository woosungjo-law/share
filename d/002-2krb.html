익명 제보 처리와 신고자 보호

3줄 요약

  • 익명 제보의 진짜 함정은 내용 부실이 아니라, 법무팀이 혼자 그 정보를 들고 있는 시간이다.
  • 접수 즉시 감사위원회에 보고하고, 예비조사(Preliminary Inquiry) 단계를 통해 객관적 사실 확인부터 해야 한다.
  • 신고자 신원 추적은 절대 금지 — 보호 원칙을 피조사자에게 명확히 고지하고 통화 내용을 기록한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사전)

접수·개시(001) -> [익명 제보 처리] -> 증거보전(004)

1. 이번 단계에서 반드시 할 일

  • [ ] 제보 내용을 3단계(구체형·반구체형·추상형)로 분류
  • [ ] 익명 제보 접수 즉시 법무팀장·감사위원회에 서면 보고
  • [ ] IT팀·인사팀에 신고자 신원 추적 금지 지시 공문 발송
  • [ ] 예비 조사(Preliminary Inquiry) 개시 — 피조사자 통보 없이 객관적 자료만 검토

4. 흔한 실수

  • 익명이란 이유로 제보를 무시 — 법적 조사 의무 회피로 해석될 위험
  • 피조사자(특히 임원)의 신원 확인 요구를 수용 — 보복 행위로 전환 가능
  • 혼자 고민하다 보고 시점을 놓침 — 결정 지연이 은폐로 해석됨

5. 전문가 상담 신호

위험도: 상담 권장

  • 경영진이 피조사자 편에서 압박을 넣는 경우
  • 익명 제보가 다수 또는 조직적 비위를 지목하는 경우
