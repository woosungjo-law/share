ID: PROC-INVS-016단계: 결정검증: L2

조사보고서 작성과 유통 통제

3줄 요약

  • 법무팀이 요약본을 쓰지 않으면 조직이 쓴다. 원본과 함께 법무팀이 직접 작성한 공식 요약본을 동시 제출하라.
  • 보고서 결론은 [현재 판단 — 핵심 전제 — 추가 조사 필요성]의 3층 구조로 설계해 전제 삭제 시 결론이 성립되지 않게 한다.
  • 보고서 표지에 "법무팀장 승인 없는 요약·편집·발췌 금지" 문구를 명시하고, 배포 대장을 작성한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 결정)

임원 조사(015) -> [보고서 작성·유통 통제] -> 사실인정(017)

1. 이번 단계에서 반드시 할 일

  • [ ] 보고서 구조 설계 — 사안 개요·조사 경과·확인 자료·주요 진술·인정 사실·법적 평가·조치 권고·재발방지안
  • [ ] 사실과 평가를 분리하여 작성
  • [ ] 법무팀 직접 작성 1페이지 공식 요약본 동시 제출
  • [ ] 보고서 표지에 유통 제한 문구 명시
  • [ ] 배포 대장 작성 — 누가 어떤 버전을 받았는지 기록

3. 작성·제출물

| 문서 | 제출처 | 주의점 | |---|---|---| | 조사보고서(원본) | 감사위원회(정식 보고) | 사실과 평가·권고 분리 | | 공식 요약본(1페이지) | 감사위원회·CEO(동시 제출) | '원본의 전제와 함께 읽어야 함' 명시 | | 배포 대장 | 법무팀(내부) | 버전·수령인·일시 기록 |

4. 흔한 실수

  • 원본만 제출하고 요약본 작성을 타 부서에 위임 — 왜곡된 요약에 법무팀 이름 도용
  • 결론의 전제 조건(증거 한계 등)을 본문 깊숙이 배치 — 요약 과정에서 누락
  • 보고서 유통을 통제하지 않음 — 여러 버전이 돌아다니며 혼선
  • 경영진 보고 시 법무팀 참석 없이 타 부서장이 설명 — 맥락 왜곡

5. 전문가 상담 신호

위험도: 혼자 가능

  • 이사회 제출용 보고서로, 외부 조사와 연계된 경우
  • 조사 결과가 형사 고소·징계·언론 대응 등으로 이어질 가능성이 있는 경우
