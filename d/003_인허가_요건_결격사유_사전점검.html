인허가 요건·결격사유 사전점검

3줄 요약

- 인허가 신청 전 법적 요건(주관적·객관적)과 결격사유를 먼저 점검해야 기각·보완 리스크를 줄인다.

- 결격사유는 허가 후에도 발생할 수 있어 사후관리도 필요하다.

- 요건 충족이 불확실하면 사전협의·사전컨설팅을 활용해 기관과 사전 조율한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사전)


리스크 매핑(002) -> [요건·결격사유 점검] -> 행정처분 리스크 탐지(004)

1. 이번 단계에서 반드시 할 일

- [ ] 법률·시행령·시행규칙·고시별 요건 체크리스트 작성

- [ ] 신청인·임원진 결격사유 전수 조회

- [ ] 시설·자본·인력·기술 요건 충족 여부 확인

- [ ] 필요시 사전협의·사전컨설팅 신청

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 결격사유를 신청 시점에만 확인하고 종료 — 허가 후 발생 결격사유 관리 소홀

- 하위규정(고시·훈령)에 상세 요건이 있는데 법률 조문만 확인

- 유사 업종의 인허가 거부 선례를 확인하지 않고 신청 진행

5. 전문가 상담 신호

위험도: 혼자 가능

- 복수의 인허가가 연계된 경우(폐기물처리 + 건축 + 환경영향평가)

- 결격사유가 의심되는 임원·주주 구조

- 규제 샌드박스·실증특례 등 특별 절차가 필요한 경우

6. 인접 절차 연결

선행: 002 · 후속: 004 행정처분 리스크 조기탐지
