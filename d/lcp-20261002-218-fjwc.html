AI 학습데이터 공정이용 판단 체크리스트

결론부터. 학습 데이터의 양이 아니라 법적 근거와 중단 기준이 먼저 승인 대상이다. 저작권법 제35조의5 공정이용은 자동 면책이 아니고 이용 목적과 성격, 저작물의 종류, 사용량과 질적 중요성, 기존·잠재 시장 영향을 종합하므로 데이터별로 위험이 다르며, “연구용”이라는 설명이 실제로는 유료 서비스나 모델 배포를 포함하는지도 확인한다. 개인정보가 있으면 개인정보 보호법 제15조의 수집·이용 근거와 정보주체가 예상할 수 있는 사용 범위를 따로 확인하고, 시행령 제30조와 연결된 접근권한·로그·보관·파기·외부 위탁 통제까지 갖춰야 사고 시 데이터셋 버전과 접근기록을 제출할 수 있다.

1비유로 먼저 이해하기

비유하면, 학습 데이터 조달은 원재료 입고 검사와 같다. 값과 양만 받으면 나중에 권리 출처와 개인정보 포함 여부를 하나하나 다시 확인해야 하고, 삭제 요청이나 옵트아웃이 들어왔을 때 어느 데이터셋에 섞였는지 찾아 재학습하는 비용과 기간이 커진다. 출처별로 분류해 두면 위험 자료를 제외해도 제품 가치가 유지되는지 계산할 수 있고, 연구 단계에서 유료 서비스로 전환되거나 학습 결과를 외부에 공개할 때 재승인 여부도 같은 기록으로 판단한다.

2법이 실제로 보는 지점

저작권법 제35조의5 공정이용은 자동 면책이 아니다.

이용 목적과 성격, 저작물의 종류, 사용량과 질적 중요성, 기존·잠재 시장 영향을 종합하므로 데이터별 위험이 달라질 수 있다.

국내 확인 판례도 연구·학술 목적이라는 명칭만으로 공정이용을 인정하지 않았다는 점을 보고받고, 영리 연구개발과 출처관리 부실을 위험요소로 반영한다.

개인정보가 있으면 개인정보 보호법 제15조의 수집·이용 근거와 정보주체가 예상할 수 있는 사용 범위를 따로 확인한다.

시행령 제30조와 연결된 안전성 확보 조치로 접근권한, 로그, 보관·파기, 외부 위탁을 정하고, 사고가 나면 데이터셋 버전과 접근기록을 제출할 수 있어야 한다.

저작권 승인과 개인정보 승인을 하나의 “통과” 표시로 줄이지 않는다.

3중요한 조건과 예외

  • 범위 — 적어 둔 각 조문·기준의 범위를 넘겨 새로운 결론을 만들지 않는다.
  • AI 프로젝트가 빠르게 학습 데이터를 확보하자고 하면 대표는 데이터 양보다 법적 근거와 중단 기준을 먼저 승인해야 한다.
  • 수집 출처, 데이터 종류, 상업 서비스 사용 여부, 라이선스 비용, 개인정보 포함 여부를 한 장의 의사결정표에 넣는다.
  • “연구용”이라는 설명이 실제로는 유료 서비스나 모델 배포를 포함하는지도 확인한다.
  • 라이선스를 살 수 있는 자료와 공정이용 검토가 필요한 자료를 나누고, 위험 자료를 제외해도 제품 가치가 유지되는지 계산한다.
  • 삭제 요청이나 옵트아웃을 받을 때 데이터셋에서 제거하고 재학습할 비용과 기간도 예산에 넣는다.
  • 사고 후 손해배상은 대법원 2023다311184의 사실관계가 같은지 확인한 뒤 법무팀의 별도 의견으로 판단한다.
  • 데이터 구매 예산에는 라이선스료만 넣지 말고 권리 확인, 개인정보 필터링, 삭제·재학습, 보안 로그와 사고 대응 비용까지 포함한다.
  • 외부 제공자가 권리를 보증하더라도 계약서의 보증 범위, 감사권, 분쟁 시 데이터 중단과 교체 의무를 확인한다.
  • 프로젝트가 연구 단계에서 유료 서비스로 전환되거나 학습 결과를 외부에 공개하면 재승인을 받는다.
  • 라이선스 구매·수집 중단·위험군 제외의 비용을 비교하고, 출처와 삭제 요청 기록을 보존할 책임자를 지정한다.
  • 사실관계가 바뀌어 상업 서비스나 공개 모델로 확대되면 기존 승인으로 갈음하지 않고 재승인한다.
  • 제품 출시 뒤 데이터 출처나 이용 목적이 바뀌면 초기 승인으로 밀어붙이지 않고 재검토한다.
  • 라이선스 구매와 위험 데이터 제외의 비용, 삭제 요청에 대한 고객 신뢰, 사고 시 설명 가능한 기록을 함께 비교해 계속·축소·중단을 결정한다.
  • 경영진 보고에는 데이터셋 규모보다 위험 데이터의 비율, 라이선스 확보율, 삭제 요청 처리율, 접근기록 점검 결과와 미확인 항목을 넣는다.
  • 법무팀이 검토하지 않은 출처를 일정 압박 때문에 추가하지 않으며, 서비스 출시 전후의 이용 목적이 달라지면 예산과 일정도 다시 승인한다.
  • 삭제 요청이나 출처 분쟁이 들어왔을 때 어느 데이터셋과 모델 버전에 영향을 주는지 바로 확인할 수 있도록 담당자를 지정한다.
  • 사업 속도보다 설명 가능한 기록을 우선하고, 확인되지 않은 데이터는 사용을 보류한다.
  • 데이터 사용 승인과 제품 출시 승인을 같은 결재로 처리하지 않는다.
핵심. 저작권 승인과 개인정보 승인은 하나의 “통과” 표시로 줄이지 않고, 데이터 사용 승인과 제품 출시 승인을 같은 결재로 처리하지 않는다.

4그래서, 대표가 정할 것

저작권법 제35조의5 네 요소별 판단표, 개인정보 보호법 제15조의 수집 근거, 시행령 제30조의 안전통제를 보고받는다.

  1. ① 연구와 상업 서비스의 실제 사용 목적을 구분한다.
  2. ② 제35조의5 시장 영향과 이용의 질적 중요성을 확인한다.
  3. ③ 제15조 수집 근거와 정보주체 기대를 확인한다.
  4. ④ 시행령 제30조 통제와 사고 기록 보존을 승인한다.
