외부 전문가 선임·조력권 행사

3줄 요약

- 납세자는 세무조사에서 변호사·공인회계사·세무사의 조력을 받을 권리가 있다(국세기본법 제81조의5).

- 세무사·회계사·변호사는 각각 세무쟁점·회계검증·법률방어 역할이 다르므로 상황에 맞게 선임해야 한다.

- 범칙조사(조세범처벌법 위반 혐의)는 반드시 형사 변호사를 선임해야 한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후


통지서 분석·팀 구성(002) -> [외부 전문가 선임] -> 장부·소명자료 정비(004)

1. 이번 단계에서 반드시 할 일

- [ ] 조사 유형에 맞는 외부 전문가 선임 기준 결정

- [ ] 세무사·회계사·변호사 각각의 역할·범위 계약

- [ ] 선임된 전문가에게 통지서·관련 자료 일괄 전달

- [ ] 전문가의 조사 참여(입회·의견진술) 일정 협의

- [ ] 변호인-의뢰인 비밀 유지(변호사법) 범위 확인

2. 준비물

준비물왜 필요한가준비 상태
통지서·관련 세무자료 사본전문가 상황 판단용미확인
전문가 선임계약서 양식신속 계약 체결미확인
전문가별 역할 범위·보수 기준 내부 검토안효율적 선임미확인

3. 작성·제출물

문서제출처주의점
전문가 위임장·계약서해당 전문가역할 범위·보수·비밀유지 조항 명시
세무조사 대응 위임 전결권 설정(내부 결재)경영진전문가 선임 비용·의사결정 권한 명확화

4. 흔한 실수

- 일반 세무사만 선임하고 변호사 선임을 소홀히 함 — 범칙조사 전환 시 대응 불가

- 변호사 선임 시 세무 전문 변호사인지 확인하지 않음 — 일반 변호사는 세무 쟁점 이해도 부족

- 전문가 선임을 조사 시작 후로 미룸 — 초기 대응 방향 설정 실기

5. 전문가 상담 신호

위험도: 상담 권장

- 통지서에 범칙조사·조세범처벌법 위반 혐의 명시 — 즉시 형사 변호사 선임 필수

- 과거 세무조사에서 불이익을 받은 이력이 있음

- 쟁점이 다수이고 세무·회계·법률이 복합된 사안

6. 인접 절차 연결

선행: 002 · 후속: 004 장부·소명자료 정비

7. 근거 조문·판례
