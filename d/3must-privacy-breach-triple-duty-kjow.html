개인정보 유출 사고 — 첫 대응 3중 의무와 손해배상 노출

적용 상황: 기업에서 개인정보 유출 사고가 발생해 신고·통지·손해배상 대응이 필요한 경우

Must Know · 알아야 할 것

3중 의무 동시 발생(원자료 기준): ①KISA 신고(72시간) ②정보주체 통지 ③법정손해배상(1인당 최대 300만원). 근거: 개인정보보호법 제34조(통지·신고)·제39조(손해배상), 정보통신망법 제48조. 원인(해킹/내부실수/관리소홀)별 과징금·과태료·징벌적 배상 차등. 손해배상 인정범위 판례(대법원 2023다311184). ※초안 독트린(draft, 0.7) — 최신 판례·72시간 규정 별도 확인 필요.

Must Check · 확인할 것

  • 유출 인지 시점 정확 기록(72시간 기산점)
  • 유출 항목·규모(정보주체 수) 파악
  • 유출 원인(해킹·내부실수·관리소홀) 확인
  • KISA 신고 대상·요건 해당 여부
  • 정보주체 통지 대상·방법·내용
  • 법정손해배상(1인당 최대 300만원) 노출 규모
  • 과징금·과태료 원인별 노출 평가
  • 증거 보전(로그·접속기록)·재발방지 계획

Must Do · 실행할 것

  1. 인지 시점 기록·72시간 기산: 즉시 문서화, 신고 기한 역산
  2. 규모·항목 파악: 유출 항목·정보주체 수 신속 확정
  3. KISA 신고: 대상이면 72시간 내 신고
  4. 정보주체 통지: 대상·방법·내용 정해 지체 없이 통지
  5. 노출 규모 산정: 법정손해배상·과징금·과태료 원인별 평가
  6. 증거 보전·재발방지: 로그·접속기록 보전, 재발방지 계획
