행정조사·현장조사 초동대응

3줄 요약

- 행정조사는 기관의 조사권한·범위를 먼저 확인하고, 변호인 동석·자료 준비·진술 통제 순서로 대응한다.

- 조사관의 권한 표시(증표) 확인과 조사 범위 이탈 여부를 지속 점검한다.

- 초동 1시간의 대응이 전체 조사 결과를 좌우한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 착수)


원보이스 체계(009) -> [행정조사·현장조사 초동대응] -> 자료제출 전략(011)

1. 이번 단계에서 반드시 할 일

- [ ] 조사관 신분·권한·조사 범위 확인(증표·조사영장·지휘서)

- [ ] 변호인 연락·동석 요청

- [ ] 자료보존(Legal Hold) 즉시 발동 — 증거인멸 금지 통보

- [ ] 현장 진술·질문에 즉답 금지, 변호인 검토 후 답변

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 증표·권한 확인 없이 조사 수용 — 위법 수집 증거 가능성

- 현장에서 즉답·즉석 진술 — 이후 입장 번복 곤란

- 임직원이 개별적으로 진술 — 내부 입장 모순·혼선

- 자료보존 명령 미발동 — 증거인멸 의심받을 위험

5. 전문가 상담 신호

위험도: 전문가 필요

- 조사가 형사 절차로 전환될 가능성이 있는 경우

- 대규모·동시다발적 조사(본사·공장 동시)인 경우

- 조사관의 권한 범위를 초과한 요구가 있는 경우

6. 인접 절차 연결

선행: 009 · 후속: 011 자료제출 범위와 시점 결정

7. 근거 조문·판례

8. 다음 단계

→ 011 자료제출 범위와 시점 결정
