접수된 분쟁 신호를 등급으로 나눠 대응 라인을 정할 때

적용 상황: 내용증명·민원·결제 지연·규제 조사 같은 신호가 여러 부서에서 흩어져 접수되고 있어, 어디까지 법무가 개입할지 기준이 필요한 상황입니다.

Must Know · 알아야 할 것

  • 분쟁은 소장으로 시작하지 않습니다. 내용증명, 민원, 결제 지연, 납기 지연, 규제 연락 같은 신호가 먼저 옵니다.
  • 신호를 담당자 기억에 맡기면 등급 판단이 늦어집니다. 한 곳에 모아 기록해야 같은 사안을 다르게 판단하는 일이 줄어듭니다.
  • 등급은 "중요도"가 아니라 "누가 언제 개입하는가"를 정하는 장치입니다. 등급마다 대응 주체와 보고 시점을 붙여 둡니다.
  • 등급은 고정되지 않습니다. 새 사실이 나오면 올리고, 해소되면 이유를 남기고 내립니다.

Must Check · 확인할 것

  • 신호가 들어오는 경로(내용증명·민원·거래처 항의·규제 연락·언론)의 목록화
  • 접수 창구와 1차 기록 담당자 지정 여부
  • 등급 기준과 등급별 대응 주체·보고 시점 문서화
  • 분쟁 대장의 기록 항목(개요·상대방·금액 규모·기한·담당)
  • 등급 상향·하향 시 사유를 남기는 절차
  • 기존 유사 사안을 대장에서 조회할 수 있는지
  • 접수자가 임의로 종결하지 않도록 하는 확인 절차

Must Do · 실행할 것

  1. 현재 진행 중인 분쟁·항의·조사 건을 한 장의 대장으로 모읍니다(접수일·경로·상대방·요약·금액·기한·담당·상태).
  2. 신호 유형별 최소 등급을 정합니다. 예: 단순 문의는 관찰, 내용증명·민원은 경고, 소송 예고·가압류·규제 조사는 심각, 소장·고소·언론 보도는 위기.
  3. 등급별 대응 라인을 붙입니다(담당자 단독 → 법무 개입 → 태스크포스 → 전사 보고).
  4. 접수 즉시 72시간 안에 할 일을 정합니다. 사실관계 확인, 자료 보존 요청, 대외 응답 창구 지정이 여기에 들어갑니다.
  5. 자료 보존 요청을 문서로 발송하고, 관련 부서에 삭제·정리 금지를 통지합니다.
  6. 월 1회 대장을 갱신하고 등급 변동 사유와 다음 조치를 기록합니다.
잠깐 멈추고 검토할 때

같은 상대방과 여러 건이 동시에 진행되는 경우 · 소송 예고·가압류·규제 조사처럼 기한이 걸린 신호가 온 경우 · 임직원 개인이 당사자로 얽힌 사안인 경우 · 언론·외부 공개 가능성이 있어 대외 메시지를 정해야 하는 경우
