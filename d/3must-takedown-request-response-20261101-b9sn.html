게시물 삭제·중단 요청을 받았을 때

적용 상황: 운영하는 채널의 게시물(이미지·영상·글·상품 상세)에 대해 권리자나 대리인이 삭제·중단을 요구하는 메일, 내용증명, 플랫폼 신고를 받은 경우입니다.

Must Know · 알아야 할 것

  • 먼저 "누가, 무엇을, 어떤 근거로" 요구하는지 확인합니다. 요청자의 권리자 지위, 지목된 게시물의 특정 여부, 침해한다고 주장하는 부분이 특정되지 않으면 답변을 만들 수 없습니다.
  • 요청은 원문 그대로 보관합니다. 전화·구두 요청은 서면으로 다시 받고, 그 요청 자체도 기록합니다.
  • 판단은 세 갈래입니다. ① 침해가 명백해 보이면 사용 중단·삭제 검토 ② 권리관계가 불분명하면 사실 확인 요청과 임시 조치 검토 ③ 우리에게 사용 권한이 있으면 근거 제시.
  • 삭제 여부와 별개로 제작 경위 기록이 필요합니다. 누가 어떤 목적으로 어디서 가져왔는지 남아 있지 않으면 내부 판단도 서지 않습니다.
  • 플랫폼을 통해 게시했다면 플랫폼 자체의 통지·이의제기·재게시 절차가 따로 돕니다. 알림을 개인 메일함에 흩어 두지 말고 한 곳에 모읍니다.
  • 라이선스 표기를 조건으로 쓰는 자료는 사용 당시 조건 준수 여부와 그 기록이 먼저입니다.
  • 요구가 과장돼도 회신 기한을 무시하면 안 됩니다. 기한을 넘기면 플랫폼이 먼저 조치하고, 그 조치가 우리 입장을 좁힙니다.

Must Check · 확인할 것

  • 요청 원문(메일·내용증명·플랫폼 신고서) 사본과 접수 시각
  • 요청자 신원과 권리자 지위를 보여주는 자료
  • 지목된 게시물의 URL·파일명·게시일·게시자
  • 제작 경위(직접 제작·외주·구매·인용·재가공)와 관련 계약·발주 자료
  • 라이선스·이용 허락 문서, 출처 표시와 이용 조건 준수 기록
  • 플랫폼 정책상 통지·이의제기·재게시 절차와 회신 기한
  • 같은 콘텐츠가 다른 채널·다른 계정에도 게시돼 있는지
  • 내부 결정권자와 외부 검토가 필요한지

Must Do · 실행할 것

  1. 요청 원문과 접수 시각을 저장하고 담당자·회신 기한을 한 줄로 적어 공유합니다.
  2. 지목된 게시물을 특정해 화면 캡처와 원본 파일을 함께 목록으로 만듭니다.
  3. 제작 경위와 권리 자료를 관련 부서에서 회수합니다(내부 기준 48시간).
  4. 세 갈래 분기 중 어디로 갈지 정하고 결정자·결정 시각을 기록합니다. 애매하면 임시 조치 후 확인 요청을 택합니다.
  5. 플랫폼 절차가 걸려 있으면 플랫폼 알림함과 회신 기한을 별도로 추적합니다.
  6. 회신문에는 확인한 사실, 요청에 대한 답, 기한만 담습니다. 책임 인정이나 법률 판단은 담지 않고 필요하면 전문가 검토를 거칩니다.
  7. 삭제·중단 조치 후에도 원본과 요청 기록은 지우지 않고 보관합니다.
  8. 같은 기준으로 다른 채널의 유사 콘텐츠도 점검해 결과를 같은 기록에 붙입니다.
잠깐 멈추고 검토할 때

권리자가 둘 이상이거나 서로 다른 주장을 하는 경우 · 형사 고소·신고 언급이 함께 온 경우 · 언론 보도나 온라인 확산이 이미 시작된 경우 · 플랫폼이 계정 정지·노출 중단을 먼저 집행한 경우 · 금액 청구가 함께 온 경우 · 인용·패러디·2차 창작 범위라 판단이 갈리는 경우 · 요청 대상에 고객·임직원 개인정보가 포함된 경우

미확인·제한: 조문 번호, 통지 후 반박·재게시의 법정 기한과 보관 기간, 면책 요건의 법적 판단은 이 카드에서 확정하지 않습니다. 플랫폼별 기한은 해당 플랫폼 정책을 직접 확인해야 합니다.

변경 기록: 원자료의 면책 요건표와 조문 인용은 제외하고 접수·확인·분기·회신·보관 절차로 재구성했습니다.
