법무 데이터 수집 및 KPI 관리 — 주간·분기 리포트의 기초 데이터 수집 체계

적용 상황: 주간·분기 법무 리포트의 기초가 되는 법무 데이터 수집 항목과 KPI를 정의하고 관리하는 경우

5데이터 영역
5KPI 산출식
5수집 주기
1즉시 보고(R등급)

Must Know · 알아야 할 것

5개 데이터 영역(계약검토·소송분쟁·리스크·자문·비용), KPI 5종 산출식(처리량·평균응답시간·리스크해소율·비용효율·예산준수율), 주기별 체크(매일·매주·매월·매분기·수시), R등급 즉시 경영진 보고.

Must Check · 확인할 것

  • 5개 영역 수집 항목이 주기(주간/월간/분기/즉시)에 맞게 수집되는지 확인
  • 각 KPI 산출식의 분자·분모 데이터가 실제로 수집 가능한지 확인
  • 계약 검토: 신규·완료 건수, 평균 소요 시간, 리젝트율, 템플릿 비율 수집 여부
  • 소송·분쟁: 진행·신규·종결 건수, 비용, 충당금 설정 건수 수집 여부
  • 리스크: 신규 등록·해소·등급 변동·미해결·고위험 R 건수 수집 여부
  • 법무 자문: 요청 건수·응답 시간·만족도 수집 여부
  • 법무 비용: 로펌·인건비·교육비 수집 여부
  • 주기별 체크리스트 담당자·완료 상태 관리 여부

Must Do · 실행할 것

  1. 데이터 수집 체계 구축: 5개 영역별 항목·주기·수집 방법·비고 시트 정의, 출처 확정
  2. KPI 산출식 적용: 5종 KPI 산출식에 맞춰 분자·분모 정기 집계
  3. 주기별 체크리스트 운영: 매일·매주·매월·매분기·수시 작업 담당자·완료 상태 관리
  4. R등급 리스크 즉시 보고: 고위험 R 등급 발생 시 경영진 즉시 보고 프로세스 가동
  5. 리포트 연계: 주간 DOC-001·분기 DOC-004에 KPI·트렌드 반영, 추세 분석 기록
잠깐 멈추고 검토할 때데이터가 실제로 수집되나요? 5개 영역 항목이 주기에 맞게 수집·출처 확정됐는지 확인, KPI를 산출할 수 있나요? 각 산출식 분자·분모가 실제로 확보되는지 확인(미확보 시 지표 공백), 주기별 작업이 이행되나요? 매일·매주·매월·매분기 체크리스트 담당자·완료 상태 관리 확인, R등급 리스크가 즉시 보고되나요? 고위험 R 등급 발생 시 경영진 즉시 보고 프로세스 작동 확인, 리포트와 연결되나요? 주간·분기 리포트에 KPI·트렌드 반영·추세 분석 기록 확인
