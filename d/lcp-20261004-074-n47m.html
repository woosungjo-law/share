사업자등록 업종코드 오판 리스크 — KSIC(한국표준산업분류) 코드 오선택 시 세무·인허가·보험·과태료 4중 리스크

결론부터. 업종코드는 단순한 통계 분류가 아니라 부가세 과세 유형·세율, 인허가, 4대보험에 직접 연결된다. 코드 선택을 행정이 아니라 비용으로 보라 — 정확히 고르는 것이 가장 싼 예방이다.

1비유로 먼저 이해하기

신설 법인의 사업자등록을 서두르던 대표가 비슷해 보이는 업종코드 앞에서 멈췄다. 업종코드는 호수 주소처럼 한 번 찍으면 뒤의 모든 것이 정해지는 좌표다. 같은 번호로 두고 다른 일을 하면, 세금(일반·간이 과세 구분과 세율)·인허가(업종별 허가 요건)·보험(4대보험 적용)이 한꺼번에 어긋난다. 빨리 내고 싶은 마음이 나중에 4중으로 돌아온다.

2법이 실제로 보는 지점

기준이 두 개다.

첫째, 연결 구조다. 업종코드는 부가세 과세 유형인 일반과 간이의 구분과 세율, 소득공제, 업종별 인허가, 4대보험 적용 등에 직접 연결된다. 부가가치세법 제61조가 간이과세 적용 범위와 연결되는 근거다. 코드를 잘못 고르면 내는 세금부터 달라질 수 있다는 뜻이다.

둘째, 등록이다. 부가가치세법 제8조는 사업자등록을 정한다. 등록할 때 적는 업종이 출발점이다.

경영 관점에서는 코드 선택을 행정이 아니라 비용으로 보는 것이 출발점이다. 실제 사업과 코드의 적합성을 먼저 보고 코드별 효과를 따진다. 적합성이 무너지면 뒤에서 4중으로 돌아온다. 코드를 가리는 시간이 가장 싸다.

3중요한 조건과 예외

  • 첫째, 사업 실체 — 실제 사업이 무엇인지를 본다. 실체가 불분명하면 코드도 흔들린다. 실체부터 문서로 묶는다.
  • 둘째, 코드 — 실제 사업에 맞는 코드를 고른다. 비슷해 보이는 코드의 차이를 표로 둔다.
  • 셋째, 과세 효과 — 부가가치세법 제61조 연결의 일반·간이 구분과 세율·공제 차이를 본다. 구분이 바뀌면 내는 세금이 바뀐다.
  • 넷째, 인허가 — 업종별 인허가 요건이 코드에 따라 달라지는지를 본다. 인허가가 비면 영업을 멈춘다.
  • 다섯째, 보험 — 4대보험 적용이 코드에 따라 달라지는지를 본다. 보험료 차이가 쌓인다.
  • 여섯째, 등록·정정 — 부가가치세법 제8조의 업종 기재를 확인하고, 어긋나면 빨리 정정 절차를 밟는다. 미루면 4중 리스크가 커진다.
핵심. 실체 → 코드 → 과세(제61조) → 인허가 → 보험 → 등록(제8조)의 순서로 점검한다. 코드 하나가 세금·인허가·보험·과태료 네 갈래로 퍼진다.

4그래서, 대표가 정할 것

코드를 아는 회사가 4중 리스크를 막는다. 대조표에는 코드별 과세·인허가·보험 칸을 둔다 — 칸이 비면 채운 표가 방어가 된다.

  1. ① 실체 정리 — 실제 사업 내용을 묶은 문서가 대조의 기준이 된다.
  2. ② 코드 대조 — 후보 코드별 효과를 표로 둔다. 표가 있으면 차이가 보인다.
  3. ③ 과세 확인 — 일반·간이 구분과 세율·공제 차이를 본다.
  4. ④ 인허가·보험 — 코드별 요건과 적용 차이를 본다.
  5. ⑤ 등록 점검 — 부가가치세법 제8조의 업종 기재를 확인하고, 어긋나면 정정 절차를 밟는다.
