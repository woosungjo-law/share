투자자 실사 요청이 왔을 때

적용 상황: 투자 검토를 위해 자료를 달라는 요청이 왔는데, NDA는 체결했지만 어떤 자료를 어느 단계에서 누구에게 열어줄지 정해야 할 때.

Must Know · 알아야 할 것

NDA 체결과 공개 범위는 별개 결정입니다. NDA가 있다고 모든 자료를 열어도 된다는 뜻이 아닙니다. 투자자 유형에 따라 노출 위험이 다릅니다 — 재무적 투자자는 포트폴리오를 통해 정보가 흐를 수 있고, 전략적 투자자는 경쟁사이거나 경쟁사에 투자한 이력이 있을 수 있습니다. 실사는 요약 → 상세 → 데이터룸 단계로 나눠 제공하고, 복수 투자자 동시 협상에서는 제공 내역을 투자자별로 구분합니다.

투자자 유형기본 노출 정책
재무적 투자자(VC·PE)요약·재무 중심. 핵심 기술 상세는 후반 단계
전략적 투자자기술·고객 상세 보류, 이해 충돌·경쟁 관계 먼저 확인
개인 투자자자료 최소화, 대면 설명 위주

Must Check · 확인할 것

  • NDA 체결 여부와 체결 주체(투자자 본인인지 특수목적법인인지)
  • 사용 목적 조항이 ‘투자 검토’로 구체화되고 실사 범위가 한정됐는지
  • 투자자의 경쟁사 관계·경쟁사 투자 이력
  • 요청 자료가 영업비밀·개인정보·핵심 기술·미공개 재무에 걸치는지
  • 개인정보 포함 자료의 제공 근거와 최소화 방안
  • 자료별 공개 단계(요약→상세→데이터룸) 구분
  • 접근 권한 부여 대상·회수 시점·열람 로그 기록 방법
  • 협상 결렬 시 자료 반환·폐기 절차와 확인 방법
  • 외부 전문가 대리 열람 시 범위와 비밀유지 승계

Must Do · 실행할 것

  1. 요청 자료 목록을 받아 항목별 공개 등급을 매깁니다(즉시 제공 / 요약 제공 / 데이터룸 / 제공 보류).
  2. 투자자 유형을 확인하고 등급별 기본 정책을 정합니다.
  3. NDA 문언과 공개 등급이 어긋나는 항목을 표시합니다(목적 제한 없음, 범위 무제한, 반환 조항 없음).
  4. 데이터룸을 준비하고 계정별 권한과 열람 로그 기록 방식을 정합니다.
  5. 개인정보·영업비밀 자료는 마스킹·집계·요약본 대체 가능성을 먼저 검토합니다.
  6. 제공 내역을 투자자별·일자별로 기록합니다(자료명·버전·방식·담당자).
  7. 공개 범위와 보류 항목을 경영진에 보고해 승인받습니다.
  8. 협상 종료·중단 시 회수·폐기 확인 절차를 문서로 남깁니다.
잠깐 멈추고 검토할 때투자자가 NDA 체결을 거부하거나 특수목적법인 명의로만 체결하려 하면 정보를 먼저 주지 않습니다. 고객 개인정보나 제3자 비밀유지 대상 정보가 포함되면 제3자 동의·계약상 제한을 먼저 확인합니다. 전략적 투자자가 소스·공정 자료를 요구하면 실사 목적과 무관한 범위로 보이므로 보류하고 근거를 요구합니다. 공개 범위가 회사 가치나 경쟁 지위를 흔들 수준이면 대표·경영진 판단으로 올립니다.
