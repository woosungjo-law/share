AI 데이터셋을 외부 판매·제공하기 전에 출처와 이용 조건을 정리할 때

적용 상황: AI 학습·분석에 쓰인 데이터셋을 외부 고객에게 판매하거나 제공하려는데, 데이터의 출처·가공 이력과 고객이 계획하는 이용 범위를 한 번에 설명하기 어려운 상황에서 사용합니다. 범위: 거래 검토용 자료를 목록화하고 확인되지 않은 항목을 법무 검토로 전달하는 절차입니다. 데이터의 판매 가능성, 개인정보·저작권·데이터베이스권의 적용, 계약상 보증·면책의 효력은 판단하지 않습니다.

Must Know · 알아야 할 것

  • 파일 자체만 넘기기 전에 어떤 데이터 묶음과 버전인지, 어디서 왔고 어떤 처리를 거쳤는지 설명할 수 있어야 검토 질문을 구체화할 수 있습니다.
  • 출처·계약·처리 자료가 없거나 서로 맞지 않는 항목은 적법 또는 사용 가능으로 추정하지 말고 확인 필요로 남깁니다.
  • 판매 제안서의 설명과 실제 고객 이용계획이 다를 수 있습니다. 예정된 목적, 이용자, 재제공 여부와 보관·갱신 조건을 별도 항목으로 기록합니다.
  • 이 카드는 거래 준비와 내부 검토 라우팅 도구입니다. 데이터 권리의 귀속이나 외부 제공의 적법성을 대신 판단하지 않습니다.

Must Check · 확인할 것

  • 거래 대상 데이터셋의 이름, 버전, 기준일, 파일·필드 범위와 책임자를 특정했는가?
  • 원천별 제공자·수집 경로·시점·방법과 관련 계약·이용조건 문서를 연결했는가?
  • 데이터의 정제·결합·라벨링·가공 단계와 사용한 원본 버전을 추적할 수 있는가?
  • 개인정보·저작물·제3자 제공자료가 포함될 가능성과 확인 담당자를 표시했는가?
  • 고객의 예정 목적, 사용 주체, 결과물 공개·재제공 여부, 보관·갱신 범위를 확인했는가?
  • 제안서와 계약 초안의 데이터 설명, 이용범위, 재제공, 갱신·삭제 요청 관련 문구를 같은 버전으로 대조했는가?
  • 자료 누락·출처 불일치·고객 이용계획 미확정 항목을 담당자와 확인 예정일이 있는 미결 목록으로 관리하는가?
  • 법무 검토 질문과 회신, 검토 대상 데이터 버전, 내부 승인자를 기록했는가?

Must Do · 실행할 것

  1. 데이터셋 식별자와 버전을 정하고, 검토 기준일·파일 목록·필드 범위·내부 책임자를 기록합니다.
  2. 데이터 항목별로 출처, 제공·수집 시점, 수집·가공 경로, 관련 계약·조건 문서의 위치를 한 표에 연결합니다. 확인되지 않은 값은 추정하지 않습니다.
  3. 원본에서 외부 제공본까지의 정제·결합·라벨링 이력을 기록하고, 각 변환본이 어느 원본 버전에서 만들어졌는지 대조합니다.
  4. 고객에게 제안한 목적과 실제 예정 사용, 접근 주체, 재제공 여부, 보관·갱신 계획을 확인해 데이터셋 버전과 함께 묶습니다.
  5. 출처·조건 문서의 누락, 개인정보·저작물·제3자 자료 관련 의문, 제안된 보증·면책 문구를 법무 검토 질문으로 분리합니다. 해당 항목의 효력이나 적법성은 자체 결론으로 표시하지 않습니다.
  6. 미결 항목이 있으면 담당자·회신 예정일·거래 단계·승인자를 적고, 내부 검토가 끝날 때까지 해당 버전을 검토 대기로 관리합니다.
  7. 검토 후 승인한 데이터셋 버전, 고객 이용 범위, 검토 회신과 최종 제공 파일을 연결해 보관합니다. 데이터나 이용계획이 달라지면 변경된 부분을 다시 검토 대상으로 올립니다.
잠깐 멈추고 검토할 때

출처나 제공 경로를 확인할 기록이 없거나, 공급자 설명과 데이터 파일의 내용이 맞지 않는 경우 · 원천 계약·이용조건 문서가 없거나 외부 제공·재제공 범위를 이해하기 어려운 경우 · 개인정보·저작물·제3자 자료의 포함 여부가 확인되지 않은 상태에서 제공 일정을 확정하려는 경우 · 고객의 실제 이용 목적·사용자·재제공 계획이 제안 내용과 다르거나 정해지지 않은 경우 · 데이터셋 버전이 바뀌었는데 이전 검토 기록으로 그대로 승인하려는 경우

원자료: 회사법 26 혼합 필수 EP-003의 §2 데이터 판매 및 §3 실무 액션

검토일: 2026-10-23

미확인·제한: 원문에 기재된 개인정보·저작권·데이터베이스권의 법적 결론, 관련 조문·판례번호, 판매 계약의 보증·면책 문구 효력은 검증하지 않았고 카드에 옮기지 않았습니다. 거래자료 정리와 법무 검토 질문 구성만 다룹니다.

변경 기록: 기존 AI 학습 개인정보 점검 카드의 처리 근거 판단과 구별해, 외부 판매·제공 전 데이터 묶음·출처·변환 이력·고객 이용계획을 정리하는 운영 절차로 한정했습니다.
