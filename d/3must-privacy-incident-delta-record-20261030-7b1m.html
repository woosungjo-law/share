3MUST · 기업법무

개인정보 사고 후속 조사에서 새 사실이 나왔을 때 변경 내역을 관리할 때

적용 상황: 사고 초기 기록을 만든 뒤 포렌식·내부 확인 과정에서 영향 대상, 정보 항목, 발생 시점 등에 관한 새로운 사실이 발견됐을 때. 범위: 확인된 사실과 이전 기록 사이의 차이를 추적하고 내부 담당자에게 넘기는 절차입니다. 누구에게 무엇을 언제 통지·신고해야 하는지, 법적 의무·기한·제재는 판단하지 않습니다.

Must Know · 알아야 할 것

  • 초기 기록을 덮어쓰지 않습니다. 당시 알고 있던 내용이 무엇이었는지 남아 있어야 이후 발견과 비교할 수 있습니다.
  • 새 정보는 발견 시각, 확인 경로, 확인 책임자와 함께 기록합니다. 추정 단계와 확인 완료를 구분합니다.
  • “더 발견됨”과 “전체 범위가 확정됨”은 다른 상태입니다. 아직 조사가 진행 중이면 미확인으로 표시합니다.
  • 개인정보를 담은 원자료는 접근을 제한하고, 변경표에는 가능한 한 집계값과 자료 ID만 사용합니다.
  • 새 사실의 대외 안내나 규제기관 보고 필요성은 지정된 개인정보·법무 담당자가 별도로 판단하도록 인계합니다.

Must Check · 확인할 것

  • 최초 기록 버전과 작성 시각
  • 새 사실을 발견한 시각과 발견 경로
  • 영향 대상 범위의 변경 전·후 값 또는 집계
  • 확인된 정보 항목의 변경 전·후 목록
  • 관련 시스템·계정·기간의 변경 여부
  • 사실을 뒷받침하는 로그·조사 결과·파일의 ID와 보관 위치
  • 확인 완료, 추가 확인 중, 판단 불가 중 현재 상태
  • 변경사항을 검토할 책임자와 다음 확인 시점
  • 이미 만들어진 내부 보고·안내 자료 중 갱신이 필요한 것

Must Do · 실행할 것

버전발견·기록 시각항목이전 기록새로 확인된 내용근거 ID·위치확인 상태담당자
v1YYYY-MM-DD HH:MM영향 범위초기 확인값—조사기록 ID초기 기록담당 A
v2YYYY-MM-DD HH:MM정보 항목확인된 항목 목록추가 확인된 항목 또는 변동 없음로그·보고서 ID추가 확인 중담당 B
잠깐 멈추고 검토할 때

조사 결과가 서로 다른 범위나 수치를 제시할 때 · 중복 레코드 또는 식별 기준 때문에 대상 규모를 계산할 수 없을 때 · 새로운 정보 유형의 민감도나 노출 여부를 분명히 말할 수 없을 때 · 개인별 원자료를 넓은 내부 채널이나 공개 문서에 복사해야만 설명할 수 있을 때 · 외부 안내·신고 의무, 법정 기한 또는 제재 여부를 판단해야 할 때

원자료: 1차 신고 후 추가 유출, 2차 통지 안 하면 과태료의 최초 안내 후 후속 조사에서 영향 범위·정보 항목이 추가 확인되는 사례.

범위 조정: 법적 추가 통지·신고 의무, 시점·방법, 과태료, 손해배상, 관련 조문·판례 주장은 모두 제외했습니다.

사용 전 확인: 실제 사고기록에는 조직의 개인정보·보안 정책에 따른 접근권한과 자료 보존 기준을 적용합니다.

일반적인 실무 참고자료입니다. 개별 사안에서는 사실관계와 적용 기준을 확인하세요.
