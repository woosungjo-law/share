인테리어 공사가 중단되거나 하자로 다툼이 생겼을 때

적용 상황: 인테리어 공사가 중간에 멈췄거나, 준공 뒤 하자 문제로 정산·해제 다툼이 생겨 현장과 자료를 정리해야 할 때 사용합니다.

Must Know · 알아야 할 것

  • 정리할 자료는 '공사가 어디까지 진행됐는지'에 따라 달라집니다. 최후 공정이 끝나지 않은 상태와, 끝났지만 불완전한 상태는 확인할 증거가 다릅니다.
  • 어느 쪽인지는 법적 평가가 필요한 문제입니다. 현장에서는 단정하지 말고 상태를 그대로 기록해 두는 것이 먼저입니다. 기록이 없으면 이후 어떤 판단도 어렵습니다.
  • 수급인이 공사 중단 의사를 밝혔다면 그 통보 자체가 핵심 증거입니다. 문자·공문·현장 철수 사실을 시간순으로 남깁니다.
  • 하자보수비는 전면 철거·재시공 견적만 모으면 실제 인정 범위와 차이가 날 수 있습니다. 부분 보수·대체 시공 견적을 함께 받아 비교해야 합니다.

Must Check · 확인할 것

  • 최후 공정 종료 여부와 주요 구조 부분 시공 상태
  • 공사 중단·이행거절 통보 기록(문자·공문·회의록)
  • 공사일지·공정별 진행률·기성고 산정 자료
  • 하자 목록(위치·증상·사진·발생 시점)
  • 보수 견적 비교표(전면 철거 / 부분 보수 / 대체 시공)
  • 지체상금 약정 조항과 기산일·종기 관련 자료
  • 발주자 측 사유(설계변경·추가공사·기성금 지급 지연) 기록

Must Do · 실행할 것

  1. 현장 상태를 사진·영상·일자별 기록으로 남기고, 최후 공정 진행 여부를 표시합니다.
  2. 중단·이행거절 통보를 시간순으로 정리해 하나의 증거 묶음으로 만듭니다.
  3. 기성고 산정에 필요한 자료(공정별 진행률·자재·인건비·검수 기록)를 모읍니다.
  4. 하자 목록과 보수 견적 3종을 비교표로 만들어, 항목별 비용 차이를 드러냅니다.
  5. 지체상금 정산표를 만들고, 발주자 사유로 지연된 기간을 별도로 표시합니다.
  6. 위 자료를 법무 검토로 넘겨 공사 상태의 유형 판단과 해제·정산 방향을 정합니다.
잠깐 멈추고 검토할 때

현장 철수·추가 공사 착수처럼 상태를 바꾸는 조치를 하기 전 · 해제·해지 통지를 보내기 전 · 지체상금·손해배상 청구액을 확정할 때 · 발주자와 수급인 사이에 공사 범위 자체가 다투어질 때
