Must Know · 알아야 할 것

  • “국내 서비스”라는 설명만으로 데이터가 국내에 남는다고 볼 수 없다. 저장 리전, API 호출, 지원 인력 접근, 하위 처리자까지 실제 흐름을 확인한다.
  • 국외이전의 적법한 방식과 고지 문구는 서비스·국가·계약에 따라 달라지므로, 카드에서는 결론 대신 확인해야 할 항목을 고정한다.

Must Check · 확인할 것

  • 프롬프트·첨부파일·로그·학습데이터별 저장 국가와 처리 국가를 확인한다.
  • API 호출 경로, 관리자·지원 인력의 원격 접근 국가, 하위 처리자 목록을 확인한다.
  • 처리방침과 계약서에 수신자·목적·항목·국가·보유기간이 구체적으로 적혀 있는지 대조한다.
  • 리전 변경·재수탁자 변경 시 통지·재평가 절차가 있는지 확인한다.
  • 서비스 대상 국가별로 별도 규제 검토가 필요한지 법무에 의뢰한다.

Must Do · 실행할 것

  1. 인프라팀과 데이터 흐름도를 만들고 각 화살표에 국가·수신자·보유기간을 붙인다.
  2. 공급자 보안문서·DPA·SCC 등 계약자료와 실제 콘솔 설정을 대조한다.
  3. 확인 전까지 식별정보가 포함된 입력을 제한하고 테스트 데이터로 검증한다.
  4. 처리방침·동의·위탁 문서의 수정 담당자와 재검토 일자를 정한다.
