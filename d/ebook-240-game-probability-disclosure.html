1. 문제상황 — "확률형 아이템 확률을 공개하지 않으면 법적 문제가 될까?"

네, 법적 문제가 됩니다. 게임산업진흥에 관한 법률(이하 게임산업법) 제33조 제2항은 확률형 아이템의 종류와 종류별 공급 확률정보를 게임물·인터넷 홈페이지·광고선전물마다 표시하도록 의무화하고 있습니다.

미표시·허위 표시 시: - 행정제재: 시정명령 → 미이행 시 2년 이하 징역 또는 2천만 원 이하 벌금(게임산업법 제45조 제11호) - 민사책임: 입증책임이 게임사에 전환(제33조의2 제1항 단서) — 고의·과실 없음을 게임사가 입증해야 면책 - 징벌적 손해배상: 고의 위반 시 손해액의 3배 이내 배상 가능(제33조의2 제3항) - 표시광고법 위반: 공정위 시정명령·과징금 - 전자상거래법 위반: 기만적 방법 금지 위반

2. 핵심 쟁점

2.1 확률 표시 의무 — 법정 의무 vs 자기규제

구분 자기규제 (2015~2024) 법정 의무 (2024.3.22. 이후)
근거 민간 자율규제안 게임산업법 제33조 + 시행령 제19조의2
적용 대상 자율 참여사 모든 게임물사업자 (매출 1억 원 이하 영세기업 제외)
위반 효과 모니터링 공표 형사처벌(2년/2천만 원) + 징벌적 손해배상(3배)
감독 GSOK 문체부 + 게임위 + 게임피해구제센터

2.2 허위·과장 표시의 위법성 기준

표시광고법 위반 여부는 일반 소비자의 전체적·궁극적 인상을 기준으로 판단합니다(대법원 2017두59215).

핵심 기준: - "확률 UP", "대폭 상승" 등의 표현이 실제 확률 구조와 정합하는가 - 중요한 제한·예외 조건이 시각적으로 동등한 중요도로 전달되는가 - "랜덤"만 표시하고 실제 확률 구조(특정 항목의 인위적 저확률 설정)를 공개하지 않았는가

→ "랜덤"이라는 표현만으로 면책되지 않습니다. (서울고법 2018누53070)

2.3 확률 조작·차단의 법적 평가

유형 법적 평가 근거
일부 항목 확률 인위적 조정 + 미고지 전자상거래법상 거짓 고지/기만적 방법 서울고법 2018누53070
고가치 옵션조합 의도적 차단 + 장기간 은폐 적극적 기망행위 (사기취소 가능) 수원지법 2021나71106
확률 공개하지 않았으나 가능/불가능 조합 임의 설정 중대한 정보 미제공 수원지법 2021나71106

3. 체크리스트 — 확률형 아이템 표시의무 이행

3.1 표시 내용 체크리스트

  • [ ] 확률형 아이템 유형별(캡슐형/강화형/합성형) 구분 표시
  • [ ] 모든 게임아이템의 종류·등급·성능별 공급 확률정보 (별표3의2 가~다목)
  • [ ] 백분율 표시 (소수점 반올림 기준 준수)
  • [ ] 한정 제공 시: 제공 총수 또는 기간 (별표3의2 라목)
  • [ ] 확률 변동 구조: 구매·사용·합성 진행에 따른 변경 내용 (마목)
  • [ ] 천장제도(확정 획득 조건) 존재 시 해당 조건 (바목)

3.2 표시 위치·매체 체크리스트

  • [ ] 게임물 내: 구매·조회·사용 화면에 직접 표시 (불가피 시 홈페이지 연결)
  • [ ] 인터넷 홈페이지: 문자열/숫자열 검색 가능 형태로 표시
  • [ ] 광고·선전물: 확률형 아이템 포함 사실 표시 (배너·크기 예외 있음)

3.3 변경 시 재고지 체크리스트

  • [ ] 확률 정보 변경 시 변경 내용 + 변경 시점을 사전 게시
  • [ ] 긴급 오류 수정 시: 사유 해소 후 지체 없이 게시
  • [ ] 변경 전후 비교 가능하도록 이력 관리
  • [ ] 게임물 내 + 홈페이지 동시 게시

3.4 내부 통제 체크리스트

  • [ ] 확률 설계·운영 내역 문서화 (개발팀 산출물, 확률 테이블, 버전별 변경 이력)
  • [ ] 확률 공지 이력 문서화 (공지 시점·매체·문안·게시 기간)
  • [ ] 표시내용 진위 여부 검토·보고 체계 수립
  • [ ] 정기적 내부 감사 절차
  • [ ] 실무자 교육·체크리스트 배포
  • [ ] 확률 오류·이상 징후 시 즉시 서비스 중단 또는 공지 프로토콜

3.5 사후 대응 체크리스트

  • [ ] 고의·과실 없음 입증 자료 사전 준비
  • [ ] 표시의무 위반 관련 문서 보관 정책 (일정 기간 이상)
  • [ ] 사후 보상조치의 적정성·시의성 확보
  • [ ] 약관상 보상 기준 사전 명시
  • [ ] 집단 분쟁 대비 인과관계·가분성별 손해 산정 시나리오

4. 위험 신호 (Red Flags)

🚩 확률 미공개

  • 확률형 아이템임에도 게임물 내 확률 표시 없음
  • 홈페이지에 확률 정보 미게시 또는 검색 불가능 형태
  • "랜덤", "확률은 영업비밀" 등 추상적 표현만 사용

🚩 허위·과장 표시

  • 실제 확률과 다른 숫자 표시
  • "확률 UP" 표시했으나 실제 상승폭 미미 또는 조건부
  • 특정 항목만 현저히 낮은 확률로 설정 + 미고지

🚩 사행성 논란

  • 컴플리트 가챠(완성형) 구조 + 확률 정보 미공개
  • 과도한 구매유도 행위 (타임어택, 한정판매, 심리적 압박)
  • 게임 내 재화의 현금 전환 경로 존재

🚩 청약철회 제한

  • 확률형 아이템이라는 이유만으로 청약철회 전면 차단
  • 청약철회 제한 사유·범위를 약관에 명시하지 않음
  • 전자상거래법 제21조 (금지행위) 위반 가능성

🚩 제재 이력 리스크

  • 3년 내 반복 위반 시 영업정지 가능 (시행령 제34조)
  • 동종 업계 제재 사례 발생 시 업계 전반 조사 가능성
  • 집단소송(기획소송) 리스크

조문 내용 실무 의미

제33조의2 제3항 고의 위반 시 징벌적 손해배상 (손해액 3배 이내) 최대 3배 배상 위험
제33조의2 제5항 게임피해구제센터 운영 근거 이용자 신고 채널 전문화
제45조 제11호 시정명령 미이행 시 2년 이하 징역/2천만 원 벌금 형사처벌 가능

사건 요지 실무 영향

6. FAQ

Q1. 확률 정보를 게임물 내에만 표시하고 홈페이지에는 표시하지 않아도 되나요? 아닙니다. 게임산업법 제33조 제2항은 게임물, 인터넷 홈페이지, 광고·선전물 각각에 표시하도록 요구합니다. 3개 경로 모두 표시해야 합니다.

Q2. 중소기업도 표시의무가 있나요? 최근 3년간 연평균 매출액이 1억 원 이하인 영세기업은 표시의무가 면제됩니다(시행령 제19조의2 제2항 제3호). 다만 면제 요건을 충족하지 못하는 중소기업은 의무 적용 대상입니다.

Q3. 확률 정보 변경 시 어떻게 해야 하나요? 변경 내용과 변경 시점을 사전에 게임물과 인터넷 홈페이지에 게시해야 합니다(별표3의2 가목 4). 긴급 오류 수정 등 불가피한 사유가 있으면 사유 해소 후 지체 없이 게시하면 됩니다.

Q4. "랜덤"이라고만 표시해도 되나요? 아닙니다. "랜덤"이라는 추상적 표시만으로는 면책되지 않습니다. 실제 확률 구조(종류별·등급별 공급 확률)를 백분율로 구체적으로 표시해야 합니다(서울고법 2018누53070).

Q5. 확률 정보를 잘못 표시했지만 실수였다면 책임을 면할 수 있나요? 행정제재(과징금·시정명령) 측면에서는 고의·과실이 불요하므로 "실수" 항변만으로 면책이 어렵습니다(대법원 2010du24371). 다만 징벌적 손해배상(3배)은 고의 위반 시에만 적용되며, 과징금 양정에서 실수 여부가 참작될 여지는 있습니다.

Q6. 확률형 아이템의 청약철회를 제한할 수 있나요? 확률형 아이품의 특성상 단순 변심에 의한 청약철회를 제한하는 약관이 일정 조건에서 유효할 수 있습니다. 그러나 청약철회를 전면 차단하거나 그 제한 사유를 약관에 명시하지 않은 경우 전자상거래법 위반이 될 수 있습니다.

Q7. 해외 게임사(글로벌 플랫폼)도 게임산업법을 준수해야 하나요? 국내에 게임물을 유통·제공하는 모든 사업자는 게임산업법의 적용을 받습니다. 다만 국내 대리인이 없는 해외 게임사에 대한 규제 집행에는 현실적 어려움이 있습니다. 게임산업법 제31조의2(국내대리인 지정)가 도입되어 있어 점차 규제 사각지대가 축소될 전망입니다.
