대관업무 위기대응 매뉴얼

3줄 요약

- 대관 위기는 행정조사·압수수색·처분 통지·언론 보도 등 다양한 형태로 발생하며, 사전 준비된 매뉴얼이 대응 성패를 좌우한다.

- 위기 단계별(발생 전·초동·확산·수습·복구) 대응 체계를 구축하고, 구성원 역할·의사결정 권한·커뮤니케이션 프로토콜을 명시한다.

- 매뉴얼은 정기적으로 점검·훈련하고, 실제 위기 경험을 반영해 업데이트한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사후)


사후관리(027) -> [위기대응 매뉴얼] -> (사이클 완료)

1. 이번 단계에서 반드시 할 일

- [ ] 위기 시나리오별 대응 절차 수립(행정조사·압수수색·언론보도·국회·민원)

- [ ] 위기 단계별(발생 전·초동 1시간·24시간·1주·1개월) 액션 플랜 작성

- [ ] 위기대응팀 구성·역할·연락망 구축

- [ ] 커뮤니케이션 프로토콜(기관·언론·임직원·이해관계자) 수립

- [ ] 매뉴얼 정기 점검·훈련 계획 수립

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 매뉴얼을 만들기만 하고 실제 훈련·교육 부재 — 위기 시 무용지물

- 단일 시나리오(행정조사)만 가정 — 다양한 위기 유형 대비 부족

- 매뉴얼 업데이트 주기 미준수 — 변경된 법령·조직 반영 안 됨

- 위기대응팀이 명목상 존재 — 실제 발동·운영 체계 미흡

5. 전문가 상담 신호

위험도: 혼자 가능

- 전사적 위기대응 체계 최초 구축이 필요한 경우

- 과거 위기 대응 실패 경험이 있는 경우

6. 인접 절차 연결

선행: 027 · 후속: (초기 단계로 회귀) → 선행: 인허가·규제 이슈
