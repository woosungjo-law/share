섹션 1

문제상황

한눈에
  • 구독서비스 해지 UX의 다크패턴이 전자상거래법 개정으로 직접 규제 대상에 포함
  • 공정위는 LG유플러스·구글·트렌비에 시정명령·과태료 부과한 선례 존재
  • 해지 버튼 위치·크기·색상·단계 수 평가 기준 부재가 기업의 가장 큰 리스크

구독서비스에서 해지를 어렵게 만드는 UX 설계(다크패턴)가 집중 규제 대상이 되고 있다. 2026년 7월 시행된 전자상거래법 개정은 온라인 인터페이스 설계 자체를 규제 대상에 포함시켜, 해지 버튼의 위치·크기·색상·단계 수까지 평가 대상이 되었다.

핵심 쟁점: 해지 절차를 구매 절차보다 복잡하게 설계한 경우, 해지 버튼을 시각적으로 구분(축소·희색·은닉)한 경우, 팝업으로 해지 의사를 반복적으로 변경 요구한 경우, 해지 경로를 가입 경로와 다른 방법으로만 제한한 경우 각각 법 위반에 해당할 수 있다.

2026년 개정의 의미

전자상거래법 제21조의2는 온라인 인터페이스 운영자의 금지행위를 신설했다. 제21조(금지행위)가 콘텐츠·고지 방식의 규제였다면, 제21조의2는 UI/UX 설계 자체를 규제한다는 점에서 질적으로 다르다. 해지 버튼의 시각적 차별(3호), 절차 복잡화(4호), 팝업 반복 요구(5호)가 각각 독립된 금지행위로 열거되었다.

선행 심결례

공정위는 이미 제21조①1호(기만적 해지 방해)를 적용해 LG유플러스, 구글, 트렌비 등에 시정명령을 부과했다. 아래 공정위 심결례는 해지 UX 관련 규제 집행의 방향성을 보여준다.

섹션 2

해지방해 금지 규제 체계

2.1 전자상거래법 제21조①1호 — 기만적 해지 방해 금지

조문전자상거래법 제21조①1호✓ 현행 확인

거짓 또는 과장된 사실을 알리거나 기만적 방법을 사용하여 소비자를 유인 또는 소비자와 거래하거나 청약철회등 또는 계약의 해지를 방해하는 행위 금지

시행일 2026.7.21. (MST 282793)

적용되는 UX 설계: 해지 가능 여부 사실과 다르게 고지, 법정 청약철회 기한 임의 단축, 해지 시 불이익 과장 협박성 메시지, 무료체험→유료전환 조건 은닉 등.

2.2 전자상거래법 제21조의2① — 온라인 인터페이스 규제

호내용UX 설계 영향
3호선택항목 간 시각적 현저한 차이 금지해지 버튼을 가입 버튼보다 작게·희미하게 표시 금지
4호 가목구매 절차보다 복잡한 해지 절차 금지해지 클릭 수·단계 수를 가입보다 많게 설계 금지

5호팝업 반복 요구로 의사결정 방해 금지해지 시 할인 제안 팝업 반복 금지 (거부 선택권 제공 시 예외)

2.3 약관규제법 제9조 — 해지 제한 약관 무효

조문약관규제법 제9조✓ 현행 확인

법률에 따른 고객의 해제권·해지권을 배제하거나 그 행사를 제한하는 약관 조항은 무효

시행일 2024.8.7. (MST 260021)

적용: "해지는 고객센터 전화 문의만 가능" 등 온라인 해지 자체를 원천 차단하는 약관 조항은 약관규제법 제9조제1호에 따라 무효이다.

섹션 3

UX 설계 기준

3.1 해지 버튼 위치

기준적합위험
접근 경로계정 설정·구독 관리 1depth 이내3depth 이상 경로·FAQ 내 은닉
가입 버튼 대비동등한 시각적 계층가입 버튼 대비 현저히 작은 크기·낮은 명도
검색 가능성"해지" 검색 시 1클릭 내 진입검색 차단·자동완성 비활성화

설계 원칙: 가입 경로의 depth를 N이라 할 때, 해지 경로는 N±1 이내여야 한다.

3.2 해지 단계 수

항목적합위험
최대 단계구매 절차 단계 수 ±1 이하구매 3단계·해지 6단계
필수 확인1회 (본인 확인)3회 이상 재확인
추가 절차없음설문·탈퇴 사유 입력 강제·재가입 유도 페이지

설계 원칙: 해지 절차는 구매 절차와 본질적으로 동등한 노력으로 완료 가능해야 한다. "정말 해지하시겠습니까?" 1회 확인은 허용되나, 이후 할인 제안 페이지를 추가하는 것은 제21조의2①5호 위험.

3.3 해지 수단

방법적합위험
온라인 해지가입과 동일한 웹·앱에서 해지 가능해지는 전화·방문·등기만 가능
해지 버튼 명칭"해지", "구독 취소", "멤버십 해지""서비스 설정 변경"·"계정 옵션" 모호 명칭
해지 확인즉시 해지 처리 또는 명확한 일정 안내"검토 후 연락" 지연 처리

3.4 해지 확인 절차 (적합 예시)

적합한 해지 UX 플로우
STEP 1
해지 버튼 클릭
계정 설정 내 "구독 해지" 버튼 (1depth)
STEP 2
본인 확인
ID/PW 인증 또는 생체인증 (1회)
STEP 3
최종 확인
"해지하시겠습니까?" 확인 (1회)
STEP 4
해지 완료
즉시 처리 + 확인 이메일 발송

위 4단계 대비 해지 경로가 7단계 이상이거나, 가입이 2단계인데 해지만 6단계면 제21조의2①4호 가목 위반 가능성 높음.

섹션 4

체크리스트 — UX 설계 자가 진단

4.1 해지 접근성

  • 1해지 버튼이 계정 설정 1depth 이내에 위치 — ★★★ 필수
  • 2해지 버튼이 가입 버튼과 동등한 크기 — ★★★ 가입 버튼 면적의 80% 이상
  • 3해지 버튼 색상이 비활성화·희색 처리되지 않음 — ★★★ 활성 상태와 동일 명도·채도
  • 4해지 버튼 명칭이 직관적 — ★★☆ "해지"·"구독 취소" 사용, 모호 명칭 지양

4.2 해지 절차

  • 5해지 단계 수가 구매 단계 수 ±1 이내 — ★★★ 구매 3단→해지 4단 이하
  • 6해지 시 추가 정보 입력(설문·사유)이 강제되지 않음 — ★★☆ 선택적 입력만 허용
  • 7해지 완료까지 3회 이상의 재확인 없음 — ★★★ 최종 1회 확인만 허용
  • 8해지 시 할인 제안·재가입 유도가 1회를 초과하지 않음 — ★★★ 0~1회, 반복 금지

4.3 해지 수단

  • 9가입한 웹/앱에서 직접 해지 가능 — ★★★ 전화·방문 강제 금지
  • 10해지 처리 결과가 즉시 또는 명확한 일정으로 안내 — ★★☆ 지연 처리 금지
  • 11검색 기능으로 "해지" 입력 시 1클릭 내 해지 페이지 진입 가능 — ★★☆ 검색 차단 금지

4.4 약관·고지

  • 12약관에 "해지 불가"·"환불 불가" 절대적 표현 없음 — ★★★ 조건부 가능 표현 사용
  • 13법정 청약철회 기간(7일)보다 짧은 단축 없음 — ★★★ 7일 미만 안내 금지
  • 14자동 연장 조건이 가입 시 명확히 고지 — ★★★ 첫 화면에서 고지
  • 15해지 조건·효과·환불 기준이 약관에 명시 — ★★☆ 모호·누락 금지
섹션 5

위험 신호 — 6가지 경고

! 신호 1: 해지 경로 4depth 이상
계정 설정 > 결제 정보 > 구독 관리 > 구독 상세 > 설정 변경 > 해지 (6depth). 가입이 메인 화면 1클릭인데 해지가 6클릭이면 제21조의2①4호 가목 위반.
! 신호 2: "해지는 고객센터로 문의"
온라인 해지 버튼 없이 전화 문의만 안내. 제21조의2①4호 나목 위반 + 약관규제법 제9조 위반.
! 신호 3: 해지 시 3회 이상 팝업
"정말 해지하시겠습니까?" → "7일 무료 이용권" → "50% 할인 쿠폰" → "정말 떠나시나요?". 3회 이상 반복은 제21조의2①5호 위반 (단, "다시 보지 않음" 선택권 제공 시 면책 가능).
! 신호 4: 해지 버튼이 회색·8px 이하
가입 버튼은 청색 44px×240px / 해지 버튼은 회색 10px×60px. 제21조의2①3호 위반 (시각적 현저한 차이).
! 신호 5: 청약철회 기한 임의 단축
"수령 후 1일 이내만 환불 가능" 안내. 제21조①1호 위반 — 트렌비 심결례와 동일 유형.
! 신호 6: "해지 시 모든 혜택 소멸" 협박성 멘트
포인트·누적 혜택 전부 소멸 안내를 해지 버튼 옆에 표시. 제21조①1호 위반 가능성 높음 (기만적 해지 방해).

Q&A

자주 묻는 질문

해지 버튼은 어디에 위치해야 하나요?
계정 설정 또는 구독 관리 메뉴의 1depth 이내여야 합니다. "설정 > 계정 > 구독 관리 > 해지"처럼 3depth를 초과하면 위험합니다. 가장 좋은 설계는 계정 설정 첫 화면에 "구독 해지" 버튼을 노출하는 것입니다.
"정말 해지하시겠습니까?" 확인 팝업은 몇 번까지 허용되나요?
1회 확인 팝업은 통상 허용됩니다. 문제는 해지 확인 후 "7일 무료" → "50% 할인" 등 추가 제안을 2회 이상 반복하는 경우이며, 이는 제21조의2①5호 위반 가능성이 있습니다. 단, "다시 보지 않음" 또는 "거절 후 더 이상 표시 안 함" 선택권을 제공하면 예외가 인정될 수 있습니다.
해지 버튼 크기의 구체적 기준이 있나요?
법령에 px 단위의 구체적 기준은 없습니다. 규제 기준은 가입 버튼과의 상대적 차이입니다. 가입 버튼이 48px인데 해지 버튼이 10px이면 위험합니다. 해지 버튼은 가입 버튼의 동등한 시각적 계층(크기·색상·명도)을 가져야 합니다.
가입은 웹으로 했는데 해지는 앱에서만 가능한 경우 위반인가요?
네. 제21조의2①4호 나목은 가입 방법과 다른 방법으로만 해지를 제한하는 행위를 금지합니다. 가입 경로(웹·앱·전화)와 동일한 해지 경로를 각각 제공해야 합니다.
해지 시 설문 조사나 탈퇴 사유 입력을 강제해도 되나요?
선택적 입력은 허용되지만, 필수 입력으로 설정하는 것은 해지 절차를 복잡하게 만드는 행위로 제21조의2①4호 가목 위반 위험이 있습니다. 사유 입력 없이 해지 완료가 가능해야 합니다.
구독 해지 시 환불 기준은 어떻게 안내해야 하나요?
해지 버튼 옆 또는 해지 확인 단계에서 환불 기준을 명확히 표시해야 합니다. 전자상거래법 제18조(청약철회 효과)에 따라 환불 지연 시 지연배상금이 발생할 수 있습니다.
제21조의2①4호 심결례가 없는 이유는?
이 조항은 2026년 전자상거래법 개정으로 신설된 조문입니다. 2026년 7월 시행되어 아직 공정위 심결례·판례가 누적되지 않았습니다. 현 시점에서는 유럽 DMA·DSA 사례와 미국 FTC Click-to-Cancel 규칙을 참고하는 것이 실무적입니다. 다만 조문 문언이 명확하므로 시행 즉시 집행 가능합니다.
본 자료는 2026년 7월 29일 기준으로 작성되었으며, 인용된 법령·판례는 작성 시점의 현행성을 확인한 것입니다. 법령은 개정될 수 있고 사안마다 결론이 달라질 수 있으므로, 실제 의사결정 전 최신 법령과 개별 사실관계에 대한 확인이 필요합니다. 본 자료는 일반적인 법률 정보 제공이며 특정 사안에 대한 법률 자문이 아닙니다.
