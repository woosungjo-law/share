PROC-LABI — 노동청 진정·근로감독 자가진단

지금 우리 회사에 필요한 대응은? · 일반 정보, 법률 자문 아님

각 질문에 따라 분기를 따라가며 현재 상황에 맞는 절차 카드를 찾아보세요.

Q1. 현재 회사가 노동청으로부터 어떤 상황인가요?

  • 아직 아무 일도 없지만 대비가 필요하다 → 예방형 (Q2)
  • 이미 근로자가 노동청에 진정을 제기했다 → 진정 대응 (Q3)
  • 노동청 근로감독관이 방문·출석 연락을 해왔다 → 감독 대응 (Q4)

Q2. [예방형] 우리 회사에 아래 위험 신호가 있나요?

  • 최근 1년 이내 퇴직자가 임금·퇴직금 문제를 제기한 적 있다
  • 직장 내 괴롭힘·갑질 신고가 접수된 적 있다
  • 근로계약서·임금대장·근태기록이 제대로 관리되지 않고 있다
  • 취업규칙을 고용노동부에 신고하지 않았다 (10인 이상 사업장)
  • 포괄임금제 계약을 사용하고 있다
2개 이상 해당 → 내부 점검과 시정이 시급합니다 → 002(서류정비) → 003(선제대응)
1개 이하 → 현 상태 유지하되 정기 점검 권장 → 001(유형파악)

Q3. [진정 대응] 진정 내용이 무엇인가요?

  • 임금·퇴직금 체불 / 부당해고·징계 / 직장 내 괴롭힘·성희롱 / 근로시간·연장수당 / 기타
쟁점을 파악한 후 Q5로 이동하여 필요한 카드를 확인하세요.

Q4. [감독 대응] 어떤 형태의 감독인가요?

  • 근로감독관 사업장 직접 방문 → 현장 감독
  • 출석요구서 수령 → 출석 조사
  • 서면 자료제출 요구만 있음 → 서면 감독
  • 유형을 모르겠다 → 004(감독 유형별 접근법)

ⓘ 결과 안내

예방 단계라면: 서류 정비와 내부 점검부터 시작하세요. 대부분의 리스크는 사전 정비로 줄일 수 있습니다.

진정·감독 진행 중이라면: 쟁점별로 즉시 대응 전략을 수립해야 합니다. 단계별 카드를 순서대로 확인하세요.

처분·과태료 통보 후라면: 불복 기한(행정심판 90일, 행정소송 90일)을 먼저 확인하세요.
