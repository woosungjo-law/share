채무자 정보·재산 파악

3줄 요약

  • 내용증명을 보낼 대상(채무자)의 정확한 성명·주소·연락처를 확보한다.
  • 채무자의 재산(부동산·급여·계좌·사업)을 파악해야 추심 실익이 있다.
  • 채무자가 여럿이면 연대채무자 각각 파악해 전원에게 발송한다.

0. 지금 당신의 위치

공통 5단계: 사전 → 착수 → 대응 → 결정 → 사후 (현재: 사전)

시효점검(002) -> [채무자 정보·재산 파악] -> 절차 선택(004)

1. 이번 단계에서 반드시 할 일

  • 채무자의 정확한 성명·주민등록주소·실거주지 확인
  • 연대보증인·연대채무자 파악
  • 채무자 재산(부동산·차량·계좌·사업체) 정보 수집
  • 채무자의 연락처(휴대전화·이메일) 확보

2. 준비물

준비물 왜 필요한가 준비 상태
계약서·약정서(채무자 정보 기재) 채무자 특정·주소 확인 미확인
등기부등본(부동산 소유 확인) 재산 유무·가압류 가능성 미확인
금융조회(계좌·예금) 계좌 압류 가능성 미확인

3. 작성·제출물

문서 제출처 주의점
채무자 정보 확인서(자체 정리) 본인 보관 프라이버시 주의, 추심 목적 외 사용 금지

4. 흔한 실수

  • 채무자의 주소를 정확히 확인하지 않아 내용증명 반송 — 주민등록등본상 주소와 실제 거주지가 다를 수 있음
  • 연대채무자를 누락해 일부만 청구 — 연대채무자 각각 개별 발송 필요
  • 채무자 재산을 확인하지 않고 내용증명만 발송 — 회수 가능성 낮아 시간·비용 낭비

5. 전문가 상담 신호

위험도: 혼자 가능

  • 채무자가 법인인 경우 대표자·본점·지점 정보 확인 필요
  • 채무자의 재산 은닉 정황이 있으면 가압류 등 선제 검토 필요
