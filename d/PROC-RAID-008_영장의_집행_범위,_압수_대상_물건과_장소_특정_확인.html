PROC-RAID-008 | 영장의 집행 범위, 압수 대상 물건과 장소 특정 확인

3줄 요약

- 영장에 기재된 압수대상물품·수색장소·피의자를 실제 집행 범위와 일대일 대조하여, 영장을 초과하는 수색이나 무관한 물건의 압수를 현장에서 즉시 이의제기해야 한다

- 수사관이 영장 범위를 넘어 다른 직원의 PC·개인 스마트폰·다른 층 사무실·자물쇠 잠긴 캐비닛을 열려고 하면 "그 부분은 영장 범위를 벗어납니다"라고 명시적으로 고지하고 제지해야 한다

- 영장 범위 이탈이 명백함에도 수사관이 강행하는 경우 구체적 일시·물건·수사관 성명을 기록하고 추후 준항고·위법수집증거배제 신청·손해배상 청구의 증거로 삼아야 한다

0. 지금 당신의 위치

PROC-RAID-007(영장 복사·메모) -> [PROC-RAID-008: 범위 적정성 확인] -> PROC-RAID-009(수색 집행 입회·기록)

1. 이번 단계에서 반드시 할 일

- [ ] 영장에 기재된 수색 장소(주소·층·호수·방)를 현장 위치와 대조하고, 영장에 없는 장소(임원 집무실·개인 사물함·다른 법인 사무실)로 이동하려는 수사관을 제지한다

- [ ] 영장에 기재된 압수 대상 물품의 구체성을 체크한다:

- 특정 품목(예: "2024년 회계장부 3권") → 해당 품목만 압수 가능

- '관련 서류 일체'류 표현 → 포괄 영장으로 위법성 다툼 가능, 현장에서 이의제기 후 기록

- [ ] 전자정보 압수가 영장에 포함된 경우: 수사관이 저장매체 자체를 반출하려는지, 아니면 현장에서 출력·이미징만 하는지 확인 → 저장매체 반출은 형소법 제215조의2 제한 규정 적용

- [ ] 피의자와 무관한 제3자의 물건이 압수 대상에 포함되는지 확인 — 영장 기재 피의자가 A인데 B 직원의 개인PC까지 뒤지는 것은 원칙적 금지

- [ ] 영장 범위를 넘는 행위가 발견되면 즉시 구두 이의제기하고 이의제기 시각·발언·수사관 반응을 기록한다

- [ ] 변호사 도착 후 변호사에게 범위 이탈 사항을 보고하고 추가 대응(준항고·의견서 제출) 방향을 논의한다

2. 준비물

3. 작성·제출물

4. 흔한 실수

- 실수 1: 수사관이 "영장에 '기타 관련 물건'이라고 써 있다"며 무관한 서류까지 압수해도 묵묵히 수인 — '기타 관련 물건'이라는 기재만으로는 특정성이 부족하여 위법 압수일 가능성이 높음(대법원 2013도7102)

- 실수 2: 수사관이 영장에는 제1층 사무실만 기재되어 있는데 "2층도 회사 소유라며?"라고 묻자 "네, 2층도 저희 사무실입니다"라고 대답 → 동의로 간주되어 2층 수색도 허용됨 — 영장에 없는 장소는 "영장에 기재되어 있지 않습니다"라고만 답변

- 실수 3: 직원 개인 스마트폰이 수사 대상이 아닌데 수사관이 "PC 옆에 있는 휴대폰 좀 봅시다"하자 "여기 있습니다" 건네줌 → 임의제출로 간주되어 영장 불요 — 개인 스마트폰은 '피의자 물건'이 아니면 압수 거부 가능

- 실수 4: 수사관이 클라우드·이메일 계정에 접근하려는데 "비밀번호를 알려주세요" 요구에 대해 침묵하거나 제공 → 자기부죄금지 원칙 위반 가능성, 변호사 상담 전까지 비밀번호 제공 거부가 원칙

- 실수 5: 영장에는 없지만 법률상 의무(전자정보 보존 의무 등)를 이유로 수사관이 모든 데이터를 복제해가는 데 동의 — 보존 의무와 압수수색 범위는 별개

5. 전문가 상담 신호

위험도: 상담 권장

- 포괄영장이 의심되는 경우(압수대상물이 "본건 범죄사실과 관계있는 전자정보 일체" 등) — 즉시 변호사에게 영장 촬영본 전송

- 영장에는 특정 직원만 기재되었으나 수사관이 전 직원 대상 대면조사·PC 열람을 시도하는 경우

- 위험도: 전문가 필요

- 수사관이 압수물을 영장 기재 외의 범죄 혐의와 관련지어 분석하겠다고 명시한 경우 — 압수수색의 본래 목적 외 사용 문제

- 수사관이 국가보안법·반국가단체·군사기밀 등 특별법을 언급하며 영장 범위를 넘는 광범위한 수색을 시도하는 경우

- 압수된 물건 중 변호인-의뢰인 간 특권 통신(법률자문 이메일·메모)이 포함된 것으로 의심되는 경우 — 즉시 분리·봉인 요구

6. 인접 절차 연결

- 선행: PROC-RAID-007 (영장 원본 확인·복사)에서 확보한 영장 8개 항목을 기준으로 범위 대조 · 후속: PROC-RAID-009 (수색 집행 입회 및 압수물 목록 확인)

- 병행: PROC-RAID-006에서 호출한 변호사가 현장 도착 시 이 카드의 범위 이탈 기록지를 전달하여 즉시 법적 대응 개시
