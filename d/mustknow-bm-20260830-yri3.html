고객이 실제로 사는 것

리포트의 양이 아니라 리스크를 발견하고 실행 순서를 정하는 능력.

고객은 법률지식이나 리포트 자체보다 다음 네 가지를 구매한다.

  1. 대표가 놓친 리스크를 발견하는 능력
  2. 무엇부터 처리할지 정해주는 우선순위
  3. 내부 담당자가 실행할 수 있는 문서·체크리스트·기한
  4. 문제가 터졌을 때 이미 회사를 알고 있는 변호사의 대응속도
외부 메시지의 기준

“AI가 법률자문을 자동으로 해준다”가 아니라, AI가 회사 자료를 넓게 정리하고 변호사가 중요한 판단과 우선순위를 확정하는 법률 리스크 운영서비스라고 말한다.

진입상품의 경계

50만~150만 원은 매출을 만드는 가격이 아니라, 범위를 지키는 설계다.

항목스타터 진단의 약속경계선
입력홈페이지·약관·광고물·핵심 계약서 1~3건·문진표자료 범위를 초기에 고정
산출물주요 위험 후보 3개, 우선순위, 추가자료, 다음 단계가 담긴 2~3쪽 브리프처방 전체를 무료로 공개하지 않음
기간자료 수령 후 5~7영업일 가설실제 소요시간을 파일럿에서 측정
보완자료 보완 1회무제한 질의·문서 전면 재작성 제외
제외전수 계약감사·정식 법률의견서·소송수행·상시 모니터링필요하면 집중 진단 또는 월간상품으로 전환

반복상품은 시간을 팔지 않게 만든다

“고문”을 넓게 약속하지 않고, 결과물·검토량·응답시간을 계약 단위로 고정한다.

Starter월 100만

월간 리스크 요약, 격주 신호, 제한된 문서·질의 제공. 월 검토건수·응답시간 고정.

Standard월 200만

주간 또는 격주 레이더, 월간 대표 브리프, 문서·광고·약관 검토. 월 검토건수·회의횟수 고정.

Executive월 300만

주간 레이더, 월간 임원 브리핑, 일정·증거·우선대응. 긴급·대형 업무는 별도 전환.

운영 금지선

무제한 문의·무제한 계약서·24시간 대응을 포함하면 월정액이 아니라 변호사의 시간을 소진하는 대기계약이 된다.

페이스북 → 카카오톡 퍼널

콘텐츠의 임무는 상담을 많이 받는 것이 아니라, 맞는 고객이 자기 문제를 언어화하게 하는 것.

01

문제 인식

페이스북에서 대표가 모르던 계약·광고·규제 리스크를 구체적으로 보여준다.

02

관심 표시

게시물 CTA는 하나. 15문항 자기점검 링크로 이동시킨다.

03

정보 수집

카카오톡 채널·비즈니스폼에서 문진·자료·적합성을 확인한다.

04

유료 전환

범위·가격·일정을 확인한 뒤 간이진단으로 전환한다.

05

반복 전환

진단 결과와 다음 단계에서 월간 리스크레이더를 제안한다.

콘텐츠 4종 순환
  1. 사각지대형: 계약·기한·광고·규제 누락
  2. 전후 비교형: 위험한 상태 → 개선상태
  3. 대표 의사결정형: 승인·보류·협상
  4. 자기점검형: 5문항 또는 1페이지 체크리스트
카카오톡 운영 규칙
  • 자동응답에 운영시간·링크·범위·긴급사건 제외를 명시
  • 무료 단계는 적합성·범위 확인만, 처방은 유료 단계로 이동
  • 응답시간은 영업일 기준으로 고정
  • 고객 식별정보·사건자료를 공개 채널·외부 AI에 그대로 입력하지 않음

업종 전략: 하나의 웨지부터

장기적으로 2~3개 업종을 두되, 90일에는 한 업종의 반응을 먼저 확인한다.

우선순위대표 웨지하나의 진단 프레임으로 묶이는 이유

2순위계약·규제 반복형 B2B건설·인테리어·유통 등 계약·하도급·거래조건·광고 리스크를 반복상품화
3순위규제형 전문서비스의료·건강·교육·프랜차이즈 등 업종별 모듈로 확장 가능
실행 판단

첫 판매에서 세 업종을 동시에 광고하지 않는다. 한 업종에 맞춘 콘텐츠 8~12개와 문진으로 반응을 확인한 뒤 두 번째 업종에 이식한다.

대립검증: 반복상품을 버릴 것인가

capacity 위험을 인정하되, 매출 변동성과 운영 통제를 함께 비교했다.

반대 가설

1인 로펌이고 외부 협업자도 없으므로 월간 반복상품은 운영을 잠식한다. 콘텐츠·단건 진단·고단가 프로젝트만 운영하는 편이 낫다.

수렴한 결론

반복상품을 폐기하지 않고, 간이진단 또는 2주 프로젝트에서 반복 업무가 확인된 고객에게만 제안한다. 고객 수·검토량·응답시간·긴급대응을 계약서에 고정한다.

최종 추천안

90일에 만들 것은 작고 선명하게, 만들지 않을 것은 명시적으로 보류한다.

출시 전 하드체크

페이지를 발행하는 것과 실제 서비스를 출시하는 것은 다르다. 출시 직전에 다시 확인한다.

  1. 실존 확인: 광고·가격·법률문구의 최신 규정과 대한변협 안내 재확인
  2. MCP 교차: 변호사법 제23조·제34조 원문 API 재확인
  3. 기밀 확인: 채널·AI 도구에 사건·의뢰인 식별정보가 들어가지 않았는지 확인
  4. 범위 확인: 50만~150만 원 진단이 전사감사처럼 오인되지 않는지 확인
  5. capacity 확인: 파일럿 3건 실제시간 측정 후 티어별 고객 수 재설정
