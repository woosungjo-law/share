전세권 설정과 확정일자 차이 — 보증금 보호의 두 가지 길

SECTION

3줄 요약 (TL;DR)

  • 전세권은 등기부상 권리로 용익물권(사용·수익)과 담보물권(우선변제·경매청구) 이중 기능 — 인도·말소와 반환은 동시이행, 경매청구 전 이행제공 필수(민법 제303·317·318조, 77마90)
  • 확정일자(주택임대차)는 주민센터 신고로 대항력·우선변제권 확보 — 전세권보다 비용·절차 간단, 단 보증금 상한·최우선변제 등 주임법 특례 적용
  • 전세금 반환 분쟁은 (i) 용익 소멸+담보 잔존 구도, (ii) 인도·말소와 반환의 동시이행, (iii) 경매·배당(또는 공탁)에서 회수·면책 구조를 한 세트로 검토해야 함
SECTION

1. 전세권 vs 확정일자 — 무엇이 어떻게 다른가

한눈에 - 전세권: 등기 필요, 등기부상 권리 공시, 전세금 전액 우선변제·경매청구 가능, 설정비용(등기세·수수료) 발생 - 확정일자: 주민센터 신고만으로 대항력·우선변제권, 비용 저렴·절차 간단, 주임법상 최우선변제·보증금 상한 제한 있음

전세권은 민법 제303조에 따라 전세금을 지급하고 타인의 부동산을 점유하여 그 부동산의 용도에 좇아 사용·수익하며, 그 부동산 전부에 대하여 후순위권리자 기타 채권자보다 전세금의 우선변제를 받을 권리가 있다. 농경지는 전세권 목적으로 할 수 없다(제303조 제2항).

전세권이 기간만료 등으로 종료하면 용익물권적 권능은 소멸하나 전세금반환채권을 담보하는 담보물권적 권능만 전세금 반환 시까지 전세권설정등기 효력으로 존속한다(대법원 2014다10694). 전세권 소멸 후 전세권설정자의 전세금 반환의무와 전세권자의 목적물 인도·말소등기서류 교부 의무는 동시이행 관계이므로(민법 제317조), 전세권자가 민법 제318조에 따른 경매를 청구하려면 먼저 인도·말소의무 이행제공을 완료해야 한다(77마90).

[근거·조문] 민법 제303조 (전세권의 내용) — 전세권자의 사용·수익권, 우선변제권, 농경지 제외 ✓ 웹 화이트리스트 + 한국법 MCP 현행 확인

[근거·조문] 민법 제317조 (전세권의 소멸과 동시이행) — 전세권 소멸 시 설정자는 전세권자로부터 목적물 인도 및 말소등기서류 교부받는 동시에 전세금 반환 ✓ 웹 화이트리스트 + 한국법 MCP 현행 확인

[근거·조문] 민법 제318조 (전세권자의 경매청구권) — 설정자가 전세금 반환 지체 시 전세권자는 민사집행법 따라 경매 청구 가능 ✓ 웹 화이트리스트 + 한국법 MCP 현행 확인

확정일자(주택임대차보호법 제3조의2)는 임대차계약서에 주민센터(또는 온라인) 확정일자를 받으면 대항력(제3자 대항)과 우선변제권(경매·공매 시 보증금 우선배당)을 취득한다. 전세권보다 비용(수수료 600원 내외)·절차 간단하나, 보증금 상한(수도권 1.5억·광역시 1.3억·그 외 1.0억)과 최우선변제(소액임차인) 등 주임법 특례가 적용돼 전액 우선변제가 안 될 수 있다.

2. 전세권의 용익·담보 이중성과 실무 쟁점

한눈에 - 기간만료로 전세권 종료 → 용익권능 소멸, 담보권능만 잔존 → 전세금 반환 때까지 등기부상 권리 유지 - 전세권 존속 중 전세금반환채권 분리 양도·압류·가압류 효력 부정(제주지법 2021나15710) - 전세권 설정계약이 상행위면 상사소멸시효 5년 적용, 시효 완성 시 등기 말소 가능(제주지법 2021나15710) - 전세권자가 전출·인도로 용익 완전 배제 합의 시 합의해지로 종료, 담보권능만 잔존

전세권이 종료하면 용익물권적 권능은 소멸하되, 전세금반환채권을 담보하는 담보물권적 권능만 전세금 반환 시까지 전세권설정등기 효력으로 존속한다. 전세권 존속 중 전세금반환채권만 분리해 양도하거나 압류·가압류하는 것은 효력 부정된다(서울동부지법 2023나20268). 전세권 설정계약이 상행위인 경우 전세금반환채권에 상사소멸시효(5년)가 적용돼 시효 완성 시 등기 말소 가능(제주지법 2021나15710). 전세권자가 전출·인도로 용익권을 완전히 배제하기로 합의하면 합의해지로 종료된다(제주지법 2021나15710).

[근거·판례] 대법원 2014다10694 — 전세권 종료 후 용익권능 소멸, 담보권능만 잔존, 최선순위 전세권자 채권자 일정 요건 하 배당요구 가능, 배당요구 시 전세권 종료 사실 소명 필요 ✓ 실존·현행 확인 (폐기·변경 없음)

[근거·판례] 대법원 1977.4.13. 77마90 — 전세권자 인도·말소서류 교부 의무와 설정자 전세금 반환의무는 동시이행 관계, 경매청구 위해선 먼저 인도·말소의무 이행제공 완료 필요 ✓ 실존·현행 확인 (폐기·변경 없음)

[근거·판례] 서울동부지법 2023.9.6. 2023나20268 — 전세권 존속 중 전세금반환채권만 분리 확정 양도 효력 부정 ✓ 실존·현행 확인 (폐기·변경 없음)

[근거·판례] 제주지법 2022.12.23. 2021나15710 — 전세권자 전출·인도로 용익 완전 배제 합의 시 합의해지 종료, 상행위 전세권 설정 시 상사소멸시효 5년 적용, 시효 완성 시 등기 말소 가능 ✓ 실존·현행 확인 (폐기·변경 없음)

3. 전세권 소멸 후 분쟁 — 동시이행·경매·공탁 한 세트

한눈에 - 전세권 소멸 후 분쟁은 (i) 용익 소멸+담보 잔존, (ii) 인도·말소와 반환의 동시이행, (iii) 경매·배당(또는 공탁) 회수·면책 구조로 한 세트 검토 - 채권양도·가압류·가처분 경합 시 혼합공탁(변제공탁+집행공탁) 가능(서울동부 2023나20268) - 기간만료 후 신소유자도 전세금 반환의무 부담, 인도·말소와 동시이행, 말소 이행/제공 없으면 지체책임(지연손해금) 제한(서울중앙 2018가합567063)

전세권 소멸 후 분쟁은 (i) 용익 소멸+담보 잔존 구도, (ii) 인도·말소와 반환의 동시이행(민법 제317조, 77마90), (iii) 경매·배당(또는 공탁)에서의 회수·면책 구조를 한 세트로 검토해야 한다. 특히 전세권 존속 중 전세금반환채권 처분(양도)이나 압류·가압류 경합 상태에서 변제·공탁 및 말소절차는 등기부(부기등기 포함), 통지·승낙 문서, 공탁 사유 중심으로 쟁점을 정리해야 한다.

[근거·판례] 서울중앙지법 2018가합567063 — 기간만료 후 신소유자도 전세금 반환의무 부담, 전세금 반환의무는 목적물 인도·말소와 동시이행, 말소 이행 또는 제공 없으면 지체책임(지연손해금) 제한 ✓ 실존·현행 확인 (폐기·변경 없음)

SECTION

4. 확정일자(주택임대차) — 우선변제권과 최우선변제의 한계

한눈에 - 확정일자 받으면 대항력+우선변제권 취득 — 전세권 없이도 경매·공매 시 보증금 우선배당 - 최우선변제(소액임차인): 보증금 일정액(수도권 5,500만·광역시 4,800만·그 외 3,800만)까지 근저당권보다 앞선 배당 - 보증금 상한 제한: 우선변제권 행사 시 보증금 전액이 아닌 상한(수도권 1.5억·광역시 1.3억·그 외 1.0억)까지만 보호 - 전세권은 상한 없이 전액 우선변제·경매청구 가능 → 고액 보증금이면 전세권 유리

주택임대차보호법 제3조의2(확정일자), 제8조(우선변제권), 제10조(최우선변제), 제10조의2(보증금 상한). 확정일자는 비용·절차 면에서 전세권보다 유리하나, 고액 보증금(상한 초과) 임차인은 전세권 설정이 더 강한 보호 수단이 될 수 있다.

5. 첫 대응 체크리스트 — 오늘 바로 확인할 것

한눈에 - 전세권 설정 여부 확인: 등기부 갑구·을구 확인, 전세권설정등기 존재·순위·피담보채권액 - 확정일자 수령 여부: 임대차계약서 확정일자 도장·온라인 발급 내역 확인 - 보증금 규모 vs 상한 비교: 주임법상 우선변제권 상한(수도권 1.5억 등) 초과 시 전세권 설정 검토 - 전세권 소멸 시점: 기간만료·합의해지·경매개시 등 종료 원인·시점 특정 - 동시이행 이행제공: 전세권자 측 인도·말소서류 준비·제공 완료 여부(경매청구 전 필수) - 배당·공탁 자료: 배당요구서, 배당표, 공탁서, 통지·승낙 문서 확보

확인 항목 세부 내용 중요도
등기부 확인 전세권설정등기 존재·순위·피담보채권액, 근저당권·가압류 등 선후순위 권리 ★★★
확정일자 확인 임대차계약서 확정일자 도장·온라인 발급 내역, 우선변제권·최우선변제권 해당 여부 ★★★
보증금 vs 상한 주임법 우선변제권 상한(수도권 1.5억·광역시 1.3억·그 외 1.0억) 초과 여부 ★★★
전세권 종료 원인·시점 기간만료, 합의해지(전출·인도 합의), 경매개시, 시효 완성 등 ★★★
동시이행 이행제공 전세권자 측 목적물 인도·말소등기서류 교부 준비·제공 완료 여부(경매청구 전 필수) ★★★
배당·공탁 자료 배당요구서·배당표·공탁서, 채권양도·가압류·가처분 경합 시 통지·승낙 문서 ★★

6. 자주 묻는 질문 (Q&A)

Q. 전세권 설정했는데 기간 끝나고도 집주인이 전세금 안 돌려줘요. 어떻게 받아내나요? 전세권 기간만료로 용익권능은 소멸했으나 담보권능(우선변제·경매청구)은 전세금 반환 때까지 잔존합니다(대법원 2014다10694). 먼저 목적물 인도·말소등기서류 교부 이행제공을 내용증명 등으로 완료한 뒤(77마90), 민법 제318조에 따라 전세권 목적물 경매 청구를 하거나, 경매 진행 중이면 배당요구로 회수하세요. 신소유자도 전세금 반환의무 부담하며, 인도·말소 이행/제공 없으면 지연손해금 제한됩니다(서울중앙 2018가합567063).

Q. 확정일자만 받았는데 보증금 2억 원(수도권) 전액 보호받을 수 있나요? 주임법상 우선변제권 상한(수도권 1.5억 원)이 적용돼 초과분 5,000만 원은 우선변제권 보호 밖입니다. 최우선변제(소액임차인)도 수도권 5,500만 원까지만 근저당권보다 앞섭니다. 고액 보증금이면 전세권 설정(상한 없이 전액 우선변제·경매청구 가능)을 병행하거나, 임대차보증금반환채권 가압류·가처분 등 보전처분 병행이 필요합니다.

Q. 전세권 설정계약이 상행위라면 소멸시효 5년인가요? 네. 전세권 설정계약이 상행위(영업용 부동산 등)인 경우 전세금반환채권에 상사소멸시효 5년(상법 제64조)이 적용돼, 시효 완성 시 등기 말소 청구 가능합니다(제주지법 2021나15710). 비상행위면 민법상 10년(민법 제162조)입니다.

Q. 전세권자가 전출하고 열쇠 돌려주기로 합의했는데 전세금 안 주면 어떻게 하나요? 전세권자가 전출·인도로 용익권을 완전히 배제하기로 합의했다면 합의해지로 전세권이 종료됩니다(제주지법 2021나15710). 종료 후에도 담보권능은 잔존하므로, 인도·말소 이행제공 후 경매청구 또는 배당요구로 전세금 회수 절차를 밟으세요.
