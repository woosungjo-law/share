3MUST · 계약법

계약이 해제된 뒤 정산 범위를 정리할 때

적용 상황: 장비·물품·용역 계약이 해제되었고, 이미 지급한 대금과 이미 받은 물건·자료를 어떻게 정리할지 결정해야 하는 경우. 범위: 해제의 효력, 반환 범위, 이자·손해배상의 법적 성립은 판단하지 않습니다. 정산 항목을 빠짐없이 표로 만들고, 상대방과 사업부에 설명할 자료를 준비하는 카드입니다.

Must Know · 알아야 할 것

  • 해제 후 정산은 "받은 돈을 돌려준다"로 끝나지 않습니다. 반환 대상, 이자, 사용이익, 손해배상, 동시이행을 나눠 담아야 합니다.
  • 정산표는 금액을 크게 보이게 하는 문서가 아니라, 같은 항목을 두 번 청구하지 않게 막는 통제표입니다.
  • 이미 사용한 기간과 훼손·교체된 부분은 반환 대상과 별도 항목입니다. 합쳐 적으면 조정 과정에서 근거를 잃습니다.
  • 사업부가 기대하는 금액과 법무·재무가 계산한 금액이 다르면, 차이의 이유를 항목 단위로 설명할 수 있어야 합니다.
  • 상대방에게 보내는 통지와 내부 승인 자료의 숫자는 같은 표에서 나와야 합니다.

Must Check · 확인할 것

  • 우리가 지급한 금액과 지급일이 모두 표에 들어갔는가.
  • 상대방에게서 받은 물건·자료·권한의 목록과 상태(사용 여부·훼손·교체)를 확인했는가.
  • 사용이익(사용 기간·대체 비용)을 어떤 기준으로 계산할지 정했는가.
  • 원금과 이자, 지연에 따른 손해를 구분해 적었는가.
  • 해제 전후 발생한 비용(운송·보관·철거·복구)을 확인했는가.
  • 같은 항목이 두 번 청구되거나 상계로 중복 처리되지 않았는가.
  • 동시이행으로 묶어야 하는 항목(반환과 대금)을 표시했는가.
  • 계약서의 정산·해제 조항과 현재 계산이 어긋나지 않는가.

Must Do · 실행할 것

  1. 담당자는 지급금 / 수령물 / 사용기간 / 훼손·교체 / 추가비용을 한 표에 먼저 적습니다.
  2. 각 항목을 반환 / 사용이익 / 손해 / 비용으로 분류하고, 근거 자료 번호를 붙입니다.
  3. 동시이행 항목을 표시하고, 어느 쪽이 먼저 움직여야 하는지 순서를 정합니다.
  4. 사업부에 표를 공유하고, 기대 금액과 차이가 나는 항목을 짚어 설명합니다.
  5. 상대방 통지 문안은 표의 항목 순서대로 작성하고, 금액·기한·반환 방법을 명시합니다.
  6. 합의·소송·중단 중 어느 경로로 갈지 결정하고, 결정 사유와 승인자를 기록합니다.
  7. 정산이 끝나면 실제 반환·지급 내역을 표에 반영해 종결 기록을 남깁니다.
잠깐 멈추고 검토할 때

상대방이 이미 반환·보상을 일부 이행한 경우 · 사용이익·훼손 산정을 두고 양측 계산이 크게 다른 경우 · 해제 통지의 효력 자체가 다투어지는 경우 · 제3자(금융·보증·운송)가 정산에 얽혀 있는 경우 · 계약서에 정산 방식이 구체적으로 정해져 있지 않아 해석이 필요한 경우
