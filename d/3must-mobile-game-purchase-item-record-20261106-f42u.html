모바일게임 결제와 아이템 상태를 기록할 때

적용 상황: 모바일게임에서 결제한 캐시·상품이 계정에 반영되지 않거나 표시된 상품과 실제 상태가 달라 보일 때 기록을 정리합니다. 범위: 결제 내역과 게임 화면, 문의·답변을 대조합니다. 환불 가능 여부, 계정 정지의 정당성, 아이템 확률·표시 의무는 판단하지 않습니다.

Must Know · 알아야 할 것

  • 결제 영수증, 게임 안의 구매 화면, 계정 내 아이템 상태는 서로 다른 기록이므로 각각 보존합니다.
  • 화면은 업데이트되거나 사라질 수 있어 캡처 시각과 게임 버전·메뉴 위치를 함께 적습니다.
  • 계정이나 거래번호 전체를 공개하지 말고, 필요한 화면만 가린 사본을 공유합니다.

Must Check · 확인할 것

  • 결제 날짜·시각, 결제 수단, 플랫폼 영수증과 표시 상품명을 저장했는가?
  • 구매 직전 상품 설명·수량·옵션을 보여주는 화면을 보존했는가?
  • 결제 뒤 캐시 잔액·아이템 수량·우편함 등 실제 표시 상태를 확인했는가?
  • 오류 문구, 접속 상태, 게임 버전과 확인 시각을 기록했는가?
  • 게임사·앱마켓 문의번호, 문의 내용, 첨부한 자료와 답변을 연결했는가?
  • 다른 이용자의 계정·대화·결제 정보가 화면에 함께 노출되지 않았는가?

Must Do · 실행할 것

  1. 결제 영수증과 상품 설명 화면을 저장하고, 계정 식별정보가 보이는 부분은 내부 원본과 공유본을 구분합니다.
  2. 게임에 접속해 결제 뒤 잔액·아이템·계정 상태를 확인하고, 화면과 시각을 함께 기록합니다.
  3. 결제시각 → 상품표시 → 계정 반영 확인 → 오류 또는 차이 → 문의·답변 순서로 시간표를 만듭니다.
  4. 고객지원에 문의할 때 결제 플랫폼 영수증 번호의 필요한 부분과 게임 내 표시 상태를 연결해 전달합니다.
  5. 추가 답변이나 계정 상태 변경이 있으면 기존 기록을 덮어쓰지 말고 새 시각의 자료로 추가합니다.
  6. 원본 자료, 가림 처리한 공유본, 문의 내역을 분리해 보관하고 미확인 항목을 담당자에게 넘깁니다.
