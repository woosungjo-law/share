3MUST · 노동법자료 정리 · 법무 인계

노동위원회 접수 통지를 받은 뒤 자료를 법무에 넘길 때

접수 통지의 날짜와 자료를 원문 그대로 보존하고, 주장·확인 사실·미확인 사항을 나눠 검토를 인계합니다.

이 카드가 다루는 범위자료 정리와 법무 인계만 다룹니다. 제출기한, 구제요건, 해고 정당성, 답변 전략은 판단하지 않습니다.

MUST KNOW 먼저 알아야 할 것

  • 접수 통지의 내용, 신청인의 주장, 회사가 확인한 사실, 아직 확인하지 못한 내용을 구분합니다.
  • 법적 기한과 대응 방향은 스스로 계산·결정하지 않습니다. 통지서 원문을 보존해 법무 또는 담당 변호사에게 확인을 요청합니다.

MUST CHECK 자료를 네 갈래로 정리

접수 원본

  • 문서·봉투·첨부 파일과 전달 경로
  • 수령 날짜·시간과 통지서 표기 날짜

확인 자료

  • 사건의 주요 날짜와 조치
  • 인사기록·회의자료·전자문서의 보관 위치와 담당자

미확인·불일치

  • 신청서 주장과 회사 확인 사실을 분리
  • 자료 간 차이와 아직 찾지 못한 자료를 별도 표시

접근 범위

  • 개인정보·민감정보 포함 여부
  • 열람자와 전달 범위 지정

MUST DO 인계까지 순서대로

01

원본 보존

접수 담당자가 문서 원본, 수령 시각, 전달 경로, 첨부 목록을 기록합니다.

02

시간순 사실표

인사 담당자가 주요 날짜와 조치를 적고 각 항목에 확인 자료를 연결합니다.

03

주장과 사실 분리

각 항목을 신청서 주장, 회사 확인 사실, 미확인, 자료 간 불일치로 나눕니다.

04

검토 질문과 인계

법무 담당자가 자료 공백과 통지서 날짜를 확인할 질문을 만들고, 보관 위치·열람 담당자와 함께 담당 변호사에게 전달합니다.

멈추고 검토할 때

  • 통지서 날짜나 제출 표시의 의미를 판단해야 할 때
  • 회사 기록과 신청서가 다르거나 원본 자료가 사라졌을 때
  • 민감정보·제한 자료가 있거나 당사자 연락·합의·회신 방향을 정해야 할 때
