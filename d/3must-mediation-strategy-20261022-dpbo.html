3MUST · 민사소송

판사가 조정을 권고했을 때 수락할지 거절할지 정해야 할 때

적용 상황: 항소심에서 재판부가 조정을 권고했을 때, 조정을 받아들여 빠르게 마무리할지 승소 확률을 믿고 소송을 계속할지 결정해야 할 때 사용합니다. 범위: 조정 절차의 세부 진행, 조정조서 작성 문안의 법적 검토, 중재 절차 등은 다루지 않습니다. 조정 권고 분석, 4대 요소 분석, 수락·조건부 수락·거절 판단만 정리합니다.

Must Know · 알아야 할 것

  • 판사의 조정 권고는 항소심에서 자주 이루어집니다. 조정은 소송보다 빠르고 비용이 적게 들지만, 조건을 잘못 결정하면 손해를 볼 수 있습니다.
  • 조정이 성립하면 재판상 화해와 동일한 효력이 발생하여 확정판결과 같은 집행권원이 됩니다. 더 이상 항소·상고로 다툴 수 없습니다.
  • 기판력이 발생하여 동일 사안으로 다시 소송을 제기할 수 없게 됩니다.
  • 조정은 소송보다 비용과 시간을 크게 절감하고, 쌍방 합의에 기초하므로 관계 유지에 유리하며, 비밀리에 진행될 수 있습니다.
  • 한번 성립된 조정은 확정판결과 같이 불가역적입니다. 조건을 잘못 설계하면 집행에 어려움이 있을 수 있습니다.

Must Do · 실행할 것

  1. 판사의 조정 권고 내용과 배경(재판부 심증·사건 난이도)을 분석합니다.
  2. 승소 가능성을 객관적으로 평가합니다. 증거·법리·판례에 기반한 냉정한 평가가 필요하며, "감"에 의존하지 않습니다.
  3. 소송 지속 시 예상 비용(인지·감정료·변호사 보수), 소요 기간(향후 수개월~수년), 사업부 업무 차질을 산정합니다.
  4. 상대방의 현재 자력과 조정금 이행 가능성을 평가합니다(재산조회·신용정보).
  5. 조정 조건(금액·분할 일정·이자·위반 시 효과)의 손익을 계산하고, 수락·조건부 수락(역제안)·거절을 결정합니다.
  6. 최종 결론을 내립니다: 조정 수락(손익 유리·관계 유지 필요) / 역제안(조건 조정 가능) / 소송 지속(승소 확률 높고 조정 조건 불리) / 부분 조정(일부 쟁점만 합의).
  7. 조정이 성립할 경우 조정조서에 기재할 구체적 조건(금액·일정·위반 시 강제집행 조항)을 사전에 준비합니다.
잠깐 멈추고 검토할 때

판사가 조정을 적극 권고하지만 조정 조건이 구체화되지 않았을 때 · 승소 가능성을 객관적으로 평가하지 못하고 감에 의존할 때 · 조정 성립 시 기판력이 발생하여 동일 분쟁을 다시 제기할 수 없음을 간과할 때 · 상대방의 자력이 불분명하여 조정 후 이행 가능성이 의문일 때 · 사업부 의사 결정이 지연되어 조정 기회를 놓칠 위험이 있을 때 · 조정을 무조건 거절하고 소송으로 밀어붙이려 할 때 · 조정을 덜컥 수락하고 조건을 꼼꼼히 검토하지 않을 때
