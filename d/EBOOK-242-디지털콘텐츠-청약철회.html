디지털콘텐츠 청약철회 — 게임·구독·캐시 환불의 기준

3줄 요약 (TL;DR)

  • 전자상거래법상 디지털콘텐츠는 제공 개시 시 청약철회 제한되나, 가분적 콘텐츠는 미제공 부분에 대해 철회 가능하고 사업자가 제공개시·제한사유·시험사용 조치 입증책임 부담(전자상거래법 제17조②⑤·⑥, 대법원 2018다214746)
  • 게임 캐시(사이버캐쉬)는 결제수단·이용권 성격으로 미사용 시 청약철회 가능(공정위 2012전자0578), 단일 아이템(스킨·캐릭터)은 계정 귀속 시 제공개시 주장 가능하나 가분성·시험사용 조치 여부가 쟁점
  • 순차 제공되는 구독형 콘텐츠도 가분적 디지털콘텐츠로 보아 미제공 부분 환불 인정(서울중앙 2025나12671 — 4주 강의 중 미제공 50% 환불, '1/2 경과 전액불가' 약관 무효)
SECTION

1. 디지털콘텐츠 청약철회 — 기본 원칙과 예외

한눈에 - 전자상거래법 제17조②⑤: 디지털콘텐츠 제공개시 시 청약철회 제한 - 가분적 디지털콘텐츠는 미제공 부분 철회 허용, 입증책임=사업자(대법원 2018다214746) - 시행령 제21조의2: 시험사용 제공 방법 규정, 제24조: 일부 소비 비용 공제 가능

전자상거래 등에서의 소비자보호에 관한 법률(전자상거래법) 제17조 제2항 제5호는 디지털콘텐츠가 '제공이 개시된 경우' 청약철회를 제한하되, 가분적 디지털콘텐츠로 구성된 계약의 경우에는 제공이 개시되지 아니한 부분에 대하여는 청약철회를 할 수 있도록 예외를 둔다. 대법원 2018다214746은 제공개시 후에도 계약이 가분적 성격을 가지면 미제공 부분 청약철회 가능성을 열어 두었고, 증명책임은 사업자에게 있음을 확인했다.

[근거·조문] 전자상거래법 제17조②⑤·⑥ (시행 2026-07-21) — 청약철회등의 제한과 예외, 사업자 조치의무 ✓ 웹 화이트리스트 + 한국법 MCP 현행 확인

[근거·조문] 전자상거래법 시행령 제21조의2 (시험사용 제공방법) / 제24조 (일부 소비 비용) ✓ 웹 화이트리스트 + 한국법 MCP 현행 확인

[근거·판례] 대법원 2018.6.15. 선고 2018다214746 판결 — 제공개시 후 가분적 용역=미제공 부분 청약철회 가능, 증명책임=사업자 ✓ 실존·현행 확인 (폐기·변경 없음)

2. 유료재화(캐시·다이아) vs 단일 아이템(스킨·캐릭터) — 무엇이 다른가

한눈에 - 캐시·다이아 등 유료재화(결제수단·이용권) = 미사용 시 청약철회 가능 (공정위 2012전자0578) - 단일 아이템(스킨 1개·캐릭터 1개) = 계정 귀속 시 제공개시 주장 가능, 가분성·시험사용 조치 여부가 쟁점

게임 내 유료재화(캐시·다이아)는 결제수단·이용권 성격으로 미사용 시 청약철회가 가능하다(공정위 2012전자0578 — 넥슨모바일 사이버캐쉬). 게임산업법상 환전금지 조항과 청약철회는 충돌하지 않는다.

반면 단일 아이템(스킨·캐릭터 등)은 계정 귀속 시점에 제공개시됐다고 주장할 수 있으나, 가분성 판단과 시험사용 제공 조치(미리보기·한시적 이용) 이행 여부가 쟁점이 된다. 사업자가 전자상거래법 제17조 제6항에 따른 시험사용 조치를 하지 않았다면 청약철회 제한 주장이 배제된다.

[근거·결정례] 공정위 2012전자0578 (넥슨모바일 사이버캐쉬) — 사이버캐쉬=결제수단, 가치 현저 감소 부정, 게임법 환전금지≠청약철회 충돌 없음 ✓ 웹 화이트리스트 + 한국법 MCP 현행 확인

[근거·결정례] 공정위 2021전자1052 (메이플스토리 큐브 확률변경 미공지) — 사실관계 확정 ✓ 웹 화이트리스트 + 한국법 MCP 현행 확인

3. 순차 제공·구독형 콘텐츠 — 미제공 분량 환불 가능

한눈에 - 서울중앙 2025나12671: 4주 온라인 강의 = 가분적 디지털콘텐츠, 미제공 3·4주차 50% 환불 인정 - '1/2 경과 전액불가' 약관 = 무효

순차적으로 제공되는 온라인 강의, 구독형 콘텐츠도 가분적 디지털콘텐츠로 보아 미제공 부분에 대한 청약철회(환불)가 인정된다. 서울중앙지법 2025.6.10. 선고 2025나12671 판결은 4주 과정 온라인 강의를 가분적 디지털콘텐츠로 보고, 미제공된 3·4주차(50%)에 대한 환불을 인정했으며, '수강 개시 후 1/2 경과 시 전액 환불 불가' 약관 조항을 무효로 판단했다.

[근거·판례] 서울중앙지법 2025.6.10. 선고 2025나12671 — 4주 강의=가분적 디지털콘텐츠, 미제공 50% 환불 인정, '1/2 경과 전액불가' 약관 무효 ✓ 실존·현행 확인 (폐기·변경 없음)

4. 실무 체크리스트 — 소비자 측 vs 사업자 측

한눈에 - 소비자: 미사용 캐시 철회(2012전자0578 원용), 가분성 주장(다수 동일 가분물 vs 단일 아이템 구분), 로그 기반 사용내역 분리 청구 - 사업자: 단일 아이템 제공개시=계정 귀속 주장, 시험사용 조치 이행으로 §17⑥ 방어, 약관에 가분적 콘텐츠 철회 기준 명시

5. 자주 묻는 질문 (Q&A)

Q. 게임 캐시(다이아)를 충전만 하고 하나도 안 썼는데 환불받을 수 있나요? 네. 게임 캐시는 결제수단·이용권 성격으로, 미사용 시 청약철회가 가능합니다(공정위 2012전자0578). 사업자에게 제공개시·시험사용 조치 증명을 요구하세요. 게임산업법상 환전금지 조항과 청약철회는 충돌하지 않습니다.

Q. 스킨 하나를 샀는데 마음에 안 들어 환불하려니 '이미 지급돼서 안 된다'고 합니다. 가능한가요? 단일 아이템(스킨 1개)은 계정 귀속 시 제공개시 주장이 가능하나, 가분성과 시험사용 조치(미리보기·한시적 이용) 이행 여부가 쟁점입니다. 사업자가 시험사용 조치를 하지 않았다면 청약철회 제한 주장이 배제될 수 있습니다(전자상거래법 제17조 제6항). 로그상 실제 사용(착용·장착) 내역이 없다면 미사용 주장도 병행하세요.

Q. 월정액 구독 서비스를 중도 해지하려는데 '이용일수만큼만 환불'이라고 합니다. 정당한가요? 구독형·순차제공 콘텐츠는 가분적 디지털콘텐츠로 보아 미제공 부분(미경과 기간) 환불이 원칙입니다(서울중앙 2025나12671). '이용일수 공제 후 잔여분 환불'이 타당하며, '1/2 경과 시 전액 환불 불가' 같은 약관은 무효로 볼 여지가 큽니다. 콘텐츠산업진흥법 제27조·제28조, 표준약관 제32조·제35조도 참고하세요.
