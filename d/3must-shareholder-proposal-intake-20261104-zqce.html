주주가 주총 안건을 제안하는 서면을 보내왔을 때

적용 상황: 주주가 주총 안건을 제안하는 서면을 보내왔을 때

Must Know · 알아야 할 것

  • 제안서가 도달한 날이 기록의 기준입니다. 접수 일시와 도달 경로(우편·내용증명·메일·직접 제출)를 원본과 함께 남깁니다.
  • 제안은 안건 단위로 나눠 봅니다. 한 장에 여러 안건이 섞이면 안건별 검토 결과가 엉킵니다.
  • 기한과 요건은 추정하지 않습니다. 총회 일정에서 거꾸로 셈하는 기한과 제안자 자격은 법무가 확인해 확정합니다.
  • 접수 사실과 검토 일정을 먼저 정하고, 회신 내용은 그다음입니다. 회신 시기와 방식은 법무와 함께 결정합니다.

Must Check · 확인할 것

  • 접수 일시와 도달 경로, 원본(봉투·메일 원문)
  • 제안자 성명·법인명과 제안 시점의 주식 보유 자료
  • 제안 안건 목록(이사 선임·해임, 정관 변경, 배당, 감사 선임, 기타)
  • 제안 내용이 안건 형식으로 특정되어 있는지
  • 예정된 주주총회 일정과 검토에 쓸 수 있는 기간
  • 법정 요건 확인 항목(지분, 보유 기간, 제안 기한, 제안자 자격)은 법무가 확인
  • 정관에 제안 횟수나 방식을 정한 조항이 있는지 (정관 원문)

Must Do · 실행할 것

  1. 접수 즉시 접수 기록표를 만들고 원본을 보존합니다(사본 1부 포함).
  2. 제안 안건을 항목별로 나눠 적고 안건 유형을 표시합니다.
  3. 주주총회 일정에서 거꾸로 셈한 검토 일정표를 만듭니다. 기한 계산은 법무 확인 후 확정합니다.
  4. 법정 요건 확인 항목(지분, 보유 기간, 제안 기한, 제안자 자격)을 표로 나눠 '확인 필요'로 표시하고 담당자를 지정합니다.
  5. 안건별 검토 담당(법무·재무·사업)을 정하고 검토 질문을 정리합니다.
  6. 회신 여부와 시기를 법무와 정하고, 결정 기록을 남깁니다.
  7. 접수부터 결정까지의 기록을 한 파일로 묶어 이사회 보고에 씁니다.
잠깐 멈추고 검토할 때

제안 기한이 이미 지났을 가능성이 있는 경우 (법무가 즉시 확인) · 제안자 자격이나 지분 자료가 불명확한 경우 · 안건이 정관이나 법령과 충돌할 수 있다는 검토 의견이 나온 경우 · 제안자가 공개 또는 언론 대응을 예고한 경우
